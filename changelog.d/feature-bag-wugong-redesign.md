### 新增

- **行囊与武功改版原型**：`docs/design/bag-wugong-prototype.html`。行囊为雾中人影 + 蓝印花布包袱（人影四处挂点引出穿戴，布面上形态格，点物件出布贴纸签）；武功为崖洞石壁（石柱分类、壁刻各门武学、拓片写详情与招式、石印装配）。方向挑选页 `docs/design/concepts/bag-wugong-pick*.html`、`bag-pick-4.html`；素材 `art/xingnang/`、`art/wugong/`（底图与上下续画版、纸签、拓片、石印、十个招式像）。
- **原型第二版**：两页底图提亮为淡墨；武功石柱改 AI 墨笔类别图标（无藏书置灰不可点）、壁刻品质改用石青 / 朱砂描边与名字色、已装配改墨金不发光、每类四张招式像按武学分配、拓片名字随品质着色、特效带图标、招式效果整行不截断、熟练改写档名（圆满盖朱印）、装配与穿戴 / 卖出改 AI 笔刷按钮、石印名加墨底；行囊穿戴改两左两右、属性合计横排垫晕墨。
- **原型第三版**：两页底图以武功页洞口外那块画为风格参考重绘（雾气留白、平滑灰阶，去掉满屏碎石纹与草地纹理，行囊去掉营火与旗杆），布局与坐标不变；背包空格只留极淡底、品阶线收细、极品不发光；武功分类图标与壁刻名改深墨落在淡石上。附据点场景与门派图重绘样张 `docs/design/concepts/restyle-samples.html`。
- **原型第四版**：武功底图重画为户外摩崖（参考前尘、修炼与行囊同一家画法，去掉洞内方格石板与石柱），一整幅 4:3 画铺满舞台上下；壁刻改为直接刻在崖面、不画框，拓片挂在松下，石印落在右侧石台；行囊背包格收进布面中央，不再压到布边与铺盖卷。
- **武功原型重做（甲一）**：按用户选定的概念图 `concepts/wg5-wd-1.jpg` 实现——松崖打坐一整幅画（AI 原图抹去界面字样后重绘、上下续画），左缘一列类别圈，旁边目录竖写这一类各门（选中金字带点、已装下标一点、未得淡灰，一页八门可翻），右侧大字竖写名、两列批注与朱印，下设「招式」圆形墨像（外圈细弧为熟练，圆满盖印，悬停给式名、倍率、效果）与「属性」墨刷条（伤害、触发、耗气、冷却 + 特效），下沿一排圆为装配（首枚金圈为主修内功）；内功类别改为心法要诀 + 五项属性条。方向挑选页 `concepts/wugong-pick-5.html`。
- **武功原型第二轮**：目录换成 AI 画的宣纸板（板上竖线分八列，名字落在列中）；招式圆满去掉朱印角标；下沿装配圈缩小下移、收在画面左中，不再压到右侧属性；底图再淡一档（亮度 120、浓墨 1% 以内、颗粒磨细）；类别图标出四组（墨圆 / 朱印 / 墨笔 / 圆画）供在原型状态栏切换对比，素材 `art/wugong/icset/`、`toc.png`。
- **武功原型第三轮**：类别图标定为甲组墨圆，下沿装配圈同套；武功、行囊与修炼底图里的人物按原位重绘为连续笔触（去掉碎斑点与白色描边光晕）；招式圆固定大小，超过四式折成两行、题跋与属性随之让位；目录名、批注、属性名三处字体可在原型状态栏切换（文楷 / 宋体 / 马善政 / 小薇）对比。
- **武功原型第四轮**：武功页画上文字一律霞鹜文楷（去掉字体切换）；内功详情在名字下写「第 N 重 · 主修 / 转修后 · 最高至某境」；底图按战斗舆图与行囊的观感调色（反差 50 → 39、冷蓝灰调 b −1.5 → −7、饱和 6% → 14%），旧版留作 `bg-v1.jpg` 并可在原型状态栏切换对比。
- **武功原型第五轮**：选中武学的大字名改回马善政；为避免与修炼页「崖上打坐」雷同，按现版构图分区与冷灰调出四个演武候选底图（竹林练剑、瀑下推掌、崖边舞剑、残碑木桩，各两张，`art/wugong/opt/`），原型状态栏可切换对比。
- **武功底图定稿「崖边舞剑」**：改为男性剑客、按正常人体比例重画（原图人物偏瘦长），连续笔触；上下续画铺满舞台。候选底图与旧版底图删除。
- **武功剑客与修炼页同一人**：以修炼页人物为角色参考重画——年轻、无须、高束发髻、白内衫灰外袍；姿势与构图不变。
