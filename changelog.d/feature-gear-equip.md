### 新增

- **装备**：胜利后按关卡掷装备掉落（普通 6%、精英 20%、Boss 必掉；传功后开始，入门关只出凡品、精良），兵器 / 暗器 / 衣甲 / 佩饰四部位，每部位两型，凡品到极品五阶，词条数随品阶，词条名作前缀连进装备名。装备叠进战斗构筑与修炼页身手（百分比乘基础值，命中 / 闪避 / 真气相加，破军只对精英 / Boss，通玄只加招式）。
- **行囊页签**：传功后出现。左侧四个部位的穿戴与合计，右侧 10 × 8 形态格背包（兵器 1×3、暗器 1×2、衣甲 2×2、佩饰 1×1），品阶靠描边 / 底晕 / 角标，新得金点、比身上好的 ▲；点开比较面板逐项对比，可穿戴 / 卸下 / 卖出，一键出售上乘以下。
- **离线掉落**：闭关期间按挂机胜场逐场掷骰，出关结算多一行「拾得」；行囊放不下时不比身上强的直接卖掉、比身上强的卖掉最差的腾位。
- **埋点**：`gear_dropped` / `gear_equipped` / `gear_sold`（telemetry.md v2.9）。
