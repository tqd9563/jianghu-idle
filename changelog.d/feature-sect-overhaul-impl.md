### 变更

- **门派换成 21 家**：旧九派（华山、少林、唐门……）改为活江湖格局里卷二到卷十可拜的 21 家（苍崖派、千帆帮、千蛇窟、千岩寺……），拜入仍在境界 3 起；帮会、会的拜入叫「入伙」。旧存档按映射迁到新门派（华山 → 苍崖派、少林 → 千岩寺、唐门 → 花影坊、丐帮 → 千帆帮、武当 → 乾元观、峨眉 → 水月庵、崆峒 → 风雷堡、雁门世家 → 苍梧派、百蛊门 → 瘴月教），贡献与已换到的东西原样保留（存档 v20）。
- **门派地位六级**：按本世累计贡献升（250 / 650 / 1300 / 2300 / 3900），称谓按门派性质（记名弟子 → 长老、帮众 → 长老、教众 → 长老……）；兑换花掉贡献不降级，转世清零，前尘「认祖归宗」开局保留二级。
- **差事按地位分六档**：每档一件、四字名带一句交代，时长一个时辰（2 小时）或四个时辰（8 小时）自选，每档贡献 40 / 64 / 100 / 160 / 260 / 400（2 小时）与 120 / 192 / 300 / 480 / 780 / 1200（8 小时）；一级与旧短差、长差相同。
- **货架按地位解锁，价格重定**：一级寻常武学 100、入门内功 200；二级上乘残页 160 / 80、本门装备低档 480；三级进阶内功 1000；四级绝学残页 800 / 400 / 600；五级镇派内功 1950、本门装备高档 1300、归真卷册 1300。
- **内功改归门派**：九部旧内功分给苍崖派、千岩寺、瘴月教，镇岳功 → 定慧功、磐石功 → 伽蓝诀、菩提心功 → 菩提心经、千蛊心诀 → 万蛊归元经（只改名）；新增 48 部门派内功（石印暂借旧图）。
- **本门装备**：每家两件（如苍崖派松纹剑、听涛剑），极品，等级跟兑换时的前沿当量（高档再 +0.5），带一条本门固定词条，一世各换一次。
- **传闻**：每开一卷赶路图，战斗记录说一次该卷门派的拜山传闻（原只有卷三、卷四）。
