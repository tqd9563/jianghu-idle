### 变更

- **主按钮统一为朱砂一笔**：突破、冲穴、挑战、领牌派出、兑换、主修、精进一重、回归江湖、就此转世等不再是鎏金龙纹牌或描金圆角框，一律朱砂笔触米白字；突破就绪、择功时朱砂缓缓起亮。
- **次按钮统一为淡墨一笔**：收功、再闯一阵、行囊「一键出售」、卸下等去掉描线框，改为同形淡墨笔触。
- **等待态不再像按钮**：「约 N 小时后可突破」「内力未足」「交手中」、兑换差贡献、精进差内力时，只显示一行题字，上下各一道干笔。
- **侧栏底部去框**：「转世 / ⚙ / 报」不再是三个描边方块，「转世」为金色题字。
- **画上文字读得清**：武功页右栏与按钮行、行囊页头字下垫一团晕开的墨；舆图与分图的地名副题、据点名放大提亮；侠名录未得名的名字提亮；典籍院 / 天工库右栏暗底加实，货架行不再半透明。
