### 变更

- **界面骨架**：顶栏和状态条去掉，改为左侧「人物卷」侧栏（境界、年岁、身体状况、内力 / 银两 / 声望、页签、转世入口、设置齿轮）加右侧单页舞台；每页背后固定铺一幅 AI 水墨底图；手机宽度改为顶部资源条 + 底部页签栏
- **视觉语言**：标题改思源宋体、正文改霞鹜文楷；按钮改描金样式；卡片不嵌套、不描边；进度线统一为「实线已完成、虚线剩余」；提示点只留在侧栏；公式与推导收进悬停提示
- **修炼页**：人物图与月夜底图融成一幅；右侧改为身手（新增真气、去掉突破后数值）与破境（突破条件、窍穴经脉、突破按钮）两卡，有伤才出现伤势卡；周天进度改为月相加燃香
- **战斗页**：地图改为江湖路驿站，65 关按钮墙改为关卡进度线加眼前一段、全表按需展开；对阵区去掉底框与四维；战报改为回合抬头加成段叙述，每门武学每一式都有专属句子；一回合揭示约 2.7 秒（原约 1.3 秒）
- **内功页 / 武学页**：内功改为五关节点路、心法要诀（含气海）与线装书册「藏经」陈列；武学改为装配槽、按类别筛选的书脊陈列（带简笔类别图标）与每式熟练四节点（生疏 · 熟练 · 精通 · 圆满）、式名与附加效果
- **书肆**：从武学页拆出，成为独立页签
- **门派 / 声望阁 / 商店**：全部改为列表行；价格写在按钮上，买不起时下方写「还差 N」
- **整屏演出**：突破、出关、战败、转世、选内功统一为整屏演出，按事件换底色；出关标题按时辰写（一个时辰 = 2 小时），并显示离线期间结算的门派任务收益
- **称谓**：玩家可见的「归隐」统一改称「转世」（入口「转世」、演出「此生至此」、按钮「就此转世」）
- **设置**：侧栏齿轮弹出设置面板，可切换卡片底色（冷灰 / 墨青 / 檀木 / 漆底描金，默认冷灰）与画面主题
