### 变更

- **需求池**：「视觉风格整改」扩大为「视觉 + 骨架大改」并转入进行中，写明五条改法
- **原型第二版**：定骨架 A；加标题字体 / 正文字体 / 按钮样式三组切换（描金、朱印、墨锭）；身手与伤势统一成同一种卡片，身手固定在上、伤势出现时排在下方；身手去掉分组；战报字体统一
- **原型第三版**：字体定为标题思源宋体、正文霞鹜文楷，按钮定为描金；修炼页人物底图改椭圆羽化并去饱和，消除与页面底色之间的直线接缝，内视时底图隐藏、不再露出方框
- **原型第四版**：燃香进度去掉实心金线，改成暗檀色细香、燃过处留淡灰香灰，并标出三段周天刻痕；关卡进度线同样改为细线；对阵区去掉双方攻防命闪与「败则停」；战斗演出放慢，你和对手分两拍出手，一回合约 1.5 秒
- **进度线统一规则**：燃香与关卡进度线都用「实线 = 已完成、虚线 = 剩余」，颜色与线宽一致
- **原型第二轮**：内功、武学、门派（含拜山）、声望阁四页按第一轮定下的规则重画，商店与传承改为列表行，公式收进悬停；补突破、出关、战败、归隐盘点四个弹窗；战斗页与四个页面配上莉刻生成的水墨底图（`code/public/art/`）
- **原型第二轮修订**：出关、战败、归隐改成与突破同一种整屏演出（按事件换底色），不再是表格；所有页面底图统一放在页头右上同一位置，修炼页补一张崖松云海图、人物场景放大；突破「新开」改「解锁」；内功页删去路数/悟性/火候等说明，「路数」卡改名「心法要诀」，真气加一条气海刻度（标出每招耗气与下一式所需），三块改为上二下一；品质标签分出寻常素、上乘青、绝学金框；武学页改为装配槽 + 按类型筛选的线装书脊陈列 + 详情（可切换、装上/卸下、招式名、触发几率、熟练四档）；书肆移到新页签「市集」；门派页删去说明文字；所有商店统一为「价格写在按钮上、买不起时下方写还差多少」；卡片底色加四种可切换（冷灰、墨青、檀木、漆底描金）
- **原型第三轮修订**：玩家可见的「归隐」统一改称「转世」（入口按钮、演出、声望阁），演出改写为「此生至此 / 随魂而去 / 随身而散」；出关、战败删去多余说明；底图改为固定铺在整个舞台背后、上浓下淡，对阵区去掉底框直接长在画上，修炼人物图改用滤色混合融进底图；武学熟练度改为「生疏 / 熟练 / 精通 / 圆满」四节点线（进度收进悬停），「耗气」改「真气消耗」，每式可带附加效果；内功页加卷轴式「藏经」陈列，可按路数筛选、点开看心法要诀并转修；战报改为回合抬头加成段叙述，普攻、暴击、闪避、敌方出手、每式武学、路数爆发各有预设句式；惊雷诀暴击数值按代码校正
- **原型第四轮修订**：战报结尾改为「获得：银两 N」、回合节奏再放慢到约 2.7 秒；内功藏经换成莉刻生成的三种卷轴（素纸、青绢、金锦）；真气移到修炼页身手（气血下方），内功页去掉真气卡，心法要诀里写「气海 ×N，每精进一重真气上限 +1」，藏经详情改写「台阶止于第几重」与「气海」；卡片底色收进侧栏齿轮的设置面板（默认冷灰）；「市集」改回设定里已有的「书肆」
