### 新增

- **武学掉落**：传功后每场胜利另掷一次武学掉落（普通 3%、精英 10%、Boss 50%）：寻常掉某一式全本，第一式全本即得这门武学，靠后的式先收书匣、前一式学会即自动学会；上乘掉某一式残页（境界 3 起占三成、境界 4 起五成），每式 5 页拼成口诀顶招式秘籍，第一式拼齐即得这门武学。绝学不进池。离线挂机胜场同样掷骰，出关结算多一行「书匣」。
- **武学名录第一批 66 门**：现有 14 门按名录改名（流云剑 → 流云剑法、惊鸿剑 → 惊鸿照影剑、降魔杵法 → 金刚降魔杵……），新增 52 门（含六个新派各一门绝学，暂无来路），式名与战报句并入冻结文案；代码读 `data/wuxue-catalog.json`，由 `export_wuxue.py` 从 sim 产物生成。
- **武学页**：藏书改书封陈列（品阶换色、类目印、路数章），类目按器械 / 肉身 / 暗器分组；未拼齐的武学压暗陈列并显示全本 / 残页进度；详情页多一行兵器搭配、每一式的特效数值与口诀页数。

### 变更

- **出招规则**：固定 55% 改为各门触发几率求和（封顶 75%）、按几率加权抽门；每门武学五项参数各不相同；耗气与冷却按抽中的那一式。
- **特效**：每一式都带特效，数值分四档随式递增；新增运劲 / 凝眸 / 轻身 / 回元 / 连击 / 透劲 / 封穴 / 卸力 / 迷目 / 破绽十种，持续类三回合、同名只刷新；必暴另加会心伤害，回气改按比例返还，护体与附毒减半。
- **熟练度**：不再加倍率，改为熟练 / 精通 / 圆熟 耗气 ×0.92 / ×0.84 / ×0.75、触发 ×1.04 / ×1.08 / ×1.12，圆熟冷却 −1。
- **兵器搭配**：器械武学要手持同类兵器、暗器武学要暗器槽有暗器、肉身不挑；换兵器或卸下时不合的武学自动卸下。
- **战报**：特效句只在特效确实生效时追加；连击补刀、封穴各自成句；拾得武学一行。
