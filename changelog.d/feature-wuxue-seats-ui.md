### 变更

- **内功、武学合为「武功」一页**：侧栏「内功」「武学」两个页签合成一个「武功」。页头下「装配」一行放主修印匣与武学印匣，中间一道竖线；下方左侧「藏书」栏可切内功 / 武学，右侧一本翻开的磁青书显示点中的那本。修炼页「详情」跳过来直接翻开主修内功。
- **装配改为印匣**：原来五个写着「空槽」的等宽盒子改为印匣：方匣描边与名字按品质着色，匣中一枚石印（武学按类目、内功九部各一枚），石印按路数换色；武学下写触发几率，内功下写第几重。
- **藏书改为 3 × 3 窄栏**：一页九本，武学可翻页，筛选改为类目石印小图标、只列有书的类目；已装的武学不再在藏书里重复陈列。
- **详情改为磁青书页**：武学左页写伤害倍率、真气消耗、冷却回合、触发几率、附加特效五项全称，不能装时按钮仍写「装配」并置灰、缘由写在上方；右页每一式一行，绝学七式在页内滚动。内功左页写第几重、最高可至与内功提供的气血 / 攻击 / 防御 / 命中 / 闪避，底部「精进一重」，临关、缺卷册或内力不足时置灰并写明缘由与约需时长；右页心法要诀只出现这一处（原页头卡片与藏经详情重复两遍），每条右侧挂会改它的关名，改了什么放进悬停，不再写「逐重加成」。
- **翻开非主修的内功按转修后显示**：同路重数减 3、跨路从 0 重起，已过之关须重新顿悟；底部为「转修 · 保留八成功力」或「散功重修」。
- **换书翻页与数字上涨**：点另一本时书先合上露出封面再以中缝为轴翻开；精进后基础属性从旧值逐格跳到新值。减少动态效果时不播。
- **路数章改为实底**：武功页与市集里的路数章由透明描边章改为与品质章同形的实底章（同色淡底 + 细描边），靠色相与品质章区分。

### 修复

- **书封题签错位**：内功书封上的书名原先偏到封面米色题签右侧之外，现按三张封面原图上的题签位置逐张对齐；武学书封叠的题签也与原图对齐，不再露出两层。
