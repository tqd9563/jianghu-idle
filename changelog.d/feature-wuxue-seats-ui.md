### 变更

- **武学页改版**：issue #80，原型定稿。页头下「装配」一行改为印匣：类目石印放在品质色描边的方匣里，印色按路数，名字着品质色；藏书收成左侧 3 × 3 窄栏，一页九本可翻页，筛选改为类目石印小图标；详情改为右侧一本翻开的磁青纸书，高度与藏书栏对齐，参数写全称，路数章改为实底，大印按路数着色，不能装时按钮仍写「装配」并置灰。书只在一处：装配后从藏书里移走，卸下即放回。
- **内功页改版**：同一套骨架。页头下「主修」只留一行：心法名、品质 / 路数章、第几重。藏经同为 3 × 3 窄栏，右侧磁青书页左页写第几重与最高可至，列出内功提供的气血 / 攻击 / 防御 / 命中 / 闪避，底部「精进一重」，点后重数、属性、要诀数值同步刷新；临关或内力不足时置灰并写明缘由与约需时长。翻开非主修的书时，按转修后的样子显示：同路重数减 3、跨路从 0 重起，已过之关须重新顿悟。右页心法要诀只出现这一处，每条右侧挂会改它的关名，改了什么放进悬停；不再标「逐重」。
- **翻书与数字动效**：内功 / 武学换书时书页先合上露出封面再翻开；精进后基础属性从旧值逐格跳到新值。
- **内功、武学合并为「武功」一页**：装配一行放主修印匣与武学印匣、中间一道竖线；藏书一栏标题旁切内功 / 武学；右侧一本书翻开点中的那本。主修印匣同武学印匣，九部心法各一枚石印、按心法名取象，印色按路数。
