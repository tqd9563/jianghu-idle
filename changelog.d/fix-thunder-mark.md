### 变更

- **剑意改叠浪，惊雷路数改名归海**：核心机制由「剑意 / 爆发剑招」改为「叠浪 / 排山倒海」，路数改名「归海 · 爆发」，三部内功改名百川诀 / 沧海功 / 沧溟真经（存档 id 不变，旧档自动显示新名）。心法要诀改为「每次会心叠 1 重浪；叠满 N 重，施展排山倒海」；战报爆发句、选内功卡、台阶效果、战败统计全部不再提「剑」，拿刀、赤手、用暗器时读起来不再错位（issue #69）。
- **叠浪重数退出战报，改在战斗页潮位条显示**：会心后不再在战报里追加「剑意又凝一分（n / m）」，改为四句不带数字的余劲句轮换（如「你收招回气，只觉胸中那股劲又足了几分。」），叠满的那一下不追加；战斗页「你」一侧气血 / 真气下方新增「叠浪」潮位条，按重上涨、水青渐金，叠满时浪头发亮停 0.7 秒再泄空。

### 修复

- **排山倒海先于会心出现**：叠满时战报原先先写「排山倒海」、再写触发它的会心句，会心句的伤害还含着爆发伤害；现在先写会心（只含本击伤害），再写排山倒海，潮位条也在会心之后才叠满泄空。
