### 变更

- **传功弹层去小字**：「择一门心法」不再显示副标题、每门心法的一句话风格与「短板 / 代价」行，只留心法名、路数与三条效果
- **行囊去引导字**：空着的穿戴槽不再写「空着」；没选中背包装备时右下角不再显示「点背包里的装备，在此与身上的比较」
- **属性面板取整**：身手里的气血、攻击、防御、命中、闪避一律显示整数（原攻击会出现 11.2 这类小数）；会心悬停说明去掉「（路数赠予与逐重）」括号小字
- **挂机状态栏**：改为「第 N 关 · 挂机中 · 停止」，不再在此处显示已打场数与拾得件数（原「收手」按钮改叫「停止」）
- **藏书招式行**：不再写「全本未得 / 全本在匣」；得了全本或残页凑齐的式整行亮起不带文字，没得的保持灰暗并显示「全本 0 / 1」或「残页 x / N」
- **战报普攻句子按手中兵器**：原先按内功路数写（修惊雷诀没拿剑也写「一剑」），现改为看兵器槽：剑 / 刀 / 枪 / 棍各一组，兵器槽空而暗器槽有物写暗器，赤手写拳脚（镇岳路数写拳掌）；新增刀、枪、棍三组句子（`battle-narration.md` v1.3）

### 修复

- **精进按钮光标**：带悬停说明的按钮不再显示问号光标，改为普通手形
