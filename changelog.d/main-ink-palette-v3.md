### 变更

- **丹田素材换墨色版**：内视液体素材由亮金双鱼旋涡换成水墨版 `dantian-ink-loop-graded.mp4`——玄墨底、淡墨笔触双鱼、仅中心一点朱砂丹核，与夜雨账台主题一致。调色用 ffmpeg 烘进素材（`eq=gamma=1.45:saturation=1.12`，720×720 / crf 26），运行时不挂任何 CSS filter。素材体积 18MB → **185KB**，循环接缝 0.58%。
- **外视丹田融入画面**：此前是深色硬边圆盘贴在水墨人影上，观感突兀。改为三层——正片叠底暗晕（在白袍上压出受光凹陷）+ 屏幕混合气光 + 径向遮罩羽化的视频层，并关闭外视的液位裁切（小尺寸下那条水平切边会暴露成矩形）。外视进度改由辉光强弱表达，液位只在内视读。
- **液面加波动**：内视液面由一刀切的直线改为两道错速正弦波（7s / 11s 反向），配合细液面线。
- **星曜去塑料感**：窍穴由带白芯的四芒亮片改为「星等圆点 + 常驻柔晕」（敦煌星图画法），半径按星等分四档；星官连线细至 0.8px。全局配色压进墨调：朱砂由 `oklch(0.62 0.19 32)` 降到 `0.55 0.115 34`，鎏金由 `0.85 0.15 78` 降到 `0.74 0.075 76`，月相/贯通柔光同步。

### 修复

- **上弦月路径损坏**：`moonShape()` 中 `y + r` 因 `y` 是字符串而做了字符串拼接（`"174.8" + 7.5` → `"174.87.5"`），导致半月路径非法、上弦月一直渲染成残缺细牙，控制台刷 `<path> attribute d: Expected number`。改为入参强制转 number 并统一 `toFixed(1)`。
- **液体区矩形白块**：给 `<video>` 或其祖先挂 CSS `filter` 会打断合成快路径，实测在液体区产生硬边矩形假影（有滤镜时采样区平均亮度 83.2，去掉后 25.9）。改为调色烘进素材、运行时零滤镜。
