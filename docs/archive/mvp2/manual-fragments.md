## 1. 一句话结论

秘籍残页以「6 本 × 3 页、全确定性获取、跨归隐保留、集齐整本才生效」的最小形态进入 MVP-2A，作为 3–5 天验证窗口的长期目标载体；门径真传通过「真传试炼」（三场专门压制所选武学门径的固定挑战）获取，声望商店的残页兑换接住第 4 轮买空平台期。星级、新招式、首发随机掉落、图鉴独立系统一概不做。

## 2. 评估

### 2.1 对照自然回流五前提（cadence.md §2）

| 前提 | 残页如何满足 |
|---|---|
| 仍有未完成目标 | 收集进度（X/18 页）常驻可见，跨轮不清零（§3.4） |
| 仍有可见的下一步成长 | 每本缺页的确切来源在秘籍阁逐本可查（§3.1 确定性序列），下一步永远可指认 |
| 离线推动但不替代关键决策 | 离线零残页产出（§3.1-D），获取全部绑定在线行为（推进 / 试炼 / 兑换） |
| 回来后有真实决策入口 | 「挑战试炼 / 改修门径收另一本真传 / 声望换页还是换节点」都是真决策 |
| 关闭前形成下次预期 | 「还差 1 页，下轮试炼可得」由确定性发放直接给出，不用玩家猜概率 |

### 2.2 对照 MVP-2A 退出标准（cadence.md §3）

| 退出标准 | 本方案贡献 |
|---|---|
| 3–5 天窗口内容不耗尽 | 18 页铺约 5–6 轮，窗口内预期集齐 2–3 本，窗口末仍有缺页、未竟试炼与整条真传长尾（§3.3） |
| 每次回访有可解释待办 | 待办 = 缺页清单 + 明确来源 + 待战试炼，埋点可验证（§4.3） |
| 一轮归隐不再压缩到 60 分钟 | **间接贡献**：跨轮收集给多轮游玩理由；轮长本身的拉长主责在 MVP-2B 重锚 |

### 2.3 与「图鉴 / 见闻录」的对比结论

选残页，图鉴不独立立项。图鉴记录「见过什么」——被动积累、零回访决策；残页要求「去做什么」——每个渠道就是一条待办，集齐还有战斗内回报。秘籍阁列表页本身就承担了图鉴的收集呈现价值（做残页 ≈ 附带图鉴骨架，反之不成立）。若未来需要「江湖痕迹」类记录，作为秘籍阁扩展页评审，不开新系统。

### 2.4 与方向记录的关系（继承 / 修订声明）

- **修订** `wuxue-collection-direction-note.md` §1/§3 的排期定位：「武学收集」的**最小子集**（秘籍残页收集）从「完整版方向」提前到 MVP-2A。理由：cadence.md §3 已将其收敛为 MVP-2A 已选方向，长期目标载体是 MVP-2 的真实缺口。
- **边界收窄**：本方案的「秘籍」不是新武学本体——不给新招式、新机制流派、新触发机制，只是既有三武学门径与属性白名单之上的收集与调节层；「8 类武学 × 多渠道 × 图鉴」的完整框架仍属完整版。完整版「概率触发主动武学」的架构定位见 `worldview.md` §5，与本方案兼容（§3.2 前向兼容声明）。
- **原样继承**：星级 / 品阶分层（完整版方向）、战斗内手动技与蓝条（已拒绝）、方向记录 §5 规格化前置检查四项（本文 §3.6 逐项落实）。

### 2.5 防膨胀边界（对照 cadence.md §8）

| 不做 | 一行理由 |
|---|---|
| 星级 / 品阶 / 强化 | 方向记录 §3 红线：强度分层把内容矩阵再乘一维，须在框架验证后进场 |
| 套装 / 组合效果 | 跨本组合会引出新的乘法项与失控的平衡面，违反乘区 ≤2 纪律 |
| 获取随机掉落（首发） | 判定次数太少，概率只剩运气没有期待感，还会污染 3–5 天窗口的回流判定；随机形态已定型后置（来源表 `drop_type` 列 + 坊间秘闻，§3.1 / §3.5） |
| 残页零散效果 | 残页有效果 = 第 N 条数值成长线；整本生效才让「差 1 页」成为钩子 |
| 残页交易 / 分解 / 合成材料化 | 新资源新三列账，超出验证需要 |
| 门派 / 奇遇 / 秘境获取渠道 | 渠道挂在现有系统与最小挑战节点上，不为渠道立新系统 |

## 3. 系统设计

### 3.1 获取来源：三渠道 + 离线零产出，全确定性

**总原则：首发全确定性发放，零随机。** 每个渠道按内容表预设的页序列发「未持有的下一页」；来源表保留 `drop_type: fixed | random` 列，首发全 `fixed`，随机掉落留给正式版评审（内容池扩大、有多人样本后才有意义）。玩家任何时刻都能在秘籍阁看到每本缺页的确切来源——「待办可解释」是系统属性，不靠文案技巧。

| # | 渠道 | 规则 | 理由 |
|---|---|---|---|
| A | Boss 1 / Boss 2 **本轮首杀** | 每轮各发江湖遗篇序列的下一缺页 | 每轮重打 Boss 有新回报，与声望里程碑（每轮重算）同构 |
| B | **真传试炼**（本轮首胜） | 通关发「当前所修门径」真传的下一缺页，规则见下 | 收集难度来自挑战性而非运气；「过试炼得真传」叙事见 `worldview.md` §8 |
| C | 声望商店 | 双商品，规则见 §3.5 | 玩家唯一的主动补齐渠道 + 声望长期出口 |
| D | 离线 | **零产出**，`offline-rewards.md` 表 B 维持 `drop_group = none` | 残页获取必须绑定在线时刻（MVP-1 §5 决策保留口径）；出关结算不加「机缘」区 |

**真传试炼（渠道 B）规则**：

- **形态**：三场**固定配置**的 1v1 挑战战，每场专门压制一条门径。敌人只用现有 7 属性、6 状态、9 标签，复用现有战斗结算，无新机制：

| 试炼 | 压制手段（标签） | 为什么难 | 本门径的解法（设计意图） |
|---|---|---|---|
| 惊雷试炼 | 高闪 + 反伤 | 闪避让暴击落空；爆发挨大额反弹 | 剑招「必中」是正解（参悟降剑意需求 = 更多必中输出）；境界血量兜住反弹 |
| 镇岳试炼 | 毒 + 破甲 | 毒绕过护盾直扣气血；破甲削防御 | 血线管理：三重参悟（低血减伤）+ 武学血防成长撑过毒伤 |
| 蚀骨试炼 | 净化 + 高攻 | 毒层被周期清除；时间压力大 | 抢毒爆：一重参悟（初始层）+ 二重（层上限）在净化间隙叠满；该敌净化取「清固定层数」形态（`../mvp0/spec.md` §7.2 既有两选项之一，取值 MVP-2B 定） |

- **双解法**：每场既能靠参悟（理解本门径机制）解，也能靠练度（境界 / 武学）硬吃——两条路都必须通，MVP-2B 用 sim 验证。
- **解锁与频次**：击败本轮 Boss 2 后开放；入口标注推荐境界 5（难度锚定境界 5 满配附近单点，MVP-2B 定）；允许提前挑战，失败免费重试（沿用 15–30 秒演出成本）；**本轮首胜发页，每轮限一次**。
- **入场限定**：只能以对应门径应试（修剑法门径 · 惊雷才能打惊雷试炼）；发哪本真传以**首胜瞬间的当前门径**为准；改修门径后再胜不重复发（每轮限一次，封死一轮刷多本的空子）。
- **结算边界**：试炼只发残页，不发内力 / 银两 / 阅历（不与回刷收益、「江湖熟路」节点纠缠）；不计入声望表现加成（防「漏打试炼 = 声望亏损」的被迫感，`economy.md` §1.2 不改）；胜利计入保底停滞计时的进展事件，失败不计（`economy.md` §6.2 事件清单需增补，登记见 §4.2）；离线不推进。

**归隐与收集的关系（渠道裁决记录）**：归隐**不直接发页**（评审删除，防收集门槛过低）；归隐的角色是**刷新闸门**——本轮首杀 / 首胜机会用完后，只有归隐开新轮才有新页。归隐预览加一行提示（「归隐后可再度寻访残页」之意，措辞进文案冻结批次）。

**与 MVP-0 §8.3 的口径区分**：残页发放挂「本轮首杀 / 首胜」计数（每轮归隐重置），不是首通奖励复发；首通阅历与解锁记录零改动，实现侧两个计数器分开。

### 3.2 秘籍作用：效果形态与公式影响面

**裁决：数值加成（江湖遗篇）+ 门径机制参数强化（门径真传）；不做新招式、新机制流派、新状态。** 理由：新招式等于新触发机制，撞 MVP-0 §7.2 属性与状态「禁止新增」的锁，且 MVP-2 验证的是回访动机不是构筑深度。

| 类型 | 数量（推荐） | 效果形态 | 生效条件 |
|---|---|---|---|
| 江湖遗篇 | 3 本（入门 / 进阶 / 压轴）`[待 MVP-2B 复核]` | 白名单 7 属性内的永久百分比加成，并入「永久加成总和」、与声望节点加法合并——不新开乘法项，公式两括号结构不动（初案「四」、`../mvp0/formulas.md` §3.1） | 集齐整本即永久生效 |
| 门径真传 | 3 本（惊雷 / 镇岳 / 蚀骨各一） | 对应门径核心机制的参数升级（等价「第四重参悟」：剑意 / 护盾反伤 / 毒的参数，形态同 `../mvp0/content.md` §3.2） | 集齐且当前所修门径对应时生效；不对应时显示「未启用」，不没收 |

**影响面收窄声明**：只触碰 `../mvp0/formulas.md` §3.1 属性数值与 §3.5 三门径机制参数；§1 战斗公式、§2 六状态规则、§7.2 结算顺序**零改动**；不新增属性、状态或乘法项。

**前向兼容**：真传效果作用于门径核心机制的参数，不绑定任何具体招式——完整版主动武学系统（`worldview.md` §5）进场后全部继续有效，无需返工。

**锚点与调参优先级**（数值 MVP-2B 定）：

- 全部秘籍效果的提速贡献之和 ≤ 声望 8 节点总和的约一半（所有者已确认）——声望仍是永久成长主轴。
- 单本效果的可感知度 ≥ 最低档声望节点（30 声望档）——集齐必须有体感。
- 调参顺序：① 先调获取节奏（页/轮），不动效果；② 再调遗篇属性幅度；③ 最后调真传参数（改它要重跑三门径 Boss 需求矩阵）。

### 3.3 收集结构与回访节奏

**结构：6 本 × 每本 3 页 = 18 页** `[待 MVP-2B 复核：随重锚后轮长调整，优先调页数不调本数]`。书名为占位，文案冻结批次定名；**命名类型已裁决（所有者 2026-07-09）**：江湖遗篇用纯风味名（不承诺效果，效果在书页详情呈现——集齐揭晓多一次开卷感）、门径真传用机制点题名（机制归属是宪章级定稿，点题维持「为门径变强」的目标感）——书名定稿因此不依赖 MVP-2B 效果分配，文案冻结批次可与数值批次并行。

| 梯度 | 书 | 铺设意图 |
|---|---|---|
| 入门 | 遗篇一 | 序列前 3 页——**第 2 轮开局集齐**（首轮 Boss 1/2 两页 + 第 2 轮 Boss 1 第三页），第一次「集齐 → 生效」构成第二轮开局奖励，教学收集回路 |
| 进阶 | 遗篇二 | 序列中段，约第 3–4 轮 |
| 压轴 | 遗篇三 | 前 2 页在序列末段；**尾页仅「指名寻访」可得（独立高价档）**——窗口末期钩子 + 声望深出口 |
| 长尾 | 真传 ×3 | 单本随试炼每轮 1 页、约 3 轮集齐；集齐三本需改修门径多轮——窗口外余量，防收集提前见底 |

**每轮产出上限 = 3–4 页**（渠道 A×2 + 试炼 ×1 + 商店 ≤1）。按 `cadence.md` §4.1 的基准锚点，3–5 天窗口预期 4–6 轮；18 页结构、窗口内集齐本数与窗口末余量须在 MVP-2B 重新核算，优先调页序 / 页数，不改渠道职责。节奏仍以**轮**为单位设计。

### 3.4 与归隐的关系（核心裁决）

**已获残页与已集齐秘籍全部跨归隐保留，含效果（定稿）。** 理由与约束：

1. **重置非惩罚**：玩家攒下的收集物被没收是最强的惩罚感；初案归隐保留总表本就「图鉴保留」，方向记录 §5.5 的两行选择中，长期目标载体只能挂「保留」行——每轮清零的收集撑不起跨多轮的 3–5 天窗口。
2. **代价与约束**：效果吃永久成长预算，与声望节点同括号加法合并；MVP-2B 重锚须复核「秘籍 + 声望节点」叠加后第二轮提速目标不被击穿（§3.2 锚点即为此封顶）。

### 3.5 与声望经济的衔接：双商品

**定位：商店是补齐渠道（兜底），不是主渠道；残页兑换是声望的长期出口，接住第 4 轮买空平台期**——一次性节点扩池只会再次买空，可复购的兑换才是长期解（`../mvp0/economy.md` §3 的结构性问题）。

| 商品 | 规则 | 上架 |
|---|---|---|
| **指名寻访** | 原价档，自选任意缺页，每轮限 1 次；压轴尾页唯一来源、用独立高价档（价差 MVP-2B 定） | 首发即上 |
| **坊间秘闻**（随机盒） | 折扣档（MVP-2B 定），随机开出一张**必定缺页**的残页、保证不重复；池不含压轴尾页（防高价档被折扣绕过） | 设计定稿，**验证窗口结束后增补上架**——窗口内不加随机干扰，窗口后补开盒乐趣 |

- **防倒挂**：兑换价格须使「打试炼 / 推 Boss 拿页」始终优于「攒声望买页」——商店解决差一页的焦虑，不替代游玩。
- **追加常规声望节点**：按 `../mvp1/spec.md` §2.1 衔接项少量追加，与本方案解耦，单独走经济表增补。

### 3.6 资源三列账与规格化前置检查（方向记录 §5 逐项）

| 检查项 | 落实 |
|---|---|
| 乘区归属 | 跨轮保留 → 遗篇并入永久括号加法合并；真传参数按等效强度计入永久预算；不开第三乘法项 |
| 残页三列账 | 来源 = 三渠道（§3.1）；主消耗 = 集齐成书（自动，无操作成本）；后期出口 = 首发有限池，序列发完渠道自然关闭、商店类目下架——「收齐后残页无出口」以有限池规避，长线出口登记为完整版残卷合成框架的衔接敞口 |
| 随机预算 | 首发获取零随机；坊间秘闻只随机「哪一张缺页」且窗口后上架，不进入验证判定 |
| 归隐处理 | 挂「图鉴保留」行（§3.4） |

### 3.7 江湖行迹（呈现层）

秘籍阁（或门径页）为每条门径展示：累计游玩轮数、真传收集进度、最佳战绩（如最快通关轮次）。**纯读存档统计，零数值、零新资源、零新规则**——目的：改修门径重玩的积累可见，「走过的门径留下痕迹」。

**专精度类数值系统维持停放**：cadence §7 MVP-3 方向表「转生差异不明显 → 传承/永久成长强化」是其条件触发位，本批不做。
