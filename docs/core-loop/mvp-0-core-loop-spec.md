## 1. MVP-0 设计目标

### 1.1 要验证的核心假设

MVP-0 的唯一核心目标是验证以下循环是否成立：

```text
挂机成长 → 卡点 → 调整构筑/资源 → 突破 → 归隐 → 第二轮更快更远
```

玩家此刻应该感到：

1. **刚开始**：我不用复杂操作，也能稳定变强。
2. **遇到卡点**：不是游戏坏了，而是我需要做一个选择。
3. **调整后突破**：我理解了构筑/资源投入带来的差异。
4. **第一次归隐**：我愿意放弃本轮进度，因为下一轮会明显更快。
5. **第二轮**：我能用更少时间越过旧终点，并想试另一个流派或声望点法。

### 1.2 MVP-0 不追求的目标

MVP-0 不验证长期内容量、不验证复杂门派经营、不验证装备收集、不验证终局。只要 30–60 分钟内玩家能完成一轮“卡住—调整—突破—归隐—加速”的闭环，就算完成该阶段的核心任务。

**特别声明——放置节拍是尚未验证的第二核心假设**：MVP-0 是一个 30–60 分钟的**主动**循环验证，完全不包含离线收益与回访节奏。「离线收益 → 回归检查 → 决策投入」的放置节拍是独立假设，MVP-0 通过**不构成**该假设成立的证据（等 2 分钟资源与隔 8 小时回访是两种不同的心理模型），该假设由 MVP-1 的基础离线收益单独验证。

### 1.3 设计支柱

| 支柱 | MVP-0 表达方式 | 判定标准 |
|---|---|---|
| 放置可理解 | 资源自动增长，战斗自动推进 | 玩家无需读长说明也知道“等资源、点升级、再挑战” |
| 卡点有原因 | Boss 用机制标签克制某些构筑 | 玩家能说出“我为什么打不过” |
| 调整有结果 | 构筑选择、武学升级、境界突破影响战斗结果 | 调整后胜率/推进距离明显变化 |
| 归隐值得做 | 重置换永久声望节点 | 第二轮到达旧终点时间缩短约 25%–40% `[待测试]` |
| 范围可实现 | 只做必要系统 | 无弟子、锻造、复杂奇遇、终局等扩展系统 |

## 2. MVP-0 范围

### 2.1 明确包含

| 类别 | MVP-0 范围 | 设计目的 |
|---|---|---|
| 境界 | 5 个境界 | 建立主成长轴和首次归隐门槛 |
| 地图 | 3 张地图 | 提供 30–60 分钟推进目标 |
| Boss | 3 个 Boss | 制造构筑卡点和归隐前目标 |
| 构筑/门派 | 3 条基础路线：华山、少林、唐门 | 验证流派差异与克制关系 |
| 归隐 | 第一次归隐 | 验证 prestige 情绪和第二轮加速 |
| 声望节点 | 6–10 个节点 | 提供少量永久成长与策略选择 |
| 资源 | 基础挂机资源 gain | 验证升级节奏，不做复杂经济 |
| 战斗 | 基础自动战斗 | 验证战斗公式、构筑差异、Boss 卡点 |

### 2.2 MVP-0 资源范围

MVP-0 只建议保留以下最小资源：

| 资源 | 用途 | 来源 | 备注 |
|---|---|---|---|
| 内力 | 升境界、升武学 | 在线挂机、地图战斗少量奖励 | 主资源，决定等待节奏 |
| 银两 | 构筑调整成本、基础强化成本 | 地图战斗、挂机少量产出 | MVP-0 可弱化，不做商店深度；核心 sink 为换路线摩擦成本（见 6.4） |
| 阅历 | 解锁/强化构筑关键节点 | 首通、Boss、地图进度 | 控制构筑选择时机 |
| 声望 | 归隐后永久节点 | 首次归隐 | prestige 资源，不可挂机获得 |

> 药材、丹药、装备材料、残页、荣誉币、门派贡献等全部不进入 MVP-0。

### 2.3 明确不包含

以下系统为 MVP-0 明确范围外，不能因为“顺手”加入：

| 系统 | MVP-0 不做的原因 |
|---|---|
| 弟子系统 | 会引入招募、品质、任务分配、远征收益，干扰核心循环验证 |
| 锻造系统 | 装备词条会显著增加构筑和平衡复杂度 |
| 武林大会 | 排名、镜像、周期奖励不服务首轮 30–60 分钟验证 |
| 复杂遭遇/奇遇 | 文案和分支成本高，且会模糊卡点原因 |
| 完整门派职位阶梯 | 外门到掌门候选过长，MVP-0 只把门派当构筑入口 |
| 终局“破碎虚空” | 属于长期愿景，不参与首次归隐验证 |
| 重度收集/图鉴 | 会把目标从循环验证转向内容收集 |
| 多门派长期声望 | 属于多轮长期系统，MVP-0 只验证一次归隐后的永久节点 |
| 炼丹 | 若需要“突破材料”可先抽象为突破条件，不做炼丹流程 |
| 秘境/爬塔 | MVP-0 暂不做；如核心循环通过，可在 MVP-1 作为额外挑战加入 |
| 复杂离线收益 | MVP-0 可记录离线收益需求，但不让离线自动突破、归隐或拿首通 |

## 3. 核心循环规格

### 3.1 即时体验：0–30 秒

- **行为**：玩家进入页面，看到角色自动修炼并获得内力；点击“提升境界/挑战地图”。
- **反馈**：内力数字增长、进度条推进、自动战斗日志滚动、胜负结果立即出现。
- **奖励**：角色属性提升、地图进度增加、解锁下一项操作。
- **玩家决策**：先升境界，还是先强化当前武学。

### 3.2 单次会话循环：5–30 分钟

```text
挂机获得内力/银两 → 升境界或武学 → 自动挑战地图 → 遇到 Boss 卡点 → 选择构筑强化方向 → 突破卡点 → 解锁下一地图/境界
```

- **紧张感来源**：Boss 战打不过，且原因与构筑短板有关。
- **可调整项**：境界、武学等级、流派选择、声望节点（第二轮后）。
- **胜利状态**：击败当前地图 Boss，进入下一地图或达到归隐条件。
- **失败状态**：挑战失败后停留在当前地图，继续挂机并提示可调整项。

### 3.3 长期循环：30–60 分钟与第二轮

```text
第一轮推进到境界 5 / 击败第 3 Boss → 开启首次归隐 → 获得声望 → 点 1–2 个永久节点 → 第二轮用更短时间超过第一轮终点
```

- **成长**：声望节点提供永久效率或构筑机制小幅提前。
- **留存钩子**：第二轮明显更快；玩家想尝试另一构筑或不同声望节点。
- **成功感**：旧 Boss 从“硬卡点”变成“可更早击败的目标”。

## 4. 首 30–60 分钟玩家体验时间线

> 时间为纸面目标，不是最终平衡值。所有时间均标记为 `[待测试]`，后续由模拟表与实测校准。

| 时间 | 玩家状态 | 系统状态 | 预期决策 | 设计意图 |
|---|---|---|---|---|
| 0–2 分钟 | 江湖新丁，只有基础修炼 | 内力自动增长，基础攻击可挑战小怪 | 点击升级/挑战 | 让玩家理解“挂机也在变强” |
| 2–5 分钟 | 进入地图 1：村外小径 | 普通敌人可自动击败 | 选择优先升境界还是升基础武学 | 建立第一层资源投入选择 |
| 5–8 分钟 | 达到境界 2：初窥门径 | 解锁 3 条构筑路线入口 | 选择华山/少林/唐门之一 | 让玩家第一次表达玩法偏好 |
| 8–12 分钟 | 构筑开始生效 | 获得 1 个核心机制：暴击/护盾反伤/毒 | 决定强化主武学还是继续冲境界 | 让构筑不只是名字，而是战斗表现 |
| 12–18 分钟 | 地图 1 Boss 前后 | Boss 1 检查基础战力 | 若失败，升级武学或境界 | 第一次轻卡点，不能太硬 |
| 18–28 分钟 | 进入地图 2：洛阳近郊 | 敌人出现机制标签 | 判断自己的构筑顺不顺 | 开始让流派差异显现 |
| 25–35 分钟 | 境界 3–4 | Boss 2 成为首个硬瓶颈 | 调整资源投入；可能意识到构筑克制关系 | 验证“卡点 → 调整”的核心 |
| 35–50 分钟 | 进入地图 3：华山古道 | 已形成基础流派 | 冲击境界 5 与 Boss 3 | 形成第一轮终点目标 |
| 45–60 分钟 | 击败 Boss 3 或达到境界 5 | 首次归隐按钮出现 | 选择立即归隐或继续刷少量声望修正 | 验证玩家是否愿意重置 |
| 第二轮前 15–25 分钟 | 带 1–2 个声望节点重开 | 资源/战斗效率提高 | 更快到地图 2/3，尝试新构筑或强化旧构筑 | 验证“更快更远” |

### 4.1 关键体验要求

1. **第一次构筑选择不能晚于 8 分钟 `[待测试]`**：否则玩家只是在看数字。
2. **第一次硬瓶颈建议出现在 25–35 分钟 `[待测试]`**：太早会挫败，太晚无法验证调整。
3. **首次归隐应在 45–60 分钟可达 `[待测试]`**：用于快速验证 prestige 情绪。
4. **第二轮到达第一轮 Boss 2 的时间应缩短 25%–40% `[待测试]`**：必须可感知，但不能直接跳过全部内容。

## 5. MVP-0 三条构筑路线

### 5.1 构筑总表

| 构筑路线 | 核心幻想 | 核心机制 | 强项 | 弱项 | 应克制敌人 | 应吃力敌人 |
|---|---|---|---|---|---|---|
| 华山剑暴击流 | 快剑出鞘，一剑定胜负 | 暴击、剑意、爆发技 | 清小怪快、打低防/狂暴敌强 | 怕高闪、反伤、长战不稳定 | 低防敌、狂暴倒计时敌 | 高闪敌、反伤敌 |
| 少林金钟反伤流 | 金钟护体，以守为攻 | 护盾、减伤、受击反伤 | 打高攻 Boss 稳、容错高 | 推图慢、怕毒/破甲 | 高攻 Boss、多段攻击敌 | 毒敌、破甲敌 |
| 唐门毒暗器流 | 先手下毒，拖入死亡节奏 | 先手叠毒、毒伤无视防御、层数爆发 | 越级打高防敌、长战强 | 短战慢、怕净化/毒抗 | 高防敌、低净化 Boss | 净化敌、毒抗敌、短时限敌 |

### 5.2 华山剑暴击流

**目的**：验证爆发型构筑是否能提供“推进快但不稳定”的体验。  
**玩家幻想**：玩家应该感到自己像快剑高手，普通敌人经常被瞬间击败。  

| 字段 | 规格 |
|---|---|
| 输入 | 玩家选择华山路线，投入内力/阅历强化剑法 |
| 输出 | 提高暴击率、暴击伤害或获得“剑意”层数 |
| 核心机制 | 开战首击必定暴击；暴击时获得剑意；剑意满后自动释放一次高倍率剑招 `[待测试]` |
| 成功表现 | 打低防小怪速度明显快；面对狂暴倒计时 Boss 有优势 |
| 失败状态 | 连续未命中/未暴击导致输出波动；打反伤敌时可能被自己爆发反噬 |
| 边界情况 | 暴击率不能轻易堆到 100%；剑意爆发不能绕过所有 Boss 机制 |
| 调节杠杆 | 暴击率、暴击倍率、剑意层数需求、爆发技倍率、命中惩罚 |
| 依赖 | 自动战斗、命中/闪避、暴击公式、敌人反伤标签 |

### 5.3 少林金钟反伤流

**目的**：验证防守型构筑是否能提供“慢但稳”的差异体验。  
**玩家幻想**：玩家应该感到自己像横练高手，Boss 打不动我，反而被慢慢震伤。  

| 字段 | 规格 |
|---|---|
| 输入 | 玩家选择少林路线，投入内力/阅历强化金钟与体魄 |
| 输出 | 提高气血、防御、护盾、反伤或低血减伤 |
| 核心机制 | 战斗开始获得护盾；受到攻击时按伤害或防御比例反伤 `[待测试]` |
| 成功表现 | 面对高攻 Boss 存活更久，靠反伤稳定过关 |
| 失败状态 | 清怪效率低；被毒或破甲绕过防御时表现下降 |
| 边界情况 | 反伤不能无限循环触发（单向截断规则见 7.2）；护盾与减伤结算顺序已在 7.2 锁定，数值由公式表定义 |
| 调节杠杆 | 护盾值、减伤比例、反伤比例、低血触发阈值、战斗时长上限 |
| 依赖 | 自动战斗、防御减伤、护盾、反伤、毒/破甲状态 |

### 5.4 唐门毒暗器流

**目的**：验证持续伤害型构筑是否能通过机制克制高防敌。  
**玩家幻想**：玩家应该感到自己先发制人，不和敌人硬拼，而是让敌人在毒层中崩溃。  

| 字段 | 规格 |
|---|---|
| 输入 | 玩家选择唐门路线，投入内力/阅历强化毒与暗器 |
| 输出 | 开战叠毒、毒伤无视防御、毒层数达到阈值后爆发 |
| 核心机制 | 先手施毒；普攻伤害偏低（轻手暗器，毒是主伤）；每回合结算毒伤；毒层数满触发一次毒爆 `[待测试]` |
| 成功表现 | 面对高防低净化敌人时，比华山/少林更容易越级通过 |
| 失败状态 | 面对净化或毒抗敌人伤害大幅下降；短战爆发不如华山 |
| 边界情况 | 毒伤规则已在 7.2 锁定（不受防御减免、不可暴击、不触发反伤），系数与层数上限由公式表定义 |
| 调节杠杆 | 初始毒层、每回合叠层、毒伤系数、毒爆阈值、毒抗（「部分穿防」为完整版预留形态，MVP-0 统一为完全无视防御） |
| 依赖 | 状态效果系统、防御公式、敌人净化/毒抗标签 |

## 6. 第一轮进度结构

### 6.1 五个境界

MVP-0 使用完整愿景中的前 5 个境界，暂不开放更高境界。

| 境界序号 | 境界名 | 设计作用 | 解锁/卡点 |
|---:|---|---|---|
| 1 | 江湖新丁 | 新手起点，理解挂机资源 | 基础修炼、地图 1 普通敌 |
| 2 | 初窥门径 | 第一次选择构筑 | 解锁华山/少林/唐门三路线 |
| 3 | 小有所成 | 构筑开始明显分化 | 解锁路线核心机制的第 1 档强化 |
| 4 | 炉火纯青 | 首个硬瓶颈前准备 | Boss 2 对构筑提出要求 |
| 5 | 一流高手 | 第一轮终点与归隐门槛 | 击败 Boss 3 后可归隐 |

> **门槛语义说明**：境界 5 不是「大后期」，而是首轮的**终点线**——MVP-0 的全部内容就是一轮完整体验，首次归隐门槛设在内容边缘（最高境界 + 最终 Boss）是刻意设计：(a) 保证每个测试者经历相同的完整节拍（Boss 2 硬卡点 → 调整 → Boss 3 冲线 → 归隐）；(b) 让第二轮「更快到达旧终点」有无歧义的度量原点。若把门槛降到境界 4，境界 5 与地图 3 后半段会变成门槛之外的冗余内容，浪费本就极小的内容量。境界间隔随进度拉长后（境界 2 约 5–8 分钟、境界 5 约 45–60 分钟），两次突破之间的奖励节拍由武学升级与地图关卡推进承接，不允许出现超过 5 分钟 `[待测试]` 无任何可见进展的空窗。为落实该要求，**境界突破采用充能式**：突破消耗分 5 段注入，每段注满是一次可见进展反馈，注满后手动点击突破（最长充能段耗时须 ≤ 5 分钟，校验见公式表 §3.3）。

### 6.2 三张地图

| 地图 | 解锁条件 | 敌人功能 | Boss | 设计目的 |
|---|---|---|---|---|
| 地图 1：村外小径 | 初始 | 低防、低机制，验证基础战斗 | Boss 1：山贼头目 | 轻卡点，教会升级与强化 |
| 地图 2：洛阳近郊 | 击败 Boss 1 或境界 3 `[待测试]` | 开始出现高防/高闪/高攻标签 | Boss 2：铁掌恶僧 | 首个硬瓶颈，要求构筑理解 |
| 地图 3：华山古道 | 击败 Boss 2 或境界 4 `[待测试]` | 组合机制敌人，验证路线优劣 | Boss 3：黑风寨主 | 第一轮终点，归隐触发条件之一 |

> **绕过路径校验**：「击败 Boss 或达到境界」的双解锁条件允许玩家纯堆境界绕过 Boss 推图。允许保留该设计作为软出路，但内容表必须校验：绕过路径的耗时严格大于击败 Boss 的耗时 `[待测试]`，且绕过者会损失 Boss 首通的阅历收入，防止「卡点 → 调整」的验证被旁路。

#### 地图内部结构（锁定）

- **每张地图由 8–12 个 `[待测试]` 线性排列的关卡节点组成**，末位节点为该图 Boss；地图 2/3 中每隔 3–4 个节点 `[待测试]` 设一个携带机制标签的精英节点。
- **每个关卡节点 = 一场 1v1 自动战斗**。MVP-0 无多怪同场，不需要群攻机制。
- **关卡内敌人强度沿节点序号温和递增** `[待测试]`，同图内不出现断崖；断崖式检查只属于 Boss。
- **推进方式为「自动连战」开关**：开启后自动逐关挑战，胜利进入下一关，失败自动停在该关并给出失败提示（见 7.5），等待玩家调整；关闭则手动逐关。玩家不做选怪操作。
- **已通关卡可手动回刷**获取少量资源，但回刷收益递减 `[待测试]`，防止原地刷爆绕过推进压力；挂机修炼（内力主来源，见 2.2）与地图战斗是并行的两条产出，回刷不是主要资源途径。

### 6.3 三个 Boss 的卡点职责

| Boss | 预期出现时间 | 机制标签 | 应测试的玩家决策 | 失败提示方向 |
|---|---:|---|---|---|
| 山贼头目 | 12–18 分钟 `[待测试]` | 基础高血量 | 是否会升级境界/武学 | “内力不足时先修炼，或提升主武学。” |
| 铁掌恶僧 | 25–35 分钟 `[待测试]` | 高防 + 高攻 | 是否理解自己流派的解法 | 华山需爆发/命中，少林需护盾，唐门可用毒穿防 |
| 黑风寨主 | 45–60 分钟 `[待测试]` | 纯数值检查：高气血 + 温和狂暴（第 N 回合起攻击逐回合递增 `[待测试]`），对三路线压力均等 | 是否完成构筑成型与境界 5 | 提示归隐即将开启，继续强化可提高首轮声望 |

> **门槛 Boss 设计守则**：强制进度门槛上的 Boss（Boss 3 是首次归隐的必经门槛）**只做数值检查，不使用反伤/净化/毒抗/高闪等硬克制机制**。原设想的「反伤/净化/狂暴三选一」被否决：反伤硬克华山、净化硬克唐门、长战狂暴压制少林——无论选哪个，约 1/3 玩家都会在唯一核心验证目标（首次归隐完成率 > 80%）门前撞上克制自己的机制墙，且此时既无声望节点可用，测试结果会被误读为「prestige 循环不成立」。机制克制的教学职责全部由 Boss 2 与地图 2/3 的精英敌人承担；硬克制标签只允许出现在可绕过的普通/精英敌人身上。温和狂暴同时充当战斗时长软上限，对三路线的约束是对称的。

### 6.4 构筑选择解锁时机

- **境界 1**：不让玩家选择复杂路线，只提供基础武学。
- **境界 2，约 5–8 分钟 `[待测试]`**：解锁三路线选择。
- **选择后立即获得**：1 个路线标识机制，不等待太久。
  - 华山：基础暴击/剑意。
  - 少林：基础护盾/反伤。
  - 唐门：基础叠毒/毒伤。
- **MVP-0 是否允许换路线**：允许。规则锁定如下：
  - **已投入原路线的阅历 100% 返还**。阅历来源是一次性的首通/Boss/进度奖励，不可再生；若不返还，换线玩家在本轮永久变穷，「切换路线」这一 6.5 认可的合法解法就变成陷阱。
  - **摩擦成本只收银两**（金额 `[待测试]`），防止无成本反复全吃三路线；这也是 MVP-0 中银两唯一的核心 sink（见 2.2）。
  - 原路线武学等级重置，新路线从头强化。
- **武学等级上限 = 当前境界 × 2**（境界 2 → 4 级 …… 境界 5 → 10 级）。理由：(a) 制造「境界 vs 武学」的真实互锁，堆满武学后境界是唯一出路；(b) 防止越级击破终局——无上限时唐门可在境界 4 满级武学击杀 Boss 3，随后被迫纯等待境界 5 超过 15 分钟（模拟实测），产生归隐前的体验死区。

### 6.5 首个硬瓶颈

- **位置**：地图 2 Boss「铁掌恶僧」。
- **目标时间**：25–35 分钟 `[待测试]`。
- **设计目的**：让玩家第一次明确感到“只等资源也许能过，但调整投入方向更快”。
- **允许的解法**：
  1. 提升境界到 4。
  2. 强化主构筑武学。
  3. 切换路线或调整强化方向。
  4. 第二轮使用声望节点提前突破。
- **不允许的解法**：通过复杂系统绕过，如装备词条、丹药、弟子、奇遇。

### 6.6 首次归隐开放时机

首次归隐在满足以下条件后开放：

```text
达到境界 5：一流高手
并击败 Boss 3：黑风寨主
```

**完成率保底（规则锁定）**：达到境界 5 后，若 Boss 3 连续失败 ≥ N 次（N = 3–5 `[待测试]`）或停滞超过 X 分钟（X = 10–15 `[待测试]`），开放「低收益归隐」：声望按标准值打折（50%–70% `[待测试]`），UI 明确提示「击败黑风寨主可获得全额声望」。首次引导仍指向击败 Boss 3，保底仅为兜住完成率 > 80% 的目标——门槛设在内容边缘意味着任何打不过 Boss 3 的玩家会被彻底卡死在归隐门外，没有保底就没有闭环可言。

> **勿向完整版外推**：MVP-0 的「境界 5 + Boss 3」双条件与「3 图消耗 5 境界」的配比是 60 分钟原型的**压缩设计**（门槛 = 内容边缘 = 终点线），不代表完整版结构。完整版的归隐门槛用推关里程碑而非境界序号、首次归隐后门槛常驻不再上升、首轮内容只占总内容 20%–30%，见初案「四、归隐触发条件与门槛结构」与「七、地图×境界配比原则」。

## 7. 基础自动战斗规格

### 7.1 战斗形式（模型锁定）

- 战斗自动进行，玩家不需要实时操作。
- **战斗模型锁定为固定回合制**：每回合玩家先行动、敌人后行动。这是设计决策而非实现细节——回合制直接定义了先手、毒结算、狂暴递增、战斗时长上限的全部语义，不下放给公式表。
- **MVP-0 不引入速度/行动条属性**。「先手」不依赖速度属性：唐门的先手实现为第 0 回合（开战瞬间）施加初始毒层 `[待测试]`。若测试证明需要速度轴，MVP-1 再评估。
- **武学释放形态锁定：自动触发式，战斗内无手动技能按钮**。三路线核心机制均由条件自动触发：华山剑意满自动释放爆发剑招、少林开战自动生成护盾且受击自动反伤、唐门第 0 回合自动施毒且层满自动毒爆。理由：(a) 手动释放违反「放置可理解」支柱与「玩家不需要实时操作」的前提；(b) 会把构筑差异的验证污染成操作水平差异；(c) 增加实现成本却不服务核心假设。玩家的全部决策发生在**战斗外**（选路线、升武学、升境界、换路线）；武学等级提升改变的是触发参数（倍率、层数需求、触发频率），不改变触发方式。
- **技能触发必须在战斗日志与演出中高亮**（触发时刻、伤害占比、状态图标），这是「调整有结果」支柱的反馈载体——玩家要能看见「升级武学后剑意爆发变多/毒爆提前」。战斗观赏性由触发演出承担，不靠操作。
- 数值公式（伤害、减伤、命中率等）由后续《公式表》定义，但**结算顺序与状态规则以 7.2 为准**。
- 每次挑战输出简短战斗日志：伤害、暴击、护盾、毒、失败原因。
- **重挑战节奏**：Boss 失败后可免费立即重试，但单场战斗有 15–30 秒 `[待测试]` 不可跳过的演出时长，用时间成本形成「继续等资源 vs 调整构筑」的真实权衡，防止无脑连点碾过卡点。

### 7.2 属性白名单与状态效果（锁定）

#### 属性白名单

MVP-0 玩家与敌人共用以下 7 项属性，**禁止新增**：

| 属性 | 说明 |
|---|---|
| 气血 | 生命值 |
| 攻击 | 基础伤害来源 |
| 防御 | 减伤来源，减伤公式由公式表定义 |
| 命中 | 对抗闪避 |
| 闪避 | 「高闪」敌人标签的载体 |
| 暴击率 | 华山核心 |
| 暴击伤害 | 华山核心 |

> 破甲、穿防、毒抗、净化等**不是属性**，而是状态效果或敌人标签的参数，见下表。

#### 状态效果清单

MVP-0 共 6 种状态效果，**禁止新增**。规则方向在此锁定，数值全部 `[待测试]` 由公式表给出：

| 状态 | 主要载体 | 结算时机 | 规则（方向锁定） |
|---|---|---|---|
| 护盾 | 少林、部分敌人 | 受击时先于气血扣除 | 战斗开始生成；耗尽后不再生（MVP-0 不做护盾回复） |
| 反伤 | 少林、反伤敌 | 每次受击结算后触发 | 反伤值按所受攻击的**减免后、护盾吸收前**伤害 × 反伤比例计算；可被攻击方护盾吸收，但**不再触发新的反伤**（单向截断，杜绝无限循环）；反伤不可暴击 |
| 毒（叠层） | 唐门、毒敌 | 每回合结束结算 | 毒伤**不受防御减免、绕过护盾直扣气血、不可暴击、不触发反伤**（毒入肌理，金钟不防——「少林怕毒」成立的前提）；层数有上限；层满触发一次毒爆后清层 |
| 净化 | 敌人标签 | 敌方每 N 回合行动时触发 | 清除自身全部毒层（或固定层数，二选一由公式表定） |
| 破甲 | 敌人标签、唐门参数 | 命中时施加 | 按比例削减目标防御，可叠层，有层数上限 |
| 狂暴 | 敌人标签（含 Boss 3 温和版） | 第 N 回合起每回合触发 | 攻击逐回合递增；作为战斗时长的软上限，约束无限拖长的构筑 |

#### 结算顺序（锁定）

```text
1. 行动方出手：命中判定 → 暴击判定 → 防御减免 → 护盾吸收 → 气血扣除
2. 受击方反伤（若有）：跳过命中/暴击判定 → 攻击方护盾吸收 → 攻击方气血扣除；
   反伤伤害不触发新的反伤
3. 回合结束：毒结算 → 狂暴/净化等回合型标签结算
```

### 7.3 战斗输入

| 输入 | 来源 |
|---|---|
| 玩家境界属性 | 境界等级 |
| 主构筑机制 | 华山/少林/唐门选择 |
| 武学等级 | 内力/阅历投入 |
| 敌人属性与标签 | 地图与敌人表 |

### 7.4 战斗输出

| 输出 | 用途 |
|---|---|
| 胜利/失败 | 推进地图或停留卡点 |
| 战斗耗时/剩余血量 | 判断是否“险胜”或“碾压” |
| 资源奖励 | 给少量内力/银两/阅历 |
| 首通标记 | 解锁地图、Boss、归隐条件 |

### 7.5 失败状态

战斗失败不是惩罚，而是反馈。失败后应显示 1–2 条方向提示：

- “你的命中不足，华山暴击流面对高闪敌人不稳定。”
- “敌人破甲较高，少林防御收益被削弱。”
- “敌人净化了毒层，唐门需要更高叠毒速度或换目标。”
- “当前境界偏低，继续修炼可提高基础属性。”

提示的触发条件（何种战斗数据触发哪条提示，如「命中率 < X% 且总输出达标 → 提示 1」）由《公式表》附带的**失败提示诊断规则**定义，见 §12 交付物清单。

## 8. 首次归隐规则规格

### 8.1 归隐目的

归隐不是失败重开，而是武侠包装下的 prestige：玩家放弃本轮江湖身份，把本轮成就转化为永久声望，使下一轮更快、更远或更有策略选择。

玩家此刻应该感到：

> “我这一轮已经走到瓶颈了。归隐后虽然从头开始，但我会带着江湖名望回来。”

### 8.2 触发条件

MVP-0 标准触发条件：

```text
首次归隐 = 达到境界 5 + 击败地图 3 Boss
```

补充规则 `[待测试]`：

| 情况 | 规则建议 |
|---|---|
| 玩家达到境界 5 但未击败 Boss 3 | 满足触发条件后开放低收益归隐（连败/停滞触发与声望折扣见 6.6 完成率保底） |
| 玩家过早想归隐 | MVP-0 不支持早归隐，避免刷短轮套利 |
| 玩家继续强化不归隐 | 允许，但声望额外收益必须有软上限，防止刷爆 |

### 8.3 重置与保留

| 类别 | 归隐后处理 | 设计意图 |
|---|---|---|
| 当前境界 | 重置到境界 1 | 保留重入江湖节奏 |
| 当前地图进度 | 重置到地图 1 | 让第二轮可验证加速 |
| 当前武学等级 | 重置 | 避免直接跳过构筑成长 |
| 当前构筑选择 | 重置，可重新选择 | 支持第二轮尝试不同路线 |
| 内力 | 清空或保留极少比例 `[待测试]` | 防止开局跳级 |
| 银两 | 清空或保留极少比例 `[待测试]` | 防止经济绕过 |
| 阅历 | 清空或保留首通解锁记录 `[待测试]` | MVP-0 建议清空数值，保留教程认知 |
| 声望 | 保留 | prestige 主资源 |
| 已购买声望节点 | 保留 | 永久成长反馈 |
| Boss 首次击败记录 | 可保留为统计，不提供重复首通奖励 | 防刷和记录成就 |
| 门派长期声望 | MVP-0 无此系统 | 避免扩展 |
| 装备/弟子/锻造/图鉴 | MVP-0 无此系统 | 避免扩展 |

### 8.4 声望奖励意图

MVP-0 不锁定最终数值，但必须遵守以下原则：

1. **主来源是最高进度**：境界 5 + Boss 3 是首次声望的主要依据。
2. **额外收益有上限**：多花时间强化不应让首次声望翻倍。
3. **避免短轮套利**：未达归隐门槛不给或极低给声望。
4. **首次归隐至少能购买 1 个节点**：否则玩家感受不到永久成长。
5. **首次归隐最多购买 2 个左右节点 `[待测试]`**：避免第二轮过度加速。

建议占位表达：

```text
首次归隐声望 = 基础声望(境界 5 + Boss 3) + 少量表现奖励
表现奖励范围 = 基础声望的 0%–30% [待测试]
首次可购买节点数 = 1–2 个 [待测试]
```

### 8.5 第二轮加速目标

MVP-0 必须验证第二轮加速，但不能让第二轮直接跳过所有卡点。

| 指标 | 目标范围 |
|---|---|
| 第二轮到达境界 2 | 比第一轮快 30%–50% `[待测试]` |
| 第二轮击败 Boss 1 | 比第一轮快 25%–40% `[待测试]` |
| 第二轮抵达 Boss 2 | 比第一轮快 25%–40% `[待测试]` |
| 第二轮击败 Boss 3 | 可以更快，但仍需至少一次构筑/资源决策 |

### 8.6 归隐流程与结算呈现（设计要求，非实现细节）

prestige 情绪是 MVP-0 的头号验证假设，归隐时刻的**呈现本身就是设计**：玩家若在信息不全时点下归隐、事后发现损失超预期，成功标准 4「不认为重置是惩罚」会因流程而非系统失败。以下为硬性要求：

1. **归隐预览**：确认前强制展示三栏对照——
   - 「你将获得」：声望预估及其来源明细（境界 5 / Boss 3 / 表现奖励）；
   - 「你将失去」：境界、地图进度、武学等级、资源清单；
   - 「你将保留」：声望、已购节点、首通记录。
   玩家必须在信息完整的前提下做决定。
2. **二次确认**：预览之后需要一次明确的二次确认操作，不可单击直达。
3. **结算演出**：声望入账要有可感知的正反馈演出，并给出本轮总结（如「你的第一段江湖：击败了 X 个强敌，走到了华山古道」），把峰终时刻做成庆典而非表单。
4. **落地引导**：结算后直接打开声望节点界面，引导完成首次购买，让「永久变强」在归隐后 30 秒内被兑现。

## 9. MVP-0 声望节点方向

### 9.1 节点设计原则

- 总数控制在 **6–10 个**。
- 效率加成使用加法合并，不设计多个独立乘区。**「加法合并」的准确含义**：作用于**同一最终量**（如内力获取速率）的所有节点效果加法合并为一个乘区；作用于不同最终量的节点（如获取提速 vs 突破消耗降低）不出现在同一公式里、不构成乘区问题，但会**复合**成实际进度加速（收益 ↑ × 消耗 ↓），节点预算必须按 8.5 第二轮加速目标（25%–40%）的复合结果校验，而非各节点面值相加。
- 至少包含 2–3 个“策略/解锁类”节点，避免全是 +10%。
- 首轮后只能买少量节点，第二轮仍需体验主循环。
- **不设路线专属死节点**：任何与构筑路线相关的节点必须跟随「当前所选路线」生效，换路线不作废。

### 9.2 候选节点池

以下为规格级候选，不是最终数值表：

| 节点 | 类型 | 效果意图 | 调参占位 |
|---|---|---|---|
| 旧梦重温 | 效率 | 内力获取提高 | +10%–20% `[待测试]` |
| 江湖熟路 | 效率 | 地图普通战斗奖励提高 | +10%–20% `[待测试]` |
| 破关心得 | 战斗 | 对 Boss 伤害或生存小幅提升 | +5%–15% `[待测试]` |
| 快速入门 | 节奏 | 境界 2 与境界 3 突破消耗降低 | −30%（定稿，理由见《声望经济表》§2.2） |
| 师门指引 | 策略 | **当前所选路线**的核心机制略提前获得/略增强，跟随本轮路线生效，换路线不作废 | 不改变终局上限 `[待测试]` |
| 再入江湖 | 解锁 | 第二轮构筑选择提示更明确，或可预览敌人标签 | 以信息优势为主 `[待测试]` |
| 轻装上路 | 策略 | 每轮第一次换路线免银两摩擦费 | 替代原「留名乡野」——1%–3% 银两约束下原节点买不到任何东西，约束保留、节点废弃（见《声望经济表》§2.1） |
| 武道笔记 | 资源 | 开局获得少量阅历 | 只够提前一次小强化 `[待测试]` |

> 节点定稿（8 个，含价格与购买路径）见 `mvp-0-reputation-economy.md`，该表为唯一权威；本节保留为候选池记录。
>
> **节点合并说明**：原设想的三个路线专属节点（剑路传闻/金钟余韵/毒谱残记）已合并为通用的「师门指引」。理由：首轮只能购买 1–2 个节点，而第二轮的留存钩子恰恰是「试另一条路线」——路线专属节点会在换线后变成死节点，在样本只有 1–2 次购买机会时，一个死节点就是 50%–100% 的浪费感，损失厌恶会直接反噬第二轮意愿。

## 10. MVP-0 成功与失败标准

### 10.1 设计验证成功

若测试中出现以下结果，可认为 MVP-0 核心方向成立：

1. **玩家能在无设计师口头指导下完成首次归隐**，目标完成率 > 80% `[待测试]`。
2. **玩家能描述至少一个卡点原因**，例如“这个 Boss 防太高，所以唐门更好”。
3. **玩家在 Boss 2 或 Boss 3 前做过至少一次有意义调整**，如强化武学、突破境界、换路线。
4. **第一次归隐后，玩家愿意开始第二轮**，而不是认为重置是在惩罚自己。
5. **第二轮明显更快**，玩家能感知永久节点带来的差异。
6. **三流派至少各有一个优势场景**，没有出现唯一最优路线碾压全部内容。

> **测试注**：完整验证包含两轮，约 90–120 分钟。招募时需注明测试形式（有偿/陪同）与时长预算；「完成率 > 80%」只统计完成两轮时长预算的测试者，避免中途脱落（时间原因而非设计原因）污染数据。本节各指标的采集事件与计算口径见《埋点与度量规格》（`mvp-0-telemetry-spec.md`），样本量、判定档位、招募与访谈提纲见《测试执行方案》（`mvp-0-playtest-plan.md`）。

### 10.2 设计验证失败

若出现以下任一情况，应优先调整 MVP-0，而不是继续扩系统：

| 失败现象 | 可能原因 | 处理方向 |
|---|---|---|
| 玩家只是在等内力，不做选择 | 卡点机制不清，构筑差异弱 | 强化 Boss 标签与失败提示 |
| 玩家不知道为什么打不过 | 战斗反馈不足 | 增加战斗摘要和失败建议 |
| 三流派体验差不多 | 核心机制只是数值加成 | 拉开暴击/反伤/毒的胜利条件 |
| 华山或某路线永远最优 | 敌人克制矩阵不足 | 增加高闪、反伤、净化、破甲等约束 |
| 归隐像惩罚 | 首次声望奖励太弱或说明不清 | 保证首轮至少买 1 个可感知节点 |
| 第二轮过快跳过全部内容 | 声望加成过强或乘区过多 | 改为加法收益，降低开局继承 |
| 首次归隐超过 90 分钟仍不可达 | 曲线太慢 | 降低前 5 境界消耗或 Boss 3 强度 |
| 30 分钟内已经无事可做 | 曲线太快或内容不足 | 提高 Boss 2/3 检查强度，但不加新系统 |

### 10.3 MVP-0 不用验证的指标

- 7 日留存。
- 商业化转化。
- 大量内容消耗速度。
- 长期多门派声望。
- 破碎虚空终局目标。
- 大规模图鉴收集。
- **放置/离线节拍**（离线收益—回归检查—决策投入）：独立假设，归属 MVP-1 单独验证（见 1.2 特别声明）。

## 11. 实现与内容规划备注

### 11.1 设计与实现分离

本文定义的是玩家体验和系统规则。具体数据结构、前端组件、后端存储、战斗循环实现方式由工程规划决定。工程实现只需保证以下设计结果：

1. 资源可自动增长。
2. 玩家能投入资源提升境界/武学。
3. 自动战斗能根据构筑机制产生不同结果。
4. Boss 失败能给出原因反馈。
5. 归隐能重置/保留指定内容。
6. 声望节点能影响第二轮节奏。

### 11.2 MVP-1/MVP-2 短 note

MVP-0 验证通过后，才考虑 MVP-1 加入简单炼丹、基础离线收益或一个小型秘境；MVP-2 再考虑图鉴、奇遇、门派长期声望等长期内容。MVP-0 阶段不要为未来系统提前增加复杂实现。

## 13. MVP-0 一句话验收标准

如果玩家在 30–60 分钟内经历了“我变强了 → 我卡住了 → 我调整后过了 → 我归隐了 → 我第二轮更快了”，并且愿意再试一次不同路线，那么 MVP-0 成立；否则不要扩系统，先修核心循环。
