## 1. 基础战斗公式

### 1.1 命中判定

```text
命中率 = clamp( 攻方命中 / (攻方命中 + 守方闪避), 30%, 100% )
```

- 下限 30%：保证任何战斗都有伤害产出，高闪敌是「减益」不是「免疫」。
- 高闪精英（闪避 50）对玩家命中 113 → 命中率 ≈ 69%，华山的暴击期望被显著稀释——这就是「华山怕高闪」的数值实现。

### 1.2 暴击判定

```text
暴击判定在命中之后独立掷骰：
最终伤害倍率 = 暴击 ? 暴击伤害 : 100%
基础暴击率 5%，基础暴击伤害 150%
```

### 1.3 伤害与防御减免（形态锁定：除法/双曲）

```text
单次攻击伤害 = 攻击 × 暴击倍率 × 减伤系数(守方防御)
减伤系数(DEF) = 100 / (100 + DEF)      ← K = 100
最低伤害 = 1
```

**为什么选除法（双曲）而不是减法（攻击 − 防御）**：

1. 境界基础曲线是指数型（×1.7/境界），减法公式在指数曲线下极度敏感——防御略高即伤害归零、略低即防御无意义，会出现「高防敌对华山 0 伤害」的硬墙，违反门槛 Boss 守则与「Boss 2 各路线均可调整通过」的要求。
2. 双曲公式伤害永不为 0、收益平滑递减，DEF = 100 时恰好减伤 50%，调参直觉清晰。
3. 唐门「毒无视防御」的对比价值有稳定的数学意义：对 Boss 2（DEF 55）毒伤相对普攻放大 1.55 倍——克制关系是连续可调的量，不是开关。

### 1.4 回合结构与结算顺序

固定回合制，每回合玩家先行动、敌人后行动（规格书 §7.1）。结算顺序按规格书 §7.2：

```text
1. 行动方出手：命中判定 → 暴击判定 → 防御减免 → 护盾吸收 → 气血扣除
2. 受击方反伤（若有）：按「减免后、护盾吸收前」的伤害 × 反伤比例，
   跳过命中/暴击判定 → 攻击方护盾吸收 → 攻击方气血扣除；不再触发新的反伤
3. 回合结束：毒结算（绕过护盾）→ 狂暴/净化等回合型标签结算
4. 回合上限 50：达到上限战斗判负（失败提示走「输出不足」分支）
```

## 2. 六状态效果数值表

| 状态 | 数值形态（实现值） | 备注 |
|---|---|---|
| 护盾 | 战斗开始生成，护盾值 = 气血上限 × 护盾系数（少林基础 30%）；耗尽不再生 | 通用吸收层，先于气血扣除 |
| 反伤 | 反伤值 = 所受攻击伤害（减免后、吸收前）× 反伤比例；不可暴击、不触发新反伤；可被攻击方护盾吸收 | 少林基础 25%；反伤敌 30% |
| 毒（叠层） | 每层毒伤 = 施毒方攻击 × 毒伤系数（唐门基础 12%）；回合结束结算；**无视防御、绕过护盾**、不可暴击、不触发反伤；层数上限 8；层满触发毒爆 = 上限层数 × 攻击 × 毒爆系数（基础 50%）后清层 | 敌方毒（五毒散人）：每层 = 敌攻击 × 8%，每次命中 +1 层，上限 5 层 |
| 净化 | 敌方每 3 个己方回合行动后清空自身全部毒层 | MVP-0 敌方专属 |
| 破甲 | 命中时施加 1 层，每层削减目标防御 15%，上限 3 层，战斗内不消退 | MVP-0 敌方专属 |
| 狂暴 | 第 13 回合起，攻击每回合 +8%（复利前值累加：第 n 回合攻击 = 基础 × (1 + 8% × (n − 12))） | Boss 3 携带；是战斗时长软上限 |

> **毒与护盾/防御的规则说明**：毒伤无视防御且绕过护盾（毒入肌理，金钟不防）——这是「少林怕毒」在数值上成立的前提，也是本次产表对规格书 §7.2 的补充修订（见规格书 v0.5 变更日志）。

## 3. 玩家侧公式

### 3.1 境界基础属性（指数曲线）

```text
气血/攻击/防御：每境界 × 1.7（对齐初案「境界基础成长为超线性/指数型」）
命中：每境界 +12；闪避：每境界 +3（线性，避免命中体系失控）
```

具体值见内容表 §1。**曲线底数 1.7 的理由**：5 个境界内总放大 8.35 倍，既让「突破」成为体感上最大的单次跃升（每次 +70%，远超单级武学的 3–8%），又不至于让跨一个境界的关卡完全不可交互（双曲减伤下仍有 30%+ 伤害效率）。

> **底数适用范围**：固定底数 1.7 只覆盖 MVP-0 的境界 1–5（完整版第一大境界段）。固定底数下绝对跃升已逐级放大（境界 4→5 的属性增量 ≈ 境界 1→2 的 5 倍），相对跃升恒为 +70%；完整版「越往后质变越大」不通过连续递增底数实现，而按初案 §三「底数分段规则」——段内固定底数、段间 2–3 个跃迁节点承载质变。若未来调整底数，须同步复查双曲常数 K=100 是否需分段（DEF 值域超过 K 一个数量级后减伤趋于饱和）。

### 3.2 挂机内力产出（经济主引擎）

```text
内力产出/秒 = 9 × 1.25^(境界 − 1) × (1 + 声望效率加成)

境界 1–5 产出：9.0 / 11.3 / 14.1 / 17.6 / 22.0 每秒
```

**产出随境界提升（×1.25）的设计理由**：修炼效率随境界提升既符合武侠直觉，更是第二轮加速的**复利引擎**——声望的 +20% 内力加成让玩家更早突破，更早突破又更早享受更高产出档位，扁平的加法节点由此产生 28% 的实测提速（见附录 A），命中 25%–40% 目标区间。没有这条规则，+20% 节点只能带来 ~13% 提速，无法达标。

### 3.3 境界突破消耗与充能

```text
境界 2 / 3 / 4 / 5 突破消耗：2,800 / 5,000 / 10,000 / 21,000 内力
充能式突破：消耗分 5 段注入（每段 = 消耗 ÷ 5），注满后手动点击突破；
每段注入完成是一次可见进展反馈（进度条 + 提示）
```

充能式突破是「相邻可见进展 ≤ 5 分钟」锚点的实现机制：最长的境界 5 充能段 = 4,200 内力 ÷ 17.6/秒 ≈ 4.0 分钟，恰好压在 5 分钟红线内。**若调整突破消耗或产出，必须复查「最大充能段耗时 ≤ 5 分钟」。**

> **防误读标注（尺度与成本形态）**：
> 1. 境界 5 突破的 21,000 内力（≈20 分钟积累）是**原型尺度下的最大单笔投资**——超过全部 10 级武学之和（13,963），也超过前三次突破之和（17,800），占首轮总时长 40%+；且充能与游玩并行（该时段玩家同时在推地图 3、打 3 个克制教学精英、升武学 lv7–8、买机制节点 3），不是挂机干等。「20 分钟」的轻重必须放在 60 分钟原型内衡量，勿与真实时间直觉比较。
> 2. 完整版同名境界（一流高手，处于 10 境界轴中段）的突破量级由初案「十四、节奏与会话结构」的轮长曲线反推——届时一轮 1–3 天，单次突破的积累为数小时至一天量级。**本表消耗数值不可外推到完整版**（与规格书 §6.6「勿向完整版外推」同源）。
> 3. **MVP-0 突破只用内力单一成本是刻意的原型简化**（规格书 §2.3 已把突破材料抽象掉）。完整版突破的「重量感」由多层承载：材料成本（突破丹，初案 §九）、前置条件（江湖挑战、心法层数，初案 §三）、风险与仪式（心魔试炼 + 温和失败规则，初案 §三）、演出（突破/结算演出）。时间成本只是其中一层，勿以 MVP-0 形态理解完整版突破。

### 3.4 武学等级

```text
武学等级 n 的内力消耗 = round(200 × 1.4^(n−1))
→ 200 / 280 / 392 / 549 / 768 / 1,076 / 1,506 / 2,108 / 2,952 / 4,132（lv1–10）
武学等级上限 = 当前境界 × 2（境界 2 → lv4 … 境界 5 → lv10）
```

**等级上限绑定境界的理由**（本次产表新增的规格规则，见规格书 v0.5）：
1. 制造「境界 vs 武学」的真实互锁——武学堆到上限后，境界是唯一出路，反之境界解锁新档位又给武学消费空间。
2. 防止越级破坏终局节拍：无上限时唐门可在境界 4 + lv10 击杀 Boss 3，随后被迫纯等待境界 5 达 15+ 分钟（模拟实测），产生归隐前的体验死区。设上限后三路线在境界 4 全部打不过 Boss 3（见附录 A 矩阵），境界 5 是真实需求，终局节拍收紧。


## 5. 失败提示诊断规则（规格书 §7.5 交付项）

战斗失败后，按以下优先级**从上到下取第一条命中**的规则输出提示（最多再附加一条次优先命中项）：

| 优先级 | 触发条件（战斗结算数据） | 提示文案方向 |
|---:|---|---|
| 1 | 玩家境界 < 关卡推荐境界（内容表列） | 「当前境界偏低，继续修炼可提高基础属性。」 |
| 2 | 敌方带「高闪」且玩家实际命中率 < 75% 且路线 = 华山 | 「你的命中不足，华山暴击流面对高闪敌人不稳定。」 |
| 3 | 敌方带「破甲」且战斗结束时玩家破甲层数 ≥ 2 且路线 = 少林 | 「敌人破甲较高，少林防御收益被削弱。」 |
| 4 | 敌方带「净化」且战斗中毒层被清除次数 ≥ 2 且路线 = 唐门 | 「敌人净化了毒层，唐门需要更高叠毒速度或换目标。」 |
| 5 | 敌方带「反伤」且玩家所受反伤 ≥ 自身气血上限 30% | 「敌人反弹了你的爆发，考虑降低单次伤害或先强化生存。」 |
| 6 | 战斗达 50 回合上限（超时判负）或敌方剩余血量 > 40% | 「你的输出不足，强化主武学或提升境界。」 |
| 7 | 兜底（以上均未命中） | 「差一点就赢了——再强化一次武学，或等内力突破境界。」 |

规则 1 优先于路线诊断：境界落后是最常见根因，先排除它，路线建议才有意义。

## 6. 回刷收益（防原地刷爆）

```text
重复通关已通关卡：内力奖励 = 首通值 × 20%，银两 = 首通值 × 50%，阅历 = 0
同一关卡连续回刷衰减：第 n 次连续回刷奖励再 × 0.8^(n−1)，间隔 10 分钟重置 [待测试]
```

阅历不可回刷是防套利核心：阅历的全部价值在机制节点与换线自由，若可刷则「阅历不可再生」的换线返还设计失去意义。

**第二轮校验假设**（预支《声望经济表》的节点定义，该表最终确认）：首轮声望购买 2 个节点——「旧梦重温」内力产出 +20%、「快速入门」境界 2/3 突破消耗 −30%。注：「快速入门」相比规格书 §9.2 候选描述（仅境界 1→2）扩宽到前两次突破，是达成 25%–40% 提速区间的必要强度，需在《声望经济表》中定稿。
