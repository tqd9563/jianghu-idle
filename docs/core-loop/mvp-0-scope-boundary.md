# MVP-0 与完整版的量级边界（保留 vs 简化对照）

> 本文档汇总散落在规格书、公式表与初案中的「勿向完整版外推」声明，作为单一回顾入口。
> 权威来源：规格书 §6.6、公式表 §3.1 / §3.3、初案 §三 / §四 / §七 / §十四。若本文与上述章节冲突，以上述章节为准并回来修订本文。

## 一句话原则

**MVP-0 是一个 60 分钟的压缩原型，唯一使命是验证「prestige 循环成立」这一个假设，不是完整版的等比缩小。**

判断口诀：**「怎么算」保留，「算多大」不保留**——公式、规则、守则、曲线形状带进完整版；具体数字、配比、时长全部是为 60 分钟测试反推的，进 MVP-1 时按新的轮长目标重新出一版。

## 保留到完整版的：规则和结构（骨架）

| 类别 | 内容 | 出处 |
|---|---|---|
| 公式形态 | 双曲防御 `100/(100+DEF)`；命中率 `命中/(命中+闪避)`，下限 30%。公式的**形状**保留；常数 K=100 完整版可能分段调整（调底数须同步复查 K） | 公式表 §2 / §3.1 |
| 战斗结算规则 | 固定回合制；毒无视防御且绕过护盾；反伤按「减免后、护盾吸收前」计算；六状态的结算时机与叠加规则 | 规格书 §7.1 / §7.2 |
| 曲线形态 | 指数基础曲线；段内固定底数 + 段间跃迁节点；敌人曲线锚定玩家基础曲线同源同步 | 初案 §三、公式表 §3.1 |
| 数值全局规则 | 每个最终量乘区 ≤2；同域加法合并；4 个加成域（域间不相乘）；禁止以新增乘区作为成长感手段。明文为**完整版全局规则**，非 MVP-0 专属 | 初案 §四 |
| 归隐结构 | 门槛锚定推关里程碑；首次归隐后门槛常驻不上升；声望公式方向（里程碑锚定 + 表现加成封顶 + 短轮惩罚） | 初案 §四 |
| 设计守则 | 门槛 Boss 只做数值检查，硬克制只放在可绕过的敌人身上；「相邻可见进展 ≤5 分钟」节拍红线（充能式突破是它在 MVP-0 的实现机制） | 规格书 §6.3 / §6.1 |
| 经济原则 | 每种资源必须有来源/主消耗/后期 sink 三列账；换路线类操作不没收不可再生资源（全额返还 + 摩擦费） | 初案 §二、规格书 §6.4 |

## 刻意简化、不可外推的：量级和内容

| 简化项 | MVP-0 形态 | 完整版形态 | 出处 |
|---|---|---|---|
| 所有具体数值 | 突破消耗/敌人属性/产出速率均为原型尺度，从 60 分钟锚点反推 | 按完整版轮长曲线重新反推 | 公式表各表头「推导锚点」 |
| 突破量级 | 境界 5 突破攒约 20 分钟内力 | 同名境界处于 10 境界轴中段，单次突破数小时至一天量级 | 公式表 §3.3 |
| 突破成本构成 | 只有内力单一成本（材料被刻意抽象掉） | 四层重量感：材料（突破丹）+ 前置条件（心法/江湖挑战）+ 风险仪式（心魔试炼 + 温和失败）+ 演出 | 公式表 §3.3、初案 §三 / §九 |
| 归隐门槛 | 「境界 5 + Boss 3」双条件（门槛 = 内容边缘 = 终点线） | 推关里程碑，与境界序号脱钩 | 规格书 §6.6、初案 §四 |
| 地图×境界配比 | 3 图消耗 5 境界 | 8 图映射 10 境界，首轮内容只占总量 20%–30% | 初案 §七 |
| 境界底数 | 固定 1.7，覆盖境界 1–5 | 1.7 只是第一大境界段的底数；后续段另定，段间跃迁节点承载质变 | 公式表 §3.1、初案 §三 |
| 节奏模型 | 全程在线的主动循环，无离线 | 离线/回访节拍是品类核心；属独立假设，归 MVP-1 单独验证，MVP-0 结论不构成其证据 | 规格书 §1.2 / §10.3 |
| 毒的穿防形态 | 完全无视防御 | 「部分穿透防御」为完整版预留形态 | 规格书 §5.4 |
| 内容系统 | 无装备、无炼丹、无门派、无秘境；声望节点仅 6–10 个、首轮只买 1–2 个 | 全量系统 | 规格书 §2.3 |

## 对后续工作的含义

1. **MVP-0 测试通过 ≠ 品类成立**：它证明的是主动 prestige 循环成立；放置/离线的习惯循环是另一个假设，MVP-1 必须单独验证。
2. **进 MVP-1 的数值工作方式**：不修改 MVP-0 各表的数字去「放大」，而是换锚点（新的轮长目标）后按各表头部的「推导锚点」重推一遍；规则层（上表第一部分）原样沿用。
3. **任何新增数值/系统先过规则层**：归属哪个加成域、乘区是否超 2、资源三列账是否闭合、是否触碰门槛 Boss 守则与 ≤5 分钟节拍红线。
