## 2. 先厘清事实：自动触发的「主动技」已经存在

用户感知的「没有主动武学」是演出存在感问题，不是机制缺失：

- 三路线核心机制**本质就是条件自动释放的主动技**：华山剑意满层自动爆发剑招 400%（每次暴击 +1 层——概率触发链）、唐门满层自动毒爆、少林开战自动护盾 + 受击自动反伤。
- 「学更强力的技能形态作为卡关解法」在 MVP-0 已有承载：武学升级改触发参数，机制节点（UI 呈现「参悟」，见内容表 §3.2 映射注记）直接改技能形态——剑招 400%→550%、剑意需求 5→4→3、毒爆 50%→80%。
- 因此本方向的增量只有两块：**收集**（多本武学、获取渠道、图鉴）与**星级**（同一武学的稀有度/强度分层）。「释放方式」不在增量里，完整版仍维持自动触发（§7.1 的理由与规模无关）。

## 3. 完整版挂点（初案 §五/§九 既有框架，星级作为其分层提案）

- **收集框架已在案**：8 类武学 × 流派组合；获取渠道五条——门派学习、秘籍掉落、奇遇、声望商店兑换、秘境残页合成（初案 §五）；秘籍研究消耗阅历产出解锁与上限（§九）；「残卷合成 → 完整秘籍」本就是长线收集钩子。
- **星级 = 强度分层**：可表达为「同名武学的品阶」（残页合成升品）或「秘籍稀有度」（掉落分层），两者都落在既有渠道内，不新增系统面。
- **内容成本红线**：初案 §五 明文「8 类武学 × 8 门派 × 装备词条的全矩阵内容成本极高，不做全铺开」——星级分层会把内容矩阵再乘一维，**必须在框架分批排期验证后进场，不得先于框架铺开**。
- 与门派独占机制武学（初案 §六「机制是轮换的理由」）的边界：星级抬强度、独占武学供机制，两轴不得互相替代——若高星通用武学强于门派独占机制武学，门派轮换承诺失效。

## 4. MVP-1 条件性动作：触发演出增强（非本方向立项）

- **本体**：规格书 §7.1 既有硬性要求——「技能触发必须在战斗日志与演出中高亮（触发时刻、伤害占比、状态图标）……战斗观赏性由触发演出承担，不靠操作」。
- **触发条件**：真人测试反馈「战斗存在感弱 / 像幻灯片 / 感知不到技能」。
- **边界**：只加演出，不引入手动操作、不加战斗内资源、不改触发参数。
- **MVP-0 已先行的最小承载**：失败战报的伤害占比行（爆发剑招/反伤/毒伤占输出比，冻结文案见 `../core-loop/mvp-0-battle-copy.md` §2）与剑意层数日志标注（同文件 §3）。

## 5. 规格化前置检查（完整版立项时逐项过）

按量级边界文档「对后续工作的含义」第 3 条的通用四项（加成域归属、乘区是否超 2、资源三列账、门槛 Boss 守则与 ≤5 分钟节拍红线）之外，本文特有检查项：

1. **星级强度的乘区归属先定**：星级加成若随轮重置 → 加法合并进本轮临时乘区；若跨轮保留 → 吃永久预算软上限并进初案 §四预算表。二选一，禁独立乘区。
2. **收集资源三列账**：残页/秘籍作为新资源须先补全「来源/主消耗/后期 sink」（初案 §二纪律），尤其防「图鉴收齐后残页无出口」。
3. **随机预算 vs「卡点有原因」支柱**：掉落随机（获取）与概率触发（战斗）双随机叠加会稀释卡点归因——需明确随机性预算，保证失败诊断仍能给出可执行方向。
4. **蓝条类战斗资源轴若做**：归内功线，须重验「放置可理解」支柱与自动战斗的观赏模型，且属性/状态白名单按完整版规格重开清单，不沿用 MVP-0 的 7+6。
5. **归隐处理**：武学星级/图鉴归入初案「归隐保留/重置总表」哪一行（现行：武学等级重置、图鉴保留）——星级挂等级还是挂图鉴，决定它是每轮咀嚼物还是永久成长。
