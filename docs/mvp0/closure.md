### 2.2 提速比实测的诚实处理（警示注记）

预试跑导出中：**T00 双轮时间被隔夜/AFK 污染，不可用；T02 只有干净的第一轮，未完成第二轮**——所有者实测的干净双轮提速比**无法计算，本文不硬算污染数据**。处理方式：

- T02 首轮四里程碑（7.0 / 13.5 / 25.9 / 43.1 分钟）作为**干净基线**入账；
- 提速比引用 **sim 理论值（47% / 29% / 22%）**并如此标注；
- 所有者多轮游玩「明显变快」的体感作为**方向性定性证据**入账，不冒充实测比值。

若日后需要实测提速比：跑一次不间断干净双轮（约 80 分钟活跃）即可补上，装置已齐（§5-3）。

## 4. 残余风险补验节点（只登记，不强推）

1. **推荐补验节点**：首个公开可玩链接或朋友圈 3–5 人小范围分发时——用存档的《测试执行方案》**降档执行**（无需陪同，埋点导出内建，加 5 问微访谈），边际成本接近零。
2. **底线登记**：若始终不分发——在任何「循环成立」的声明被第三方消费之前（展示 / 发布 / 宣传），R1–R6 须先补验；**对外宣称「放置循环成立」前，R7 须先按其销账条件补验**（R7 的补验不依赖分发：内容量扩充后的自然游玩期即可执行）。
3. **装置保留**：MVP-0 测试埋点与一键导出功能**不删**——它是日后零成本补验的全部装置。
