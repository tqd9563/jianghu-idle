## 3. 实现口径注记（定稿，验收按此判）

1. **满额对账以主公式 floor 真值为准**：增补表 §3.3 校验表为四舍五入粗算，4 格与 floor 差 1（75→74 / 1822→1821 / 111→110 / 2621→2620）；§2.1 主公式是权威。
2. **热刷新下界**：原始离线 < 5 秒完全跳过（不入账、不发事件），防会话内热刷新事件噪声；5s–180s 静默入账并发 `silent=true` 事件。
3. **观察员暂停中的存档不结算**：暂停冻结一切结算（与 tick 口径一致），时间戳照常消费；暂停横跨离线的时段不产生离线收益。
4. **`charge_segment_full` 补发口径**：出关入账后首个 tick 按新水位一次性连发（同 ts burst），即 A2「一次性补发不轰炸」的事件层表达；UI 提示层不逐段弹提示。
5. **`current_max_idle_stage` 权威来源**（增补表开放问题 1 裁决）：= 已通关的最高关卡全局序号（关卡顺序通关构成前缀，未通任何关取 1），不新增存档字段。
6. **构成公式行仅观察员通道显示**（所有者 2026-07-07 裁决，规格 §6 呈现裁决 ②）：A1「三因子构成在结算屏可查」子项在**观察员模式**（`#observer=1`）下验收；玩家侧默认不渲染公式行。
