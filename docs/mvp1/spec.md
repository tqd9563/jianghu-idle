## 1. MVP-1 设计目标

### 1.1 头号假设：放置节拍（定义保留，验证后置）

```text
离线收益 → 回归检查 → 决策投入
```

MVP-0 只验证了主动 prestige 循环（等 2 分钟资源与隔 8 小时回访是两种不同的心理模型，见 MVP-0 规格书 §1.2 / §10.3）。放置节拍是独立的第二核心假设。

**当期状态（§10-1 终裁）**：MVP-1 不验证该假设，只交付其功能载体并做功能验收（§8.1）；假设验证后置到「内容量扩充后的自然游玩期」，挂《收口记录》R7。当期核心目标 = 基础离线收益的功能正确性：结算对、不越权、不破坏 MVP-0 既有系统。

### 1.2 假设边界

- 验证的是**心理模型**而非功能：玩家离开后是否愿意回来、回来是否看得懂、看懂后是否有事可决策——三环缺一，节拍不成立。
- MVP-0 结论按单人口径收口：数值层与机械层成立，主观层为永久敞口（《收口记录》R1–R6）。本文不得引用 MVP-0 任何数据作为放置节拍成立的证据。
- 玩家应感到：① 离开时可以放心走，闭关不会替我做决定；② 回来时一眼看懂拿到了什么；③ 结算后有一件值得做的事；④ 形成节奏后开始预期「下次上线能做 Y」。

### 1.3 设计支柱

沿用 MVP-0 五支柱，新增一条：

| 支柱 | MVP-1 表达方式 | 判定标准 |
|---|---|---|
| 回访有决策 | 出关结算后必然衔接至少一个真实决策点 | 无「上线只点一下就走」的空会话（初案 §十四明文禁止） |

## 3. 核心循环规格：回访会话

以下均为设计意图值，当期不设验证目标（验证后置）。

### 3.1 单次回访会话（3–10 分钟）

```text
上线 → 出关结算（一屏看懂）→ 回归检查（进度/资源/卡点）→ 决策投入 → 设定下次目标 → 离线
```

- 紧张感来源：离线上限——收益封顶构成回访动机；不做惩罚机制（无「不回来就扣东西」）。
- 胜利状态 = 会话内完成至少一个有意义决策并对下次回访形成预期；失败状态 = 空会话（§8.3 头号现象）。

### 3.2 单日循环（2–3 次会话）

会话间隔与离线上限的匹配是增补表的核心命题（间隔 > 上限 = 浪费感；间隔 << 上限 = 上限形同虚设）。当期按 §4.1 预算约束取值，后置验证时按真实生活间隔重估。

### 3.3 长期循环

MVP-0 的「归隐 → 第二轮更快」循环原样保留；当期轮长维持压缩锚点，离线只是轮内资源积累的并行通道。「轮长拉长为多会话跨日」随全量重推批次后置。

## 4. 轮长锚点与当期数值工作范围

### 4.1 轮长锚点裁决（定稿）：保留 MVP-0 压缩锚点不动

**MVP-1 保留 60 分钟压缩锚点，全部既有数值表一字不改；当期数值工作 = 一张离线数值增补表。全量换锚点重推推迟到内容量扩充批次。**

理由（摘要）：节拍验证已后置，轮长重推失去当期目的；功能验收在压缩锚点上完全可执行（上限压低即可覆盖触顶用例）；锚点不动则 sim golden、Boss 需求矩阵、声望收支全部零迁移。

**当期命题——离线预算约束**：压缩锚点下离线收益的相对威力极大（一夜离线按初案完整版起点值可跳过整轮张力），增补表必须按以下预算线取值：

```text
单次满额离线收益 ≈ 一次会话级投入（一次武学升级或一段周天充能），
且 << 一轮总需求
```

初案的 4h / 60–80% 是完整版轮长下的起点值，仅作方向记录，取值以增补表为准。

### 4.2 重推方法论（保留给后置批次引用）

按量级边界文档执行：「怎么算」保留、「算多大」不保留；换锚点后按各表头部「推导锚点」重推，规则层原样沿用；任何新增数值先过规则层四项检查（加成域归属、乘区 ≤2、三列账闭合、门槛 Boss 守则与 ≤5 分钟红线）——**增补表当期即适用此条**。≤5 分钟红线是在线尺度约束，离线等价约束由后置验证另定。

## 6. 闭关—出关结算呈现（硬性要求）

1. **一屏看懂**：闭关时长、资源明细、是否触顶，一屏内呈现不埋层级。
2. **数值可信**：结算数字 = 结算函数实际输出，构成（时长 × 速率 × 效率）可核对。
3. **不越权确认**：结算屏让玩家确认闭关没有替他做决定。
4. **衔接决策**：结算屏关闭后落在可行动的决策入口，30 秒内有事可做。
5. **术语纪律**：玩家侧一律「闭关 / 出关结算」，「离线收益」不出现在界面文案。

> **呈现裁决（所有者，2026-07-07）**：
> ① 结算与回归检查**合并一屏**（账目式：三资源 + 触顶提示 + 不越权行 + 回归检查现状）；
> ② 构成公式**仅观察员通道**（`#observer=1`）显示，玩家侧默认隐藏——§6-2 红线由观察员通道满足，公开分发时随 R1 补验重估；
> ③ 关闭落点 = **回归主界面**（单按钮「出关 · 回归江湖」），决策衔接由回归检查现状 + 主界面既有入口承接；
> ④ **入账动效**：时长与三资源自零滚动至实发值（约 1 秒，reduced-motion 降级直显）；只做入账反馈，无弹字无频闪。

## 7. 与 MVP-0 的关系

### 7.1 规则层沿用清单（原样带入，不重推）

1. 公式形态：双曲防御 `100/(100+DEF)`、命中率 `命中/(命中+闪避)` 下限 30%。
2. 战斗结算规则：固定回合制；毒无视防御绕过护盾；反伤「减免后、护盾吸收前」；六状态结算时机。
3. 曲线形态：指数基础曲线、段内固定底数 + 段间跃迁、敌人曲线锚定玩家曲线。
4. 数值全局规则：乘区 ≤2、同域加法合并、4 加成域域间不相乘、禁新增乘区作成长感。
5. 归隐结构：门槛锚定里程碑、首次后常驻、声望公式方向。
6. 设计守则：门槛 Boss 只做数值检查；≤5 分钟可见进展红线（在线尺度）。
7. 经济原则：资源三列账；不没收不可再生资源。
8. **MVP-0 全部已实现系统作为基底，规则与数字都不动**（§4.1）。

### 7.2 MVP-0 结论的效力边界

- prestige 循环成立（单人口径）≠ 放置节拍成立；MVP-0 无外部测试报告，主观层结论以敞口台账 R1–R6 为准，不得引用为已成立。
- 反向同理：MVP-1 若失败，优先归因节拍层（回访/结算/决策点），不自动否定主动循环——归因隔离是两阶段拆分的意义。

### 7.3 验收与验证形式

- **当期 = 阶段 A 功能验收**：按 §8.1 A1–A7 逐项验收，允许边验边修、修后重跑；产物 = 验收记录（`acceptance.md` §4）。
- **后置 = 阶段 B 节拍验证**（内容量扩充批次启用，届时若轮长已变先修订协议）：正式窗口 ≥3 天含 ≥2 隔夜；窗口内数值/文案冻结；问题只记不修。**防偏差五条**：① 预登记（预期值与失败阈值开测前写死）；② 失败信号触发即承认，禁止事后豁免；③ 自然嵌入（无闹钟无日程，回访由「想到它」驱动）；④ 即时笔记（每会话 ≤1 句，只作附注）；⑤ 双帽分离（改一个数就是废一窗数据）。
- 埋点：另立《MVP-1 埋点增补规格》（`telemetry.md`）——出关结算/会话事件当期启用，回访节拍类指标保留定义、后置启用；复用 MVP-0 事件信封。

|---|---|---|---|---|
| 1 | 回访意愿 | 自发回访间隔分布与上限匹配 `[待定-预登记]` | 无提醒条件下回访自然发生 | 动机泛化（R4） |
| 2 | 出关结算可信 | 结算同源校验通过；结算屏停留时长落在合理带 | — | 自解释性本体（R1） |
| 3 | 回访有决策 | 空会话占比与首个决策时延达标 | — | 无 |
| 4 | 上限机制有效 | 触顶浪费率 < 阈值（设计者频繁触顶 = 错配的诚实信号） | — | 「上限被理解」（R1/R5） |
| 5 | 节奏形成 | 窗口后半段回访间隔方差收敛（窗口 ≥3 天方可采样） | 即时笔记出现「预期下次能做 X」 | 感知泛化（R6 同类） |
| 6 | 在线仍有价值 | 在线决策事件密度达标；纯收菜会话占比 < 阈值 | 在线自发挑战/突破/调整 | 无 |

### 8.3 节拍验证失败现象表（后置启用）

| 失败现象 | 可能原因 | 处理方向 |
|---|---|---|
| **设计者本人任一自然日零自发回访（最强红旗）** | 回访动机崩溃（义务感是正偏差，压不住即无可辩驳） | 触发即承认失败，禁止事后豁免 |
| 空会话超阈值 | 回访决策点不足 | 先查决策呈现衔接（§6-4）；仍不足触发 §2.4 例外条件 |
| 结算数字对不上/构成不可查 | 结算构成不透明 | 重做结算屏信息架构；数值可信是红线 |
| 回访间隔远超上限（触顶浪费常态化） | 上限太宽/收益预期太弱 | 收紧上限或强化下次目标呈现 |
| 回访过密（接近在线挂机） | 上限/速率错配 | 重推匹配关系（§3.2）；确认非义务感效应 |
| 离线被体验为惩罚 | 效率折扣或触顶浪费感过重 | 调效率或触顶前提示；不引入没收机制 |
| 在线纯收菜化 | 离线效率过高或在线独占内容太薄 | 压离线效率；查在线独占决策密度 |
| 回访后无进展感 | 离线产出撑不起会话内一次投入 | 重推产出/消耗配比 |
| 归隐节奏被离线打乱 | 轮长锚点与离线速率错配 | 回 §4.1 重定锚点；prestige 规则不动只动数字 |

> **当期例外**：末行的数值前置（离线收益不得跳过轮内张力）当期即由 §4.1 预算约束 + §8.1-A1/A4 守住。

放置节拍假设本身（R7，后置）；留存/商业化；主动循环机械与数值层（已收口）及其主观层敞口（R1–R6，自测测不出，按《收口记录》§4 补验）；完整版轮长曲线与 MVP-2 内容；移动端形态（沿用桌面优先）。
