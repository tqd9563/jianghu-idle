## 1. 一句话口径

**MVP-2 不是拿 MVP-0 当前内容直接测试自然回流，而是先把 60 分钟压缩原型扩成一个最小多会话放置原型，再在内容未耗尽的前提下验证自然回流节奏。**

因此，MVP-2 的工作顺序是：

```text
内容量准备 → 轮长与数值重锚 → 少量长期目标 → 自然回流验证 → 根据失败原因决定下一版
```

---

## 2. 为什么不能直接用 MVP-0 内容验证

MVP-0 的内容量是为 60 分钟压缩验证服务的：5 个境界、3 张地图、3 个 Boss、三路线、归隐与少量声望节点。它证明的是主动 prestige 循环在压缩条件下可跑通，不证明多日放置节奏成立。

如果玩家已经通关或没有未完成目标，那么「一天没有自然想打开」不能判定为回流失败，只能说明：

```text
当前内容量不具备验证自然回流的条件。
```

自然回流验证只有在以下前提成立后才有效：

- 仍有未完成目标；
- 仍有可见的下一步成长；
- 离线收益能推动但不能替代关键决策；
- 玩家回来后存在至少一个真实决策入口；
- 关闭前能够形成「下次回来要做什么」的预期。

---

## 3. MVP-2A：内容量准备

MVP-2 的第一阶段不是验证，而是建出可验证的最小场地。

目标：让游戏从「一小时可通关」变成「能支撑 3-5 天自然窗口内多次回访，且回访时仍有目标」。

内容准备不等于系统膨胀。MVP-2A 已选两个方向：

| 已选方向 | 权威文档 | 用途 | 边界 |
|---|---|---|---|
| 内容纵深 | `content-depth.md`；结构表见 `content.md` | 拉长主线脊柱、提供新地图 / Boss / 挑战节点 | 只定结构，不定数值；不新增系统 |
| 秘籍残页 | `manual-fragments.md` | 长期收集与跨归隐目标 | 不新增新武学本体、随机掉落或门派 / 秘境渠道 |

图鉴 / 见闻录、传承、炼丹、秘境、门派、奇遇等仍按 §8 停放；若 MVP-2C 证明缺口不在内容耗尽，而在决策、目标表达或江湖感，再按 §7 的失败原因进入后续主题版本评审。

MVP-2A 的退出标准：

```text
3-5 天窗口内，玩家理论上不会因为内容耗尽而自然停止；
每次回访至少存在一个可解释的待办目标；
一轮归隐不再默认压缩到单次 60 分钟体验内完成。
```

---

## 4. MVP-2B：轮长与数值重锚

MVP-1 为了功能交付，保留 MVP-0 的 60 分钟压缩锚点。MVP-2 若要验证自然回流，必须重锚为多会话节奏。

这不要求 3-5 天内完整跑完所有长期内容，但要求验证窗口内能经历多个有意义节点，例如：

```text
离线回来 → 升级 / 突破
再离线 → 挑战新 Boss
失败 → 调整路线或资源投向
再回来 → 打过 / 接近打过
达到瓶颈 → 考虑归隐或追长期目标
```

MVP-2B 需要重估：

- 单轮时长从压缩体验改为多会话体验；
- 离线上限与真实生活间隔的匹配；
- 离线收益效率与一次会话级投入的关系；
- 境界、地图、Boss、归隐收益的时间锚点；
- 周天动态 N 是否需要进入；
- 离线收益是否跳过「卡点 → 调整 → 归隐」张力。

原则沿用 MVP-1 §4.2：规则形态保留，具体数字按新锚点重推。

### 4.1 基准节奏锚点（所有者确认）

| 锚点 | 目标 |
|---|---|
| 首轮标准归隐 | 12–18 小时 |
| 第二轮标准归隐 | 8–12 小时 |
| 后续单轮 | 6–12 小时 |
| 3–5 天验证窗口 | 预期完成 4–6 次归隐 |
| 基础离线上限 | 8 小时 |

离线上限覆盖睡眠 / 工作间隔，但离线仍只发基础资源，不自动突破、不推进关卡 / Boss / 试炼、不归隐、不产残页；离线效率与各档资源量由 MVP-2B 后续表重推。

## 5. MVP-2C：自然回流验证

只有在 MVP-2A / MVP-2B 使内容与轮长具备验证条件后，才进入自然回流验证。

验证问题不是抽象的「留存率」，而是三句话：

```text
我为什么回来？
回来后我做什么？
我为什么下次还会回来？
```

建议窗口：3-5 天，至少包含 2 个隔夜。窗口内遵守 MVP-1 §7.3 的防偏差纪律：无闹钟、无日程、无待办提醒，回访只能由「想到它」驱动；窗口内不边测边改数值或文案。

每次回访只做轻量记录，避免测试行为本身制造回流：

```text
日期 / 时间：
距离上次关闭：
是否自然想打开：是 / 否
打开原因：
是否触顶：是 / 否
出关结算是否看懂：是 / 否
本次做了什么决策：
关闭前下次目标：
一句话感受：
```

## 6. 判定口径

以下失败信号必须先检查前提：内容是否未耗尽、目标是否仍存在、轮长是否已重锚。

| 现象 | 若内容已耗尽 | 若内容未耗尽且目标存在 |
|---|---|---|
| 一整天没有自然想打开 | 内容准备不足，不判回流失败 | 回访动机强红旗 |
| 打开只领取收益就关闭 | 可能是内容已通关 | 回访决策不足 |
| 关闭前没有下次目标 | 内容目标不足 | 长期目标表达失败 |
| 经常触顶且不在意 | 可能已无目标可消耗资源 | 上限 / 动机错配 |
| 离线回来一路点完无判断 | 可能内容太短 | 离线收益过强或在线决策太薄 |

MVP-2 自然回流在单人口径下可暂定成立，当且仅当：

- 3-5 天内没有在「内容未耗尽」前提下出现整日零自然回访；
- 大多数回访不是纯收菜；
- 出关后 30-60 秒内能做出至少一个真实决策；
- 多数关闭前能说出下一次回来要做什么；
- 离线上限没有长期严重错配；
- 离线收益没有跳过卡点、挑战、归隐等核心决策。

## 7. 与后续版本节奏的关系

MVP-2 之后不预设无限 MVP 编号。

- 若 MVP-2 自然回流成立：停止把后续版本称为 MVP，转入主题版本 / 垂直切片节奏。
- 若 MVP-2 暴露核心缺口：可保留一次条件性 MVP-3，但 MVP-3 必须只修一个主问题。

MVP-3 的方向由 MVP-2 结果决定：

| MVP-2 结果 | MVP-3 方向 |
|---|---|
| 回来后没事可判断 | 回流决策增强 |
| 长期目标不够吸引 | 长期追求强化 |
| 节奏太快 / 太慢 | 数值重锚 |
| 转生差异不明显 | 传承 / 永久成长强化 |
| 内容够但缺江湖感 | 轻量事件或门派声望 |

MVP-4 不在当前规划中。若 MVP-2 或条件性 MVP-3 后核心循环成立，后续改用：

```text
主题版本：秘籍与图鉴 / 江湖事件 / 门派声望 / 传承天赋 / 数值重锚
```

每个主题版本只回答一个问题，避免用「再做一个 MVP」掩盖系统膨胀。

---

## 8. 设计纪律

- 不用当前 MVP-0 内容直接判定自然回流失败。
- 不在内容耗尽后把「不想打开」记为回访动机失败。
- 不因为回流弱就盲目堆系统；先诊断是内容不足、决策不足、数值错配，还是目标表达不足。
- 不同时加入炼丹、秘境、门派、奇遇、图鉴、传承等多个主系统。
- 不在自然回流窗口内边测边改；改一个数就废一窗数据。
- 不对外宣称放置节奏成立，除非 R7 按自然窗口纪律销账。
