## 1. 一句话结论

MVP-2A 内容纵深采用**最小主线扩容包**：2 张新主线地图、2 个新主线 Boss、每张新图 1 个固定挑战节点、1 个后续成长段结构占位，并复用既有战斗结算、属性、状态与标签；不新增门派、炼丹、秘境、奇遇、装备、武器或新武学池。

---

## 2. 已批准方向

| 方向 | 裁决 | 一行理由 |
|---|---|---|
| 主线脊柱扩容 | **进 MVP-2A** | 秘籍残页给长期目标，但不提供新的江湖空间与主线瓶颈。 |
| 少量挑战节点 | **进 MVP-2A** | 作为内容节点级挑战，补足 Boss 外的回访目标。 |
| 敌人变体 | **进 MVP-2A** | 用既有标签组合制造卡点差异，成本低于新机制。 |
| 完整 10 境界 / 长线终局 | **不进本批** | MVP-2A 只支撑 3-5 天验证场地，终局措辞仍见 `../overview/worldview.md` §10。 |

---

## 3. 内容纵深范围

| 做 | 说明 | 边界 |
|---|---|---|
| 境界跨度结构 | 只登记 MVP-2A 需要承接的后续成长段 | 不填最终属性、突破成本、时长 |
| 主线地图结构 | 追加 2 张新主线地图，形成“新增中段 → 窗口末端”的最小阶梯 | 地图名可待定；不写剧情线 |
| 主线 Boss 门槛 | 追加 2 个新主线 Boss，分别承担中段锚点与末端主锚点 | 不把 Boss 设计成门派掌门或组织首领 |
| 挑战节点 | 每张新图 1 个固定节点，复用现有战斗规则 | 不是秘境、爬塔、刷新玩法或独立经济 |
| 敌人变体 | 高闪、反伤、高防、毒压、净化、高攻等既有标签组合 | 不新增属性、状态、结算顺序 |

挑战节点是**内容节点**，不是系统：无层数、无扫荡、无独立货币、无每日刷新，只为“下次回来试着攻克”提供目标。

---

## 4. 与长期目标的分工

| 模块 | 职责 | 不负责 |
|---|---|---|
| 内容纵深 | 地图推进、Boss 卡点、江湖足迹、轮长上限 | 长期收集经济 |
| 秘籍残页（`manual-fragments.md`） | 跨归隐收集、明确待办、长期成长钩子 | 新地图 / 新境界 / 新主线 Boss |
| 真传试炼 | 门径专属挑战与门径真传来源 | 主线推进骨架 |
| 声望商店残页兑换 | 缺页补齐与声望长期出口 | 替代主线推进或试炼攻克 |

奖励分工：主线 Boss 继续服务推进与归隐声望锚点；门径真传残页仍由真传试炼发放；商店只做补齐，不替代打 Boss / 打试炼。

---

## 5. 明确不做

| 不做 | 原因 |
|---|---|
| 门派系统 / 源流揭示 | 与武学门径正交，具体对应表仍属 `../overview/worldview.md` §8 / §10 留白。 |
| 炼丹 / 秘境 / 奇遇 / 传承 | 会新增资源、随机性或跨轮能力层，污染 MVP-2A 验证面。 |
| 装备 / 武器系统 / 新武学池 | 会展开构筑矩阵，不服务本批“内容未耗尽”前提。 |
| 新属性 / 新状态 / 新结算规则 | 与 MVP-0 属性、状态、结算白名单冲突，留待完整版规则重开。 |
| 最终数值与时间锚点 | 气血、攻击、收益、成本、价格、轮长全部由 MVP-2B 重锚。 |

## 6. 规格化输入

`content.md` 只接收结构输入：

| 输入 | 要求 |
|---|---|
| 境界跨度 | 记录段位角色与解锁目的；数值列标 MVP-2B 定。 |
| 地图与主线节点 | 记录地图位置、用途、Boss 门槛与是否主线里程碑。 |
| Boss / 门槛节点 | 记录机械职责、允许标签、奖励指针与归隐声望关系。 |
| 挑战节点 | 记录解锁、目的、复用系统、奖励指针；不得形成秘境系统。 |
| 敌人变体 | 记录考验对象、允许标签、是否需新规则；新规则列必须为否。 |
| 残页接口 | 只登记与 `manual-fragments.md` 的接口，不复制残页规则。 |

## 7. MVP-2B 移交项

| 项 | MVP-2B 处理 |
|---|---|
| 敌人气血 / 攻击 / 防御 / 命中 / 闪避 | 统一随轮长与 Boss 需求矩阵重锚。 |
| 资源收益与突破成本 | 与离线收益、声望提速、秘籍永久加成一起复核。 |
| 地图 / Boss / 挑战耗时 | 以 3-5 天自然窗口和多轮回访节奏反推。 |
| 奖励强度 | 保证主线推进、真传试炼、声望商店职责不互相替代。 |
| 三武学门径通过性 | 验证每个门径有解法，卡点不是单门径硬锁。 |
