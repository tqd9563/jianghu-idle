## 1. 一句话结论

**建议立项**：秘籍残页以「6 本 × 3 页、全确定性获取、跨归隐保留、集齐整本才生效」的最小形态进入 MVP-2A，作为 3–5 天验证窗口的长期目标载体，并顺手成为声望商店第 4 轮买空后的长期 sink；星级、新招式、随机掉落、图鉴独立系统一概不做。

## 2. 评估

### 2.1 对照自然回流五前提（cadence.md §2）

| 前提 | 残页如何满足 |
|---|---|
| 仍有未完成目标 | 收集进度（X/18 页）是常驻可见的未完成目标，跨轮不清零（§3.4） |
| 仍有可见的下一步成长 | 缺页的「下一页来源」在秘籍阁逐本可查（§3.1 确定性序列），下一步永远可指认 |
| 离线推动但不替代关键决策 | 离线零残页产出（§3.1-E），获取全部绑定在线决策（挑战 / 归隐 / 兑换） |
| 回来后有真实决策入口 | 「打哪个 Boss 拿哪页 / 声望换页还是换节点 / 换路线收另一本」都是真决策 |
| 关闭前形成下次预期 | 「还差 1 页,下轮 Boss 3 掉」这类预期由确定性掉落直接给出，无需玩家脑补概率 |

### 2.2 对照 MVP-2A 退出标准（cadence.md §3）

| 退出标准 | 本方案贡献 |
|---|---|
| 3–5 天窗口内容不耗尽 | 18 页铺约 4–5 轮，窗口内预期集齐 2–4 本，窗口末仍有缺页与整条路线本长尾（§3.3） |
| 每次回访有可解释待办 | 待办 = 缺页清单 + 明确来源，埋点可验证（§4.3） |
| 一轮归隐不再压缩到 60 分钟 | **间接贡献**：跨轮收集给多轮游玩理由；轮长本身的拉长主责在 MVP-2B 重锚，本方案不越权承诺 |

### 2.3 与「图鉴 / 见闻录」的对比结论

选残页，图鉴不独立立项。图鉴记录「见过什么」——被动积累、零回访决策、效果为空或纯完成度；残页要求「去做什么」——每个渠道就是一条待办，且集齐有战斗内回报。此外秘籍阁列表页本身就承担了图鉴的收集呈现价值（做残页 ≈ 附带图鉴骨架，反之不成立）。若未来需要「江湖痕迹」类记录，作为秘籍阁的扩展页评审，不开新系统。

### 2.4 与方向记录的关系（继承 / 修订声明）

- **修订** `wuxue-collection-direction-note.md` §1/§3 的排期定位：「武学收集」的**最小子集**（秘籍残页收集）从「完整版方向」提前到 MVP-2A。理由：cadence.md §3 已将其列为优先候选，长期目标载体是 MVP-2 的真实缺口。
- **边界收窄**：本方案的「秘籍」不是新武学本体——不给新招式、新流派、新触发机制，只是既有三路线与属性白名单之上的收集与调节层；方向记录中「8 类武学 × 多渠道 × 图鉴」的完整框架仍属完整版。
- **原样继承**：星级 / 品阶分层（完整版方向）、战斗内手动技与蓝条（已拒绝）、§5 规格化前置检查四项（乘区归属、三列账、随机预算、归隐处理——本文 §3.6 逐项落实）。

### 2.5 防膨胀边界（对照 cadence.md §8）

以下常见收集设计**明确不做**，防止载体升级成系统群：

| 不做 | 一行理由 |
|---|---|
| 星级 / 品阶 / 强化 | 方向记录 §3 红线：强度分层把内容矩阵再乘一维，须在框架验证后进场 |
| 套装 / 组合效果 | 跨本组合 = 新乘区诱惑 + 平衡面爆炸，违反乘区 ≤2 纪律 |
| 抽卡 / 随机掉落池 | 双随机稀释卡点归因（方向记录 §5.3）；3–5 天窗口样本撑不起概率体验 |
| 残页零散效果 | 残页有效果 = 第 N 条数值成长线；整本生效才让「差 1 页」成为钩子 |
| 残页交易 / 分解 / 合成材料化 | 新资源新三列账，超出验证需要 |
| 门派 / 奇遇 / 秘境获取渠道 | 渠道挂在现有系统上，不为渠道立新系统（cadence §8） |

## 3. 系统设计

### 3.1 获取来源：四渠道 + 离线口径

**总原则：首发全确定性，零随机掉落。** 每个渠道按内容表预设的页序列发放「未持有的下一页」，玩家任何时刻都能在秘籍阁看到每本缺页的确切来源——「待办可解释」由此成为系统属性而非文案技巧。

| # | 渠道 | 规则 | 理由 |
|---|---|---|---|
| A | Boss 1 / Boss 2 **本轮首杀** | 每轮各发「推进序列」（通用本）的下一缺页 | 把每轮重打 Boss 变成有新回报的事，与声望里程碑（每轮重算）同构，强化螺旋重玩 |
| B | Boss 3 **本轮首杀** | 发「当前所选路线」路线本的下一缺页 | 沿用「师门指引」跟随当前路线的先例（`../mvp0/spec.md` §9.1）；换路线重玩 = 收集另一本，给换线一个收集理由 |
| C | 归隐结算 | 每次归隐发「推进序列」下一缺页，进「你将获得」栏 | 把归隐本身做成收集节点，直接强化「归隐值得做」支柱 |
| D | 声望商店「寻访残页」 | 声望兑换**任一自选缺页**，每轮限 1 次；压轴本尾页为本渠道专属 | 玩家自选 = 每轮一个真决策；限购防声望碾压挑战渠道；定位见 §3.5 |
| E | 离线 | **零产出**。`offline-rewards.md` 表 B 维持 `drop_group = none` | 残页是关键收集决策物，获取必须绑定在线时刻——与 MVP-1 §5「离线不推进关键决策」（A2 验收口径）相容；离线掉页会把长期目标变成挂机副产物，反噬回访动机 |

**与 MVP-0 §8.3「不重复发放首通奖励」的口径区分**：残页发放挂「本轮首杀」计数（每轮归隐重置），不是首通奖励的复发；首通阅历 / 解锁记录的既有规则零改动。实现侧须区分两个计数器，写入内容表规则说明（§4.2）。

### 3.2 秘籍作用：效果形态与公式影响面

**裁决建议：数值加成（通用本）+ 路线内触发参数强化（路线本）；不做新招式、不做新流派、不做集齐后二选一的 build 分化。** 理由：新招式 = 新触发机制，撞 MVP-0 §7.2 属性白名单与六状态「禁止新增」的锁，且 MVP-2 验证的是回访动机不是构筑深度。

| 类型 | 数量（推荐） | 效果形态 | 生效条件 |
|---|---|---|---|
| 通用本 | 3 本（入门 / 进阶 / 压轴）`[待 MVP-2B 复核]` | 白名单 7 属性内的永久加成，加法并入「永久加成总和」乘区（与声望节点同区） | 集齐整本即永久生效 |
| 路线本 | 3 本（华山 / 少林 / 唐门各 1）`[待 MVP-2B 复核]` | 该路线触发参数的追加档位（等价「第四重参悟」：剑意 / 护盾反伤 / 毒系数类参数，形态同 `../mvp0/content.md` §3.2） | 集齐且**当前路线对应**时生效；非对应路线时显示「未启用」不作废——收集物闲置不是死节点（区别于声望节点裁决,那是花钱买的一次性选择） |

**对 `../mvp0/formulas.md` 的影响面（收窄声明）**：只触碰 §3.1 白名单属性数值与 §3.5 三路线机制参数表；§1 战斗公式、§2 六状态规则、§7.2 结算顺序**零改动**；不新增属性、不新增状态、不新增乘区。

**锚点原则与调参优先级**（具体数字待 MVP-2B 重锚）：

- 锚点 1：全部秘籍效果的提速贡献之和 ≤ 声望 8 节点总和的约一半——声望保持永久成长主轴，秘籍是收集副轴。
- 锚点 2：单本效果的可感知度 ≥ 最低档声望节点（30 声望档）——集齐必须有体感，否则收集是空转。
- 调参顺序：① 先调获取节奏（页/轮），不动效果；② 再调通用本属性幅度；③ 最后调路线本触发参数（改它要重跑三路线对 Boss 需求矩阵）。

### 3.3 收集结构与回访节奏

**推荐结构：6 本 × 每本 3 页 = 18 页** `[待 MVP-2B 复核：随重锚后轮长调整，优先调页数不调本数]`。书名为占位、走文案冻结流程后定稿。

难度梯度靠**获取序列位次**表达，不靠效果复杂度：

| 梯度 | 书 | 铺设意图 |
|---|---|---|
| 入门 | 通用本 1 | 推进序列前 3 页——**首轮内可集齐**，第一次「集齐 → 生效」在首轮发生，教学收集回路 |
| 进阶 | 通用本 2 | 推进序列中段，跨 2–3 轮 |
| 压轴 | 通用本 3 | 前 2 页在推进序列末段；**尾页仅声望兑换（高价档）**——窗口末期的持续钩子 + 声望长 sink |
| 长尾 | 路线本 ×3 | 单本随 Boss 3 每轮 1 页、3 轮集齐；集齐全部 3 本需换路线多轮——窗口外余量，防收集提前见底 |

**每轮产出上限 = 4–5 页**（渠道 A×2 + B×1 + C×1 + D≤1）。按 MVP-2B 重锚后轮长（预期半天–2 天/轮，初案 §十四曲线），3–5 天窗口 ≈ 2–4 轮 → 窗口内集齐 2–4 本、始终有缺页在册。对照 cadence §5 回访节奏：每次回访打开秘籍阁即得待办（缺页 + 来源），关闭前的下次预期由「下一页来源」直接构成。节奏以**轮**为单位设计，轮长换算成天由 2B 定锚——本表不预设天数。

### 3.4 与归隐的关系（核心裁决点）

**建议：已获残页与已集齐秘籍全部跨归隐保留，含效果。** 理由：

1. **重置非惩罚原则**：没收收集物是最强的惩罚感（禀赋效应正向利用的反面）；初案归隐保留总表本就「图鉴保留」，方向记录 §5.5 的两行选择（挂武学等级=重置 / 挂图鉴=保留）中，长期目标载体只能选后者——每轮清零的收集撑不起 3–5 天跨多轮窗口。
2. **代价与约束**：跨轮保留 → 效果吃永久预算（初案「四、永久成长预算」软上限），与声望节点同乘区加法合并；MVP-2B 重锚时须复核「秘籍 + 声望节点」叠加后第二轮提速目标不被击穿（§3.2 锚点 1 即为此设的封顶）。
3. **保底归隐同样发放渠道 C 的页且不打折**：声望折扣 60% 已是保底的代价，残页再打折等于双罚，违反重置非惩罚。（进开放问题 #2 供确认。）

### 3.5 与声望经济的衔接

**定位：声望商店是残页的补齐渠道（兜底），不是主渠道；残页兑换是声望的长期 sink，接住第 4 轮买空平台期。**

- MVP-0 第 4 轮商店买空（`../mvp0/economy.md` §3）的结构性原因是「一次性节点 × 固定池」——追加多少节点都会再次买空；**可复购的兑换类 sink 才是平台期的长期解**。渠道 D（每轮 1 页自选 + 压轴尾页专属）让声望在节点买空后每轮仍有去处。
- 是否**另追加 2–3 个常规声望节点**：建议追加少量（延续 `../mvp1/spec.md` §2.1 已列的平台期衔接项），但其与本方案解耦、单独走经济表增补——本文不为凑完整而设计节点内容（docs/README §8）。
- 防倒挂：兑换价格档位须使「打 Boss 拿页」始终优于「攒声望买页」（价格 ≥ 现有最高节点档,具体待 MVP-2B）——商店解决的是「差一页的焦虑」，不是替代游玩。

### 3.6 资源三列账与规格化前置检查（方向记录 §5 逐项）

| 检查项 | 落实 |
|---|---|
| 乘区归属（§5.1） | 跨轮保留 → 通用本加法并入「永久加成总和」；路线本触发参数按等效强度计入永久预算；不开第三乘区 |
| 残页三列账（§5.2） | 来源 = 四渠道（§3.1）；主消耗 = 集齐成书（自动合成,无操作成本）；后期 sink = **首发有限池,全收集后渠道自然关闭（序列发完即止,商店类目下架）**——「收齐后残页无出口」以有限池方式规避,长线出口留给完整版残卷合成框架,登记为衔接敞口（§5 开放问题 #6） |
| 随机预算（§5.3） | 首发零获取随机,战斗内概率触发是唯一随机源——双随机叠加不存在,卡点归因不受稀释 |
| 归隐处理（§5.5） | 挂「图鉴保留」行,见 §3.4 |

### 4.4 UI 需求（仅清单与信息层级；视觉走原型流程,以 prototype.html + `DESIGN.md` 为准）

1. **主界面「秘籍阁」入口**：常驻,带收集进度摘要（X/18）。
2. **秘籍阁页**（信息层级由上至下）：总进度 → 逐本卡片（书名 / 页格 3 格 / 效果预览 / 生效状态含路线本「未启用」态）→ 缺页行内「下一页来源」指引。
