# 江湖无尽录：网页武侠放置游戏策划设计方案

> **设计目标：** 打造一款以武侠为主题的网页放置游戏，核心循环为修炼成长、闯荡江湖、归隐重修、声望代币购买永久加成。游戏需要具备足够长线深度，通过多系统、多流派、多轮转生和长期收集支撑玩家持续游玩。

## 一、游戏概念

**暂名：** 江湖无尽录

玩家从无名小卒开始，通过练功、闯荡、拜师、炼丹、锻造、经营门派、挑战秘境、参悟武学，逐步成长为一代宗师。游戏采用网页放置玩法，核心体验不是单一数值膨胀，而是让玩家在每一轮重入江湖时拥有不同流派、不同路线和不同阶段目标。

**核心循环：** 修炼资源 → 提升境界、武学、装备 → 挑战更高区域 → 获得稀有资源 → 归隐重修 → 用声望代币购买永久加成 → 下一轮推进更远。

## 二、基础成长循环

玩家初始拥有四类基础资源：

- **内力：** 主要修炼资源，用于提升境界、武学等级。
- **银两：** 用于购买药材、装备、门派建筑升级。
- **阅历：** 通过游历、战斗、奇遇获得，用于解锁功法和江湖事件。
- **声望：** 归隐重修后获得的高级代币，用于购买永久加成。

基础循环为：挂机修炼获得内力，派遣角色游历获得银两、材料、阅历，提升境界后解锁新地图、新门派、新系统，挑战关卡获得装备、秘籍、丹方，达到瓶颈后选择归隐重修并获得声望。下一轮依靠永久加成更快推进。

转生建议包装为 **归隐**、**破而后立**、**重入江湖**，避免现代感太强的"重生"说法。归隐后可保留声望天赋、已解锁图鉴、部分门派传承、特殊称号和奇遇记录。

## 三、境界与长期进度

境界是主线等级，也是内容解锁轴。推荐境界如下：

1. 江湖新丁
2. 初窥门径
3. 小有所成
4. 炉火纯青
5. 一流高手
6. 绝顶高手
7. 宗师
8. 大宗师
9. 武林神话
10. 破碎虚空

每个境界不应只是消耗资源升级，而应设置突破条件，包括内力达到要求、完成指定江湖挑战、拥有对应心法层数、消耗突破丹或特殊材料。后期可加入心魔试炼，避免纯挂机导致节奏单调。

## 四、声望与归隐重修系统

声望系统是长期循环的核心。玩家达到指定境界后，可选择归隐重修。归隐会重置大部分当前轮进度，但根据本轮成绩获得江湖声望、传承点、武道感悟、称号进度和门派影响力。

声望收益可由以下因素共同决定：

- 当前最高境界。
- 当前轮击败的强敌数量。
- 当前轮收集的秘籍数量。
- 完成的奇遇数量。
- 秘境最高层数。
- 当前轮耗时倍率修正。

### 声望天赋树

| 路线 | 定位 | 示例加成 |
|-|-|-|
| 修炼系 | 提高基础成长效率 | 内力获取提高、突破消耗降低、挂机修炼速度提高、离线收益上限提高、突破成功率提高 |
| 战斗系 | 强化闯关和秘境能力 | 攻击、防御、气血永久加成，暴击、连击、反击概率提升，武学伤害倍率提升 |
| 经营系 | 强化门派、炼丹、锻造、资源生产 | 银两收益提高、药材产量提高、锻造暴击概率提高、弟子上限提高、建筑成本降低 |
| 奇遇系 | 强化随机事件与收集体验 | 奇遇出现概率提高、稀有事件权重提高、游历收益提高、秘籍掉落率提升、可锁定一个奇遇结果 |
| 传承系 | 提供跨轮保留能力 | 保留一本低阶秘籍、开局继承部分银两、开局选择一个门派特性、额外获得传承点、解锁高阶天赋页 |

传承系不宜早期过强，否则会破坏重新开局的节奏。建议中后期开放，让玩家在多次归隐后逐步获得更强的跨轮控制能力。

## 五、武学系统

武学是构筑核心，建议分为拳掌、剑法、刀法、棍法、暗器、轻功、内功、奇门。每种武学应有明确定位：

- **剑法：** 高暴击、高爆发。
- **刀法：** 流血、破甲、持续压制。
- **拳掌：** 稳定输出、反击、控制。
- **棍法：** 防御、群攻、眩晕。
- **暗器：** 中毒、先手、削弱。
- **轻功：** 闪避、连击、行动速度。
- **内功：** 资源倍率、恢复、护盾。
- **奇门：** 特殊机制，例如复制、封印、反伤。

武学不应只提供数值，而应组成流派。示例流派包括寒梅剑流、血刀流、金钟罩流、五毒暗器流、逍遥轻功流。武学可通过门派学习、秘籍掉落、奇遇获得、声望商店兑换、秘境残页合成获得。

## 六、门派系统

门派是中期核心系统，不只是职业选择。玩家每轮可以拜入一个门派，不同门派影响本轮玩法。

| 门派 | 核心特色 |
|-|-|
| 华山派 | 剑法、暴击、突破速度 |
| 少林寺 | 防御、气血、反伤 |
| 丐帮 | 资源获取、群攻、游历收益 |
| 唐门 | 暗器、中毒、先手 |
| 明教 | 爆发、燃烧、低血增伤 |
| 逍遥派 | 轻功、闪避、奇遇 |
| 古墓派 | 控制、寒气、持续伤害 |
| 武当派 | 内功、护盾、后期成长 |

门派进度分为本轮贡献、永久门派声望、门派传承等级。归隐后本轮职位重置，但永久门派声望保留。门派职位从外门弟子、内门弟子、亲传弟子、护法、长老、掌门候选到代掌门，职位越高，解锁越多门派秘技和资源加成。

## 七、战斗与挑战

战斗自动进行，但玩家通过武学、装备、声望天赋和门派选择影响结果。基础属性包括气血、攻击、防御、身法、暴击、闪避、命中、破甲、内力恢复、控制抗性。

### 江湖地图

主线地图用于推进内容解锁。推荐区域包括新手村、洛阳城、华山道、塞北荒漠、苗疆密林、东海孤岛、昆仑雪岭、武林禁地。每个地图包含普通敌人、精英、首领和特殊事件。

### 秘境

秘境是长期挑战系统，类似爬塔。每层敌人更强，每 10 层一个 boss。归隐后秘境重置，并根据最高层数给予声望加成。秘境可掉落残页、稀有材料和特殊称号。主题可包括剑冢、藏经阁、血魔洞、机关城、心魔幻境。

### 武林大会

武林大会是周期玩法，可每日或每周刷新。玩家使用当前构筑自动挑战排名，产出荣誉币。荣誉币可兑换称号、头像框、特殊武学残页。该系统可采用异步镜像挑战，避免强实时 PvP 造成体验压力。

## 八、资源生产与经营系统

为了让玩法多样化，除了战斗成长，还应有经营线。中期可解锁自己的小门派或山庄。

| 建筑 | 功能 |
|-|-|
| 练功房 | 提高内力产出 |
| 药园 | 产出药材 |
| 丹房 | 炼制突破丹、属性丹 |
| 铁匠铺 | 锻造装备 |
| 藏书阁 | 提升秘籍研究速度 |
| 弟子堂 | 招募弟子 |
| 演武场 | 弟子历练，提高被动收益 |
| 山门 | 提高门派影响力和声望收益 |

弟子是中后期放置收益来源，品质可分为普通、优秀、精英、奇才、天骄、绝世。弟子可分配到修炼、采药、挖矿、游历、护山、参悟秘籍等任务，也可参与门派远征带回稀有资源。

## 九、炼丹、锻造与秘籍研究

### 炼丹

丹药包括突破丹、气血丹、聚灵丹、洗髓丹、悟道丹。炼丹拥有熟练度，熟练度可跨轮部分保留，形成长期成长。

### 锻造

装备部位包括武器、衣甲、护腕、靴子、玉佩、戒指。装备词条包括基础属性、流派加成和特殊效果，例如剑法伤害提高、流血层数上限增加、闪避后恢复内力、暴击时获得护盾。装备每轮大多重置，但图鉴和部分锻造配方永久保留。

### 秘籍研究

秘籍不是拿到就完全生效，需要研究。研究消耗阅历和时间，产出武学解锁、武学升级上限、被动加成和流派组合效果。后期可加入残卷合成，让玩家长期追求完整秘籍。

## 十、奇遇系统

奇遇负责变化感，避免纯数值挂机。奇遇可由游历、地图推进、门派任务、秘境探索、特定武学组合和特定声望天赋触发。

奇遇类型包括获得秘籍、遇到隐士、拾取神兵、被仇家追杀、发现洞府、误入禁地、获得特殊体质、选择正邪路线。奇遇最好带选择，例如在山洞中发现两卷秘籍时，玩家可选择阳刚心法提高攻击成长，选择阴柔心法提高闪避和控制，或烧毁秘籍获得特殊称号与声望倾向。

部分奇遇可跨轮追踪，形成长期收集目标。

## 十一、长期目标设计

| 阶段 | 目标 |
|-|-|
| 第一周 | 熟悉修炼、战斗、突破，解锁第一个门派，完成第一次归隐，点出第一批声望天赋 |
| 第一个月 | 尝试多个门派，解锁炼丹、锻造、弟子、秘境，形成第一个稳定流派，推进到宗师或大宗师 |
| 三个月 | 形成声望天赋分支，多门派声望成长，秘境深层推进，收集稀有秘籍和称号，解锁传承系高阶节点 |
| 半年以上 | 多流派构筑切换，高阶秘境挑战，周期武林大会排名，完成门派、秘籍、奇遇图鉴，解锁终局系统破碎虚空 |

## 十二、终局系统：破碎虚空

后期可开放破碎虚空作为超长期目标。玩家达到极高境界后挑战天道试炼，成功后进入更高层级：江湖 → 武林 → 天下 → 破碎虚空。

每次破碎虚空解锁一个天命槽。天命示例包括剑道天命、不灭天命、丹圣天命、天机天命、宗师天命。天命是极长期追求，但数量要控制，避免数值失控。

## 十三、商业化与留存建议

如果是网页免费游戏，建议采用轻度商业化，不破坏放置游戏核心。适合月卡、外观、战令、可选广告奖励；不建议直接售卖高额永久战力，否则会削弱声望系统价值。

留存点包括每日门派任务、每日秘境扫荡、每周武林大会、每周限时奇遇、每月新门派或新秘籍池、长期图鉴收集。

## 十四、推荐最小可行版本

第一版不要一次做完所有系统，建议 MVP 包含：

1. 修炼、境界、突破。
2. 地图战斗。
3. 三个门派：华山、少林、唐门。
4. 武学系统基础版。
5. 第一次归隐与声望天赋。
6. 简单炼丹。
7. 一个秘境爬塔。
8. 离线收益。
9. 图鉴记录。

> **MVP 验证目标：** 挂机成长 → 打不过 → 调整武学和资源 → 突破 → 归隐 → 永久变强 → 下一轮更快更远。只要这个循环成立，后续再逐步加入弟子、锻造、奇遇、武林大会和破碎虚空。
