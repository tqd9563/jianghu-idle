# 长线游戏设计

> **版本**：v2.7
>
> **日期**：2026-09-29
>
> **范围**：当前权威——长线 GDD 框架定义

## 1. 这是一款什么游戏

武侠主题的网页放置游戏。玩家从无名小卒开始，挂机修炼 → 提升境界 → 闯荡江湖 → 挑战 Boss → 归隐重修 → 用声望换永久加成 → 下一轮走得更远。

**核心循环**：练功 → 变强 → 推关 → 卡住 → 调整策略 → 突破 → 归隐 → 更强地重来。

**目标玩家**：喜欢数值成长和构筑决策的放置游戏玩家，每天 2–3 次、每次 3–10 分钟碎片时间。

## 2. 资源体系

每种资源都要回答三个问题：从哪来、花在哪、满了怎么办。

| 资源 | 从哪来 | 花在哪 | 满了怎么办 |
|---|---|---|---|
| 内力 | 挂机修炼 | 境界突破、内功升重、冲穴 | 周天分期缴纳，丹田随之扩容 |
| 银两 | 关卡通关、离线收益 | 书肆（武学、招式秘籍、上乘内功）；一世之内转修内功（境界 × 100） | 每世清零 |
| 门派贡献 | 门派任务（短差 2 小时 +40、长差 8 小时 +120，离线照算） | 本派贡献商店（绝学内功、绝学武学、绝学招式秘籍、归真卷册） | 每世清零 |
| 阅历 | —（冻结） | —（冻结） | 不再产出、界面隐藏，留给以后「提升悟性」 |
| 声望 | 归隐结算 | 声望商店（8 个永久加成节点） | 买空即满，跨轮继承 |

资源源汇表是设计的硬约束：新增任何一种资源，必须先补全"从哪来、花在哪、满了怎么办"三项，否则不进实现。

## 3. 境界轴

10 个境界，分成三段，段间有质变（玄关跃迁）。

| 段 | 境界 | 循环形态 | 当前状态 |
|---|---|---|---|
| 第一段 | 1–5（江湖新丁 → 一流高手） | 小周天（任督二脉） | 已实现 |
| 第二段 | 6–8（一代宗师 → 登峰造极） | 大周天（十二正经） | 数据已有，未接入 |
| 第三段 | 9–10（占位） | 天人/混元周天 | 占位，未设计 |

- 属性每境界 ×1.7（指数曲线），突破是体感最大的单次跃升（+70%）
- 境界 2 选一部内功（三个路数三选一）；本世突破过一次即可归隐
- **本版终点**：突破入境界 6 即小周天圆满、本版收官；境界 7 与大周天封存（`../systems/pacing/design.md` §4）
- 周天（经脉/窍穴/冲穴）增加突破过程的重量感和策略选择

## 4. 内功与路数

门径已并入内功（`../systems/sect-neigong/design.md` v2.2、`spec.md`）。内功是根基，武学是招式，门派是靠山。

### 三路数

| 路数 | 核心机制 | 优势 | 弱点 |
|---|---|---|---|
| 惊雷（爆发） | 暴击叠剑意，满层释放剑招 | 清小怪最快 | 怕高闪敌人 |
| 镇岳（护体） | 护盾 + 反伤，稳扎稳打 | Boss 战最稳 | 怕毒（绕过护盾） |
| 蚀骨（阴毒） | 叠毒 + 毒爆 | Boss 战最快 | 怕净化敌人 |

境界 2 在三部寻常内功中选一部，每一世开头重选，不收费。一世之内转修要付银两：同路数少 3 重，跨路数从头练。三路数各有优势场景，无唯一最优。

### 内功成长

- **重数**：内力灌注升重，价格每重 ×1.08；前十重按路数逐重加成，此后每 20 重折合一个境界（`../rules/formulas.md` §3.4）。内力每天都有持续的去处，战斗力随乘区每天往上走。
- **台阶**：登堂 / 入室 / 大成（原三重参悟）在第 2 / 4 / 6 重，高品质内功另有化境、归真。到了台阶先要顿悟，挂机每 10 分钟一判，悟性越高越快。
- **品质**：寻常 / 上乘 / 绝学，高品质火候略强、多一两个台阶，差距封顶一档。
- **悟性**：每一世天生不同（0.8–1.2），决定顿悟快慢。

### 武学

- 境界 2 起装配武学（槽数随境界 2→5），战斗中冷却好了、真气够了，每回合有 55% 机会随机出一门，替下普攻。
- 每门武学由若干招式组成，每一式按出招次数升熟练（生疏 → 熟练 → 精通 → 圆熟）；后几式要境界、真气与招式秘籍齐备，再靠顿悟领悟。
- 来源：书肆用银两买寻常武学与上乘招式秘籍；各图 Boss 首杀必掉上乘秘籍。与所修内功同路数的武学有共鸣（招式 ×1.1）。

### 门派

- 境界 3 起可拜入华山、少林、唐门之一，免费，不受所修路数限制；一世只拜一派，下一世重选。突破入境界 2 时听到一句拜山传闻。
- 门派任务同时只跑一件，到时自动结算、离线照算；贡献在本派商店换绝学内功、绝学武学、绝学招式秘籍与归真卷册。
- 本门绝学武学熟练阈值 ×0.8，不加战力。

## 5. 归隐与声望

每一世走完，选择「归隐」——散功重修，带着声望重新开始。长线版**每世从境界 1 重爬，一世随进度越活越长**：前期一世一天，后期一世五天，前 100 天约 33 世。寿元随境界提高，寿元将尽的那次上线推完前沿再归隐；乘区一世比一世高，重爬一世比一世快、爬得一世比一世远（`../systems/pacing/design.md` §2）。

- **归隐条件**：本世至少突破过一次（`../rules/economy.md` §1.4）
- **声望**：基础声望按「乘区加权时长」计，打到自己的前沿另有加成，首杀首通给一次性成就声望（`../rules/economy.md` §1）
- **永久加成**：宿慧（首达境界的一次性加成）与声望阁「修行感悟」（无限级，每级 +20% 基础产出）
- **归隐保留**：声望、声望节点、宿慧、已拥有的内功 / 武学 / 秘籍 / 卷册、窍穴图鉴、难度解锁、江湖历
- **归隐重置**：境界、内功重数与台阶、武学装配与本世领悟（熟练带一半）、门派与贡献、银两、窍穴进度、伤势、年岁；悟性重掷
- **寿终正寝**：寿元耗尽即自动归隐，声望照常、不受罚
- **被迫转世**：战死，声望照常全额，来世前 10 年修炼六成（`../systems/reincarnation/spec.md` §4）

## 6. 节奏与会话

| 参数 | 值 |
|---|---|
| 长线里程碑 | 第 1 / 7 / 21 / 42 / 100 天首达境界 2 / 3 / 4 / 5 / 6（境界 5 设计锚点原为第 50 天，门径并入内功后实测前移，`../systems/pacing/design.md` 裁决 25） |
| 标准玩家 | 每天 4 小时在线 + 20 小时离线，有效 16 小时 |
| 一世 | 前期约一天，后期约五天；寿元随境界提高（70 → 150 岁） |
| 离线收益 | 在线速率 × 60%，上限 24 小时 |
| 战斗前沿 | 三档难度错开，每个时段至少两条可推进的前沿 |

**开发节奏**：MVP-0/1/2 已收口，不再编号；后续转入「主题版本」模式，每个主题版本只回答一个问题（如「内功周天怎么接入核心循环」），不做功能堆叠。主题版本之间可以并行，独立合入。
