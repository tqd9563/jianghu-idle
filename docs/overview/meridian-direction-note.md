# 经脉/窍穴系统方向记录

> **状态**：**完整版方向记录，未规格化**——本文不是规格书，不含实现值，不进入 MVP-0/MVP-1 任何交付物。
> **决策状态**：用户已认可「记录此方向」（2026-07-05），**未立项**；完整版立项时以本文为讨论起点重新评审。
> **上游文档**：初案 §三（突破条件与底数分段规则）/ §四（永久成长预算与加成规则）、公式表 §3.3（完整版突破四层重量感占位）、量级边界文档（跃迁节点与规则层检查清单）、规格书 §6.1 v0.9（周天运转呈现体系）。
> **动机**：用户提议引入武侠经典的经脉/窍穴设定，并问「直接影响境界算法，还是做单独开放的乘区系统」。

## 1. 先排除的路径：独立乘区系统（违规，不做）

「经脉作为单独开放的乘区系统」与初案 §四的全局硬约束直接冲突：**每个最终量乘区 ≤ 2**（基础值 × 永久加成 × 本轮临时加成已满员）、**禁止以新增乘区作为成长感手段**——该条款明文为完整版全局规则，非 MVP-0 专属。经脉若做成独立乘法项即第三乘区，属明文违规路径，不予采用。经脉的价值须在既有规则层内表达，可行路径见下。

## 2. 三方案比较

| | 方案一：突破前置层 | 方案二：加法成长盘 | 方案三：机制解锁层 |
|---|---|---|---|
| 一句话 | 窍穴打通是境界突破的结构化前置条件 | 经脉图 = 武侠皮的成长棋盘，点亮窍穴给小额加成 | 窍穴（玄关）解锁机制，不给数值 |
| 数值归属 | **零新增数值来源**——它是公式表 §3.3 完整版「突破四层重量感」中本有占位的「前置条件」层的武侠皮 | 每窍穴加成**加法合并**进既有永久或本轮乘区（合规），吃对应加成域预算 | 零乘区零加法——解锁武学档位、构筑关键机制（如唐门通「手三阴」解锁毒爆二段）；对应初案 §三「质变由机制解锁承载」 |
| 与境界轴关系 | 子层/前置，不独立 | 并行子系统（资源建议复用阅历；若引新资源须先过三列账） | 绑定境界段间的 2–3 个**跃迁节点**（初案 §三：跃迁 = 一次性倍率 + 机制解锁 + 新内容层），玄关即跃迁节点缺的叙事皮 |
| 与「周天运转」皮肤的兼容 | **天然消解「行气冲窍」方案当年被否的虚构矛盾**：窍穴是一次性的「门」（对应境界这个一次性里程碑），周天是重复的「路」（每次突破重新运转）；门开则路变长（小周天 → 大周天），下个境界的运转获得叙事升级 | 需立措辞规矩：经脉窍穴 = 名词（通路节点），周天 = 动词（运转）。可视化红利：周天动画跑在经脉图上，点亮越多路径越华丽——呈现随成长变化，无数值纠缠 | 同方案一；玄关稀缺（全游戏 2–3 个），「冲开生死玄关」的仪式感强于「到达绝顶高手」 |
| 归隐处理 | 随境界重置（武侠语义自洽：归隐散功重修）；声望天赋修炼系可设「经脉记忆」类节点加速重开 | 建议随轮重置、归入本轮临时乘区，作为螺旋重玩的每轮咀嚼物；若永久保留则吃永久预算软上限，须进初案 §四预算表 | 跃迁随轮重经历；首通玄关可作称号/图鉴永久记录（初案归隐保留表已有此类目） |
| 主要风险 | 无新玩法面，纯结构化（但这正是它便宜的原因） | **最危险**：若只是「+10% 海绵」，即不产生新决策的复杂度，违反声望节点设计确立的「避免全是 +10%」原则；必须有分支互斥、与三路线构筑联动才值得做 | 内容成本最高（每个玄关都要配真机制） |
| 引入时机 | 完整版（依附突破四层重量感） | 完整版，且以「能产生构筑决策」为前提，否则不做 | 完整版（跃迁节点本身就是完整版结构） |

## 3. 推荐（方向记录，非立项决定）

**方案一为主干 + 方案三补跃迁；方案二为条件性延伸。**前两者实为同一设计在两个尺度上的应用：小境界的突破前置用普通窍穴（方案一），大境界段的跃迁用玄关（方案三）。理由：

1. **零新增乘区**——完全在既有规则层内活动，是给两个早已存在的占位（突破「前置条件」层、段间「跃迁节点」）穿武侠的皮，不是往骨架上加骨头；
2. **虚构自洽**——一次性的门 + 重复的路，「运转周天」语汇不但不冲突反而被补全（小周天/大周天的升级路径）；
3. **时机全在完整版**——MVP-0/MVP-1 零改动、零代码、零数值。

方案二仅在「能与三路线产生构筑联动、产生真决策」的前提下作为延伸选项，否则不做。

## 4. MVP-0 / MVP-1 边界

- **三个方案均不进 MVP-0/MVP-1**。除范围纪律（规格书 §2.3）外的具体理由：MVP-0 正在验证三路线构筑差异，插入新成长轴会把卡点归因从「构筑/境界/武学」三候选稀释成四候选，失败提示 7 级诊断规则须全部重写，污染标准 2/3 的测试。
- **当前唯一动作（零成本呈现层种子）**：周天运转的可视形态若做成「环形经脉上的窍点」而非普通直条，完整版经脉系统上线时视觉语言无缝衔接。此为原型视觉建议，不是系统实现。
