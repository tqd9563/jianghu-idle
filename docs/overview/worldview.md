## 3. 基调三定

1. **力量层级：写实武侠为基调。** 超凡感只由境界大段之间的跃迁节点承载（初案 §三「底数分段」）；终局「破碎虚空」的措辞与力量定位**转开放问题**（§10-1），在裁决前不得以该词展开新内容。
2. **时代：架空泛古典，不锚定真实朝代。** 洛阳、华山等作泛化的古典地名使用，不做历史考证，也不与任何真实历史事件挂钩。
3. **归隐主体：同一个人废功重修。** 不是转世、不是传人——图鉴、称号、江湖行迹跨轮保留的都是同一个人的江湖记忆，文案按此口径写。

---

## 4. 主角设定与两层世界结构

- **主角是独行散人**：从无名小卒起步，闯荡、习艺、归隐、再入江湖，不以任何门墙为归属——完整版拜入门派是每轮的权宜，散人是不变的本色。
- **流派与门派是两码事**：流派 = 武学传承（你练的是哪一脉功夫）；门派 = 江湖组织（你是否拜入是另一回事，组织玩法整体属完整版）。玩家先有功夫，之后才谈得上门墙。

---

## 5. 三系统定位：流派 / 主动武学 / 门派

| 系统 | 管什么 | 一句话定位 |
|---|---|---|
| 流派 | 怎么打 | **打法根基**：决定战斗核心机制（攒剑气爆发 / 护体反伤 / 叠毒），现为三选一、可改修 |
| 主动武学（完整版） | 用什么打 | **招式收集**：自由学习与装备，战斗中自动按概率触发（无手动按钮，`../mvp0/spec.md` §7.1 锁定不变） |
| 门派（完整版） | 靠着谁 | **江湖组织归属**：每轮拜入，给资源、职位玩法与独门武学（初案 §六） |

**铁律四条**：

1. **互不设资格限制**：流派不限制能学、能装什么武学；门派不限制流派；装某派武学也不要求改修该流派。三个选择各自独立，才都是真选择。
2. **门派好处的大头与流派无关**（资源、职位、通用加成、独门武学的收集价值对谁都一样）；「本门弟子修本门武学」的加成只是小甜头，小到不改变拜哪个门的决策。
3. **流派永远是战斗核心机制的载体**——禁止未来任何版本把它做成纯数值标签。
4. **带艺投师是常态**：修惊雷剑意拜入别的门派不奇怪，武侠里转益多师本就是主角标配；文案不得把这写成背叛。

## 6. 战斗力构成排序（完整版定性，数值完整版定）

```text
武学品质 / 等级 ≥ 功能与敌人的适配 > 流派搭配 > 类别（= 0，类别无强弱）
```

- **类别（剑法 / 棍法 / …）之间没有强弱，只有分工**（爆发 / 控制 / 护体 / 下毒…）；克制发生在「功能 vs 敌人机制」之间，不在类别之间。关键功能不在每个类别里都备一份，异类武学才有出场理由——这是完整版内容排布纪律。
- **流派核心机制由基础战斗行为驱动**（如：暴击就攒剑气），不依赖装备特定类别的武学——装一身别的类别，根基照常运转，只是转得慢一点。
- **与流派相配的武学有搭配加成，幅度封顶**：不超过一档武学品质差、不超过一次克制适配的收益——配得上是优势，配不上不是残废。越线则玩家只按类别清单打勾，收集自由就成了空话。

## 7. 命名与文案红线

1. **两个词库不重叠**：流派名（惊雷 / 镇岳 / 蚀骨，两字定式）不含组织专名；华山、少林、唐门只作**组织名与地名**（地图「华山古道」照旧）。
2. **不称玩家为弟子**：文案写「修习惊雷剑意」，永远不写「你是××弟子」。
3. **动词规矩**：流派用「修习 / 改修」，门派用「拜入 / 叛出」，不得混用。
4. **首触点定语**：流派选择界面须有一句「习其艺，不列门墙」意思的定语（措辞进文案冻结批次）。
5. **避强 IP 专名**：不用金庸、古龙等作品的专有名词（紫霞、独孤、降龙一类）；公域概念（金钟罩、五毒等）可用，但用前过一遍联想检查。初案 §六 的门派名 IP 风险标注继续有效。
6. **术语武侠语感**：新的玩家侧术语对齐既有体系（周天 / 闭关 / 参悟 / 归隐），二至四字，看得懂、猜得到。
7. **语体基准**：玩家侧文案语体对齐 `../mvp0/copy/` 冻结件（半文半白、短句、克制、不滥叹号）。

## 8. 源流设定（锁两条，留白一条）

- **锁**：① 三流派各有源流门派——武学必有出处，不是无源之水；② 传递者是源流的隐世前辈（真传试炼的守关隐士），散人败之而得真传，不入门墙。
- **留白**：哪个流派源出哪个组织、以及未来如何向玩家揭示，留待门派系统规格化批次——届时一行图鉴文案即可完成揭示（「惊雷剑意，相传源出××」）。

## 9. 留白条款（是条款，不是遗漏）

本文明确**不设定**，任何人（含 AI）不得自行补写：

- 具体朝代与历史大事件；
- 入门武学的来源（首轮所修功夫从何而来，不解释）；
- NPC 背景故事（守关隐士只有名字 + 一句话人设）；
- 主线剧情与章节叙事；
- 门派的名单、数量与恩怨史；
- 正邪阵营细节（初案 §十 的正邪路线维持概念占位）。

需要以上任何一项时，开专项批次先修订本文，再动笔写内容。
