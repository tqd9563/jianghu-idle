## 0. 怎么读这份文档

战报把战斗引擎每一次出手翻成一句话本式的叙述。每回合先出一行抬头 `【第 N 回合】`，下面按出手顺序一句一段。

**占位符**：模板里花括号里的字会在战斗中换成实际内容。

| 占位 | 换成什么 | 颜色 |
|---|---|---|
| `{我}` | 固定是「你」 | 墨金 |
| `{敌}` | 敌人名字（如「山道野狼」「「快刀」刘七」） | 朱红 |
| `{招}` | 招式名（见 §2） | 冷青 |
| `{功}` | 所修内功名（如「百川诀」）；没修内功时写「归海」 | 冷青 |
| `{伤}` | 这一下的伤害，取整 | 加粗；暴击、爆发、毒爆时用余烬色 |
| `{层}` | 层数（毒层）；v1.6 起通用句式不再用，中毒只写体感，层数只在毒印悬停 | 加粗 |
| `{上限}` | 层数上限（毒层上限），取当前生效值；v1.6 起通用句式不再用，层数只在毒印悬停 | 正文色 |
| `{盾}` | 护体真气挡下的伤害 | 加粗 |
| `{爆}` | 牵机镖引爆的毒伤 | 加粗 |

**变体怎么挑**：同一类句子写了 2–3 条，每场开战时掷一个种子，按种子随机取，相邻两回合不取同一条。同一场战斗无论重放多少次，文字都一样；换一场就换一种顺序。

**数字从哪来**：所有数字都是引擎当场结算出的实际值，与血条、统计同源，不做美化。

**句子怎么写**（v1.6 起，新句一律按这几条检查）：战报当一本微型小说来写，措辞偏文言，参照《天下刀宗》等武侠小说的战斗描写。

1. **一句三拍**：起手动作 → 落点（部位、兵器去向）→ 对方身体反应 + 数字。每拍是一个具体动作；「又快又狠」「势大力沉」「结结实实」「足足」这类评价词不能替代动作。
2. **机制写成体感**：特效、状态、狂暴只写身上发生了什么（手臂一麻、门户大开、扑咬一下狠过一下），不写「之后更容易 / 更难」「一回合比一回合」这类规则句；规则留给石印悬停。层数（叠浪、毒）不进战报。
3. **旁白不下场**：叙述始终是冷静的书面语。敌人可以粗野（啐、骂），旁白不用「嗷嗷叫着」「连滚带爬」「懒得计较」这类市井口吻与评价。
4. **主语不漂移**：一句最多换一次主语；「受了 / 损了 / 蚀去{伤}点」前承受者必须明确；招式名不裸作主语，用「一式{招}」「使出{招}」包住。
5. **意象放开用**：比喻、四字格不限数量，取自然与器物（匹练、寒星、骤雨、江河决堤、金铁）；拟声（嗤、喀、砰然）可代替形容词；可写周遭受波及（青砖一震、衣襟应声而裂）。
6. **去套话**：「看准一个破绽」「虚晃一招趁回防不及」在同一分组只许出现一次；落点动词按伤情换（受了 / 损了 / 蚀去 / 折去）。
7. **时序词提速**：「下一瞬」「招势未尽」「甫一照面」用来接上下句（排山倒海接会心、补刀接招后）。
8. **叹号只给爆发**：普攻暴击、狂暴不用叹号，靠动词与落点出力；只有排山倒海与毒爆保留。
9. **用词取书面**：不用「得」字补语描述结果（打得…弯下腰、跳得慢了、拍得一歪），直接写结果（腰身一折、起势稍迟、身形一晃）；不用「挨了、顺手、一把、半晌、只管、冷不防、什么、没能、自己」这类口语词，换作「中了 / 着了、回手、一蓬、良久、一味、倏然、未能」。出手瞬间用「未及、稍迟、之际、方、倏然」拉节奏，不用「到一半、慢了」。可用「X 未至，Y 已……」先声句（刀锋未至，森寒已逼面而来）、「为……所」被动句（为劲风所扫）与「霎时间、顷刻间、当是时」一类连接词。
10. **句首错开**：同一组变体不要都写成「{我}+四字短语，」开头。句首在几种形态间轮换：主语带长动作（{我}手中长刀挟风雷之势当头斩落）、兵器或招势起句（斗大枪花自{我}枪头抖出）、对方起句（{敌}腰间空门方露）、时间状语起句（右拳虚引之间）。
11. **不写仙侠化描写**：真气凝形成盾、雷光化剑、罡炁、魔气这类玄幻写法一概不用，劲力只写成落在身上的感受。

## 1. 敌人类型怎么分

句子按敌人类型分三套口吻：野兽扑咬、草莽乱打、高手沉稳。按下面顺序判断，先命中先算：

1. 名字带绰号（以「」开头）或是精英 / Boss → **江湖高手 / 头目**
2. 名字里有兽类字（犬、狼、虎、豹、熊、蛇、猪、猿、鹰、狐、蛟、兽） → **野兽**
3. 名字里有行当 / 身份字（剑客、刀客、武者、镖师、僧、道人、游侠、都督、寨主、头目、头子） → **江湖高手 / 头目**
4. 其余 → **山贼草莽**

例：村口恶犬 = 野兽；拦路泼皮、醉酒闲汉 = 山贼草莽；「钻山豹」侯四、古道剑客、黑风寨主 = 江湖高手。

## 3. 通用句式

### 3.1 你的普攻 · 命中（按手中兵器）

普攻句子看手里拿的是什么，不看所修内功的路数：兵器槽有剑 / 刀 / 枪 / 棍就用对应一组；兵器槽空着、暗器槽有物用暗器一组；都空着写拳脚（修镇岳路数的写拳掌）。

**赤手（拳脚）**

1. {我}一拳当胸捣出，劲风未至，{敌}已觉胸口一窒，闷哼出声，受了{伤}点伤害。
2. {敌}来势正急，{我}侧身让过，反掌按落其肩头，掌劲吐处，对方身形一晃，造成{伤}点伤害。
3. 右拳虚引之间，{我}身形倏转，已至{敌}侧方，一腿横扫，正中腰眼，造成{伤}点伤害。

**剑**

1. {我}剑尖化作一点寒星，直点{敌}胸前，逼得对方连退两步，造成{伤}点伤害。
2. {敌}只见{我}身形一晃，肩头已中反手一剑，带起一蓬血花，造成{伤}点伤害。
3. {我}剑尖斜斜一引，{敌}举手来格，剑锋却于中途折转，划过其腰间，造成{伤}点伤害。

**赤手 · 镇岳路数（拳掌）**

1. {我}沉步踏落，足下青砖为之一震，借这一踏之力，一拳直捣{敌}中门，造成{伤}点伤害。
2. {敌}一击方至，{我}硬受其势，反掌推在其肩头，对方踉跄退开三步，造成{伤}点伤害。
3. 肘膝连环撞出，{我}步步进逼，{敌}退无可退，胸腹连中数记，受了{伤}点伤害。

**刀**

1. {我}手中长刀斜斜劈落，刀光乍起处，锋刃已入{敌}肩头半寸，造成{伤}点伤害。
2. {敌}腰间空门方露，{我}拧腰横刀，刀锋掠过，衣襟应声而裂，造成{伤}点伤害。
3. 一刀自下而上撩起，{敌}仰身急避，{我}刀锋已在其胸前划开一道血口，造成{伤}点伤害。

**枪**

1. 斗大枪花自{我}枪头抖出，虚实之间，枪尖已点中{敌}胸前，造成{伤}点伤害。

### 5.2 通用追加

**出招被闪开**（替换整句）

1. {我}一式{招}递出，{敌}堪堪避开，招势落在空处。
2. {我}一式{招}尚未使老，{敌}已看破来路，抽身退开。

1. 这一式正中要害，{敌}周身一震。
2. 适逢{敌}旧力已尽、新力未生，这一式尽数打入要害。

### 5.3 招式特效追加句

每一式都带特效（`../../systems/wuxue-catalog/design.md` W17），只在本招特效**确实生效**时追加：持续类挂上、回气 / 回元 / 护体 / 附毒 / 透劲结算了、封穴掷中、引爆确实炸了毒层（`{爆}` 大于 0）。「必暴」不另写，已由 §5.2 暴击句体现；「连击」掷中时不追加本句，改走 §5.4 的补刀事件。

|---|---|

## 6. 一句话怎么拼

同一次出手的几段按固定顺序接在一起：

1. **主句**：§3 / §4 / §5.1 里挑一句；
2. **暴击追加**（武学出招暴击时）：§5.2；
3. **特效追加**：§5.3；
4. **状态追加**：归海会心后追加、唐门毒层（§4）；敌方出手的破甲、护体（§3.4）。

例（华山，第 3 回合，流云剑第一式暴击）：

> 你剑势舒展，如白云出岫，正是这招**流云出岫**，看似漫不经心，剑尖已递到**山道野狼**眼前，造成 **34** 点伤害。这一式正中要害，**山道野狼**周身一震。
