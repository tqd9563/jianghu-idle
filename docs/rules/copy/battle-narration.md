## 0. 怎么读这份文档

战报把战斗引擎每一次出手翻成一句话本式的叙述。每回合先出一行抬头 `【第 N 回合】`，下面按出手顺序一句一段。

**占位符**：模板里花括号里的字会在战斗中换成实际内容。

| 占位 | 换成什么 | 颜色 |
|---|---|---|
| `{我}` | 固定是「你」 | 墨金 |
| `{敌}` | 敌人名字（如「山道野狼」「「快刀」刘七」） | 朱红 |
| `{招}` | 招式名（见 §2） | 冷青 |
| `{功}` | 所修内功名（如「惊雷诀」）；没修内功时写「剑意」 | 冷青 |
| `{伤}` | 这一下的伤害，取整 | 加粗；暴击、爆发、毒爆时用余烬色 |
| `{层}` | 层数（剑意层、毒层） | 加粗 |
| `{上限}` | 层数上限（剑意需求、毒层上限），取当前生效值 | 正文色 |
| `{盾}` | 护体真气挡下的伤害 | 加粗 |
| `{爆}` | 牵机镖引爆的毒伤 | 加粗 |

**变体怎么挑**：同一类句子写了 2–3 条，按回合号轮流取（第 N 回合取第 `(N + 偏移) 除以条数的余数` 条），不掷骰子。同一场战斗无论重放多少次，文字都一样。

**数字从哪来**：所有数字都是引擎当场结算出的实际值，与血条、统计同源，不做美化。

## 1. 敌人类型怎么分

句子按敌人类型分三套口吻：野兽扑咬、草莽乱打、高手沉稳。按下面顺序判断，先命中先算：

1. 名字带绰号（以「」开头）或是精英 / Boss → **江湖高手 / 头目**
2. 名字里有兽类字（犬、狼、虎、豹、熊、蛇、猪、猿、鹰、狐、蛟、兽） → **野兽**
3. 名字里有行当 / 身份字（剑客、刀客、武者、镖师、僧、道人、游侠、都督、寨主、头目、头子） → **江湖高手 / 头目**
4. 其余 → **山贼草莽**

例：村口恶犬 = 野兽；拦路泼皮、醉酒闲汉 = 山贼草莽；「钻山豹」侯四、古道剑客、黑风寨主 = 江湖高手。

### 5.2 通用追加

**出招被闪开**（替换整句）

1. {我}使出一招{招}，却被{敌}堪堪避开，招式落空。
2. {招}使到一半，{敌}已抽身退开，{我}这一招扑了个空。

**出招暴击**（接在招式句后面）

1. 这一招正中要害，力道倍增！
2. 恰逢破绽，这一下伤得极重！

### 5.3 招式特效追加句

只在带特效的那一式后面追加（寻常 / 上乘 / 绝学武学在第一式和最后一式带特效；落星剑、降魔杵法、牵机镖每式都带）。「必暴」不另写，已由 §5.2 暴击句体现。

| 特效 | 追加句 |
|---|---|
| 护体 | 护体真气随招而生，又厚一层。 |
| 回气 | 招随气转，这一式没耗真气。 |
| 附毒 | 锋上淬毒，{敌}又添两层毒。 |
| 蓄势 | 剑势层层相叠，后招更重。 |
| 反震 | 杵借身沉，连一身筋骨之力也压了上去。 |
| 引爆 | 机括一响，{敌}体内积毒尽数炸开，其中{爆}点是毒伤。 |

「引爆」只在确实引爆了毒层（`{爆}` 大于 0）时追加。

## 6. 一句话怎么拼

同一次出手的几段按固定顺序接在一起：

1. **主句**：§3 / §4 / §5.1 里挑一句；
2. **暴击追加**（武学出招暴击时）：§5.2；
3. **特效追加**：§5.3；
4. **状态追加**：华山剑意（§4）、唐门毒层（§4）；敌方出手的破甲、护体（§3.4）。

例（华山，第 3 回合，流云剑第一式暴击）：

> 你剑势舒展，如白云出岫，正是这招**流云出岫**，看似漫不经心，剑尖已递到**山道野狼**眼前，造成 **34** 点伤害。这一招正中要害，力道倍增！剑意又凝一分（2 / 5）。
