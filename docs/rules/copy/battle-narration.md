## 0. 怎么读这份文档

战报把战斗引擎每一次出手翻成一句话本式的叙述。每回合先出一行抬头 `【第 N 回合】`，下面按出手顺序一句一段。

**占位符**：模板里花括号里的字会在战斗中换成实际内容。

| 占位 | 换成什么 | 颜色 |
|---|---|---|
| `{我}` | 固定是「你」 | 墨金 |
| `{敌}` | 敌人名字（如「山道野狼」「「快刀」刘七」） | 朱红 |
| `{招}` | 招式名（见 §2） | 冷青 |
| `{功}` | 所修内功名（如「百川诀」）；没修内功时写「归海」 | 冷青 |
| `{伤}` | 这一下的伤害，取整 | 加粗；暴击、爆发、毒爆时用余烬色 |
| `{层}` | 层数（毒层） | 加粗 |
| `{上限}` | 层数上限（毒层上限），取当前生效值；v1.6 起通用句式不再用，层数只在毒印悬停 | 正文色 |
| `{盾}` | 护体真气挡下的伤害 | 加粗 |
| `{爆}` | 牵机镖引爆的毒伤 | 加粗 |

**变体怎么挑**：同一类句子写了 2–3 条，每场开战时掷一个种子，按种子随机取，相邻两回合不取同一条。同一场战斗无论重放多少次，文字都一样；换一场就换一种顺序。

**数字从哪来**：所有数字都是引擎当场结算出的实际值，与血条、统计同源，不做美化。

**句子怎么写**（v1.6 起，新句一律按这七条检查；参照武侠小说战斗描写的手法）：

1. **一句三拍**：起手动作 → 落点（部位、兵器去向）→ 对方身体反应 + 数字。每拍是一个具体动作；「又快又狠」「势大力沉」「结结实实」「足足」这类评价词不能替代动作。
2. **机制写成体感**：特效、状态、狂暴只写身上发生了什么（手臂一麻、门户大开、扑咬一下狠过一下），不写「之后更容易 / 更难」「一回合比一回合」这类规则句；规则留给石印悬停。层数（叠浪、毒）不进战报。
3. **旁白不下场**：叙述始终是冷静的书面语。敌人可以粗野（啐、骂），旁白不用「嗷嗷叫着」「连滚带爬」「懒得计较」这类市井口吻与评价。
4. **主语不漂移**：一句最多换一次主语；「受了 / 损了 / 蚀去{伤}点」前承受者必须明确；招式名不作主语。
5. **一句一象**：比喻至多一个，取自然物象（潮、雪、鸦、墨迹）；拟声（嗤、喀、闷响）可代替形容词。
6. **去套话**：「看准一个破绽」「虚晃一招趁回防不及」在同一分组只许出现一次；落点动词按伤情换（受了 / 损了 / 蚀去 / 折去）。
7. **时序词提速**：「下一瞬」「招势未尽」「甫一照面」用来接上下句（排山倒海接会心、补刀接招后）。
8. **叹号只给爆发**：普攻暴击、狂暴不用叹号，靠动词与落点出力；只有排山倒海与毒爆保留。

## 1. 敌人类型怎么分

句子按敌人类型分三套口吻：野兽扑咬、草莽乱打、高手沉稳。按下面顺序判断，先命中先算：

1. 名字带绰号（以「」开头）或是精英 / Boss → **江湖高手 / 头目**
2. 名字里有兽类字（犬、狼、虎、豹、熊、蛇、猪、猿、鹰、狐、蛟、兽） → **野兽**
3. 名字里有行当 / 身份字（剑客、刀客、武者、镖师、僧、道人、游侠、都督、寨主、头目、头子） → **江湖高手 / 头目**
4. 其余 → **山贼草莽**

例：村口恶犬 = 野兽；拦路泼皮、醉酒闲汉 = 山贼草莽；「钻山豹」侯四、古道剑客、黑风寨主 = 江湖高手。

## 3. 通用句式

### 3.1 你的普攻 · 命中（按手中兵器）

普攻句子看手里拿的是什么，不看所修内功的路数：兵器槽有剑 / 刀 / 枪 / 棍就用对应一组；兵器槽空着、暗器槽有物用暗器一组；都空着写拳脚（修镇岳路数的写拳掌）。

**赤手（拳脚）**

1. {我}踏前半步，一拳当胸捣去，{敌}闷哼一声，受了{伤}点伤害。
2. {我}侧身让过来势，顺势一掌拍在{敌}肩头，拍得对方身形一歪，造成{伤}点伤害。
3. {我}拳头虚晃，脚下却已绕到侧面，一脚踢在{敌}腰眼上，造成{伤}点伤害。

**剑**

1. {我}踏步抢攻，剑尖直点{敌}胸前，逼得对方连退两步，造成{伤}点伤害。
2. {我}身形一晃，反手一剑削向{敌}肩头，带起一蓬血花，造成{伤}点伤害。
3. {我}剑尖一偏，{敌}随之回防，腰间空门却已被{我}一剑扫过，造成{伤}点伤害。

**赤手 · 镇岳路数（拳掌）**

1. {我}马步一沉，一拳直捣{敌}中门，造成{伤}点伤害。
2. {我}硬接来势，反手一掌推在{敌}肩头，推得对方一个趔趄，造成{伤}点伤害。
3. {我}步步进逼，肘膝连撞{敌}胸腹，对方退无可退，受了{伤}点伤害。

**刀**

1. {我}刀光一闪，顺势劈在{敌}肩头，刀锋入肉半寸，造成{伤}点伤害。
2. {我}拧腰横刀，一刀扫过{敌}腰间，衣襟裂开，造成{伤}点伤害。
3. {我}刀锋一抬作势劈落，{敌}举臂去格，刀背却已沉沉砸在其背上，造成{伤}点伤害。

**枪**

1. {我}长枪一抖，枪尖抖出一朵枪花，正点在{敌}胸前，造成{伤}点伤害。
2. {我}枪杆一拨，拨开来势，顺手一枪扎进{敌}肩头，造成{伤}点伤害。
3. {我}枪杆横扫，抽在{敌}腰间，打得对方踉跄半步，造成{伤}点伤害。

**棍**

1. {我}抡棍横扫，一棍抽在{敌}肋下，闷响一声，造成{伤}点伤害。
2. {我}棍头一点，正戳在{敌}胸口，逼得对方连退两步，造成{伤}点伤害。
3. {我}棍梢贴地一扫，{敌}跳得慢了，小腿上挨了结实一记，造成{伤}点伤害。

**暗器**

1. {我}袖底一扬，两枚透骨钉破空而出，钉在{敌}肩上，造成{伤}点伤害。
2. {我}脚下游走，顺手一把铁蒺藜洒出，{敌}躲过几枚，仍有几枚咬进肉里，造成{伤}点伤害。
3. {我}指间寒光一闪，一枚毒针钉进{敌}臂上，造成{伤}点伤害。

### 3.2 你的普攻 · 暴击（按手中兵器）

分组同 §3.1。

**赤手（拳脚）**

1. {敌}一拳递空，胸前门户大开，{我}抢步进身一拳正中其心口，对方双足离地，跌出丈外，受了{伤}点伤害。
2. {我}掌影一晃，{敌}尚未看清，胸口已被一掌印实，闷哼着退了三步，受了{伤}点伤害。

**剑**

1. {敌}回防稍慢，{我}剑走偏锋直取要害，剑锋入肉极深，造成{伤}点伤害。
2. 剑光一闪，{我}这一刺正中{敌}空门，剑尖透背而出，造成{伤}点伤害。

**赤手 · 镇岳路数（拳掌）**

1. {我}沉腰发力，一拳打得{敌}弯下腰去，对方半晌直不起身，受了{伤}点伤害。

### 5.2 通用追加

**出招被闪开**（替换整句）

1. {我}一式{招}递出，{敌}堪堪避开，招势落在空处。
2. {我}{招}尚未使老，{敌}已看破来路，抽身退开。

**出招暴击**（接在招式句后面）

1. 这一式正中要害，{敌}周身一震。
2. 恰撞在{敌}回防的空当，这一下落得实了。

### 5.3 招式特效追加句

每一式都带特效（`../../systems/wuxue-catalog/design.md` W17），只在本招特效**确实生效**时追加：持续类挂上、回气 / 回元 / 护体 / 附毒 / 透劲结算了、封穴掷中、引爆确实炸了毒层（`{爆}` 大于 0）。「必暴」不另写，已由 §5.2 暴击句体现；「连击」掷中时不追加本句，改走 §5.4 的补刀事件。

| 特效 | 追加句 |
|---|---|
| 护体 | 招势未歇，一层护体真气已随之鼓荡而起。 |
| 回气 | 招随气转，耗去的真气顺着经脉又回了大半。 |
| 附毒 | 锋上淬毒，{敌}伤处转眼泛出一圈青黑。 |
| 运劲 | 一股劲力自丹田贯入四肢，{我}只觉双臂沉了几分。 |
| 连击 | 招势未尽，{我}顺手又补了一记。 |
| 凝眸 | {我}心神一凝，{敌}招式间的空隙在眼中纤毫毕现。 |
| 轻身 | {我}收势时足下一轻，身形已飘出半步。 |
| 回元 | 招意圆转，一缕真气循经而回，归入丹田。 |
| 透劲 | 劲力透过皮肉直入脏腑，{敌}的护身功夫拦它不住。 |
| 封穴 | 这一下正点在穴道上，{敌}半边身子顿时僵住。 |

### 5.4 连击补刀与封穴

连击掷中后另起一条事件（有伤害数字）；封穴生效的那一回合，敌方行动替换成一句：

| 事件 | 句子 |
|---|---|
| 连击 · 补上 | 招势未尽，{我}手腕一翻又补一记，再添{伤}点伤害。 |
| 连击 · 落空 | 招势未尽，{我}手腕一翻又补一记，{敌}侧身让过。 |
| 封穴 | {敌}穴道受制，僵立原地，这一下竟出不了手。 |

## 6. 一句话怎么拼

同一次出手的几段按固定顺序接在一起：

1. **主句**：§3 / §4 / §5.1 里挑一句；
2. **暴击追加**（武学出招暴击时）：§5.2；
3. **特效追加**：§5.3；
4. **状态追加**：归海会心后追加、唐门毒层（§4）；敌方出手的破甲、护体（§3.4）。

例（华山，第 3 回合，流云剑第一式暴击）：

> 你剑势舒展，如白云出岫，正是这招**流云出岫**，看似漫不经心，剑尖已递到**山道野狼**眼前，造成 **34** 点伤害。这一式正中要害，**山道野狼**周身一震。

## 7. 战报收尾行

胜利句之后另起一行，墨金 / 暖金色，每项一行：

| 场景 | 文案 |
|---|---|
| 首通 | `获得：银两 {银两}` |
| 回刷 | `获得：银两 {银两}（回刷五成）` |
| Boss 首杀掉落 | `首杀掉落：{物品}` |
| 首次击败精英 / Boss | `名号传开：挑落{敌名}，声望 +{声望}` |
| 拾得装备 | `拾得：{装备名}`（名字按品阶着色；行囊满了接 `（行囊已满，卖得 {银两} 两）`） |
| 拾得武学 | `拾得：{武学名} 全本`（寻常整门）/ `拾得：{武学名} 残页 · 第X式`（悬停式名）；重复的接 `已有 · 银两 +{两}`（寻常整门重复不写「全本」） |

- 数值是实际入账值（回刷五成、连打同一关递减之后），与侧栏资源增量一致（同 `battle.md` §1 口径）。
- 拜山传闻（突破到境界 2 后的第一场战斗）在战报最上方单独一行：`江湖传闻　{传闻正文}`。
