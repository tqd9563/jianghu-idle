## 1. 胜利收益行（战斗日志末行，交付【前端 1】）

> **v1.2 起**：收获行措辞改由 `battle-narration.md` §7 定义（`获得：银两 {银两}`，回刷加 `（回刷五成）`；首杀掉落、名号传开各占一行），下表保留为历史。下方「显示规则」的数值口径仍然有效。

| 场景 | 文案（v1.1，已被 battle-narration.md §7 取代） |
|---|---|
| 首通 | `收获　银两 +{银两}` |
| 回刷 | `回刷收获　银两 +{银两}` |
| 名号传开（首次击败精英 / Boss，跨世只一次） | `名号传开　挑落{敌名}，江湖为之侧目　声望 +{声望}` |

**显示规则**：
- 阅历已冻结（关卡不再发阅历），收获行不写阅历项。
- 数值 = **实际入账值**（回刷银两 50%、阅历 0 与连续回刷衰减 ×0.8^(n−1) 之后的实发数，取整），与资源面板增量逐位一致（同源同值）。
- v1.1 起关卡不掉内力（`../formulas.md` §6.1），收获行不再有内力项。「名号传开」行紧跟收获行、金色，只在首次击败精英或 Boss 时出现（`../economy.md` §1.3），声望即时入账。
- Boss/精英首通同格式，不另设措辞（奖励值本就不同）。
- 两态措辞差异仅在行首「回刷」二字，防止玩家把回刷收益误读为另一套规则。

## 2. 失败战报（失败弹窗，双条诊断下方，交付【前端 2】）

> **v1.2 起**：战败改为整屏演出（原型 `#d-fail`）：`战 败` / 敌名 / `第 {关} 关 · 鏖战 {回合} 回合` / `剩余气血 {敌余}%` 墨条 / 按钮 `立即重试`、`回去修炼 · 周天 {进度}%`。演出上**不再铺**诊断与战报长句——诊断双条与下列战报各行原文不变，改放进「剩余气血」一行的悬停里（诊断在上、战报在下，不再有「战报」区块标题）。

**区块标题**：（v1.2 起不显示）
**结构总则**：通用 4 行（恒显）→ 路线行（按当前路线三选一）→ 敌方机制行（条件显示）。通用行**取代**旧版「回合数/敌余血/命中率」三项独立显示，不得双份并存。战败诊断双条（主提示 + 至多一条次优先）仍在战报之上，文案取公式表 §5，始终免费（声望经济表 §6.5）。

### 2.1 通用行（恒显，4 行）

```text
历时 {rounds} / 50 回合
我方输出 {dmg_dealt}（敌余 {enemy_hp_pct}%）
我方承伤 {dmg_taken}（余 {player_hp_pct}%）
实际命中 {hit_pct}%
```

- 「/ 50」为回合上限常量（公式表 §1.4），调参须同步改文案。

### 2.2 路线行（按当前路线显示对应一行）

| 路线 | 文案 |
|---|---|
| 华山 | `暴击 {crit_n} 次 · 排山倒海 {burst_n} 次（占输出 {burst_pct}%）` |
| 少林 | `护盾吸收 {shield_abs} · 反伤输出 {thorns_out}（占输出 {thorns_pct}%）` |
| 唐门 | `毒伤占输出 {poison_pct}% · 毒爆 {burst_n} 次 · 毒层被清 {purge_n} 次` |

### 2.3 敌方机制行（条件显示，逐标签一行）

| 行 | 文案 | 显隐规则 |
|---|---|---|
| 破甲 | `身中破甲 {ab_max} 层` | 仅 `ab_max > 0` 时显示 |
| 反伤 | `承受反伤 {thorns_taken}` | 仅 `thorns_taken > 0` 时显示 |

> 敌方毒对玩家的伤害不设战报行——战斗日志已逐回合明示（`毒入肌理（{n} 层），你受到 {x} 毒伤（绕过护盾）`），且已计入「我方承伤」。

### 2.4 字段口径表（工程实现输入，与引擎 `FightStats` 字段对照）

| 变量 | 引擎字段 | 口径 |
|---|---|---|
| `{dmg_dealt}` | `dmgDealt` | 我方总输出 = 普攻 + 排山倒海 + 毒伤 + 毒爆 + 反伤输出，取整显示 |
| `{dmg_taken}` | `dmgTaken` | 我方总承伤（减免后，**含护盾吸收部分**：敌攻 + 反噬 + 敌毒），取整显示 |
| `{hit_pct}` | `pHitRate` | 实际命中率（RNG 模式为实测值），四舍五入整数百分比 |
| `{burst_pct}/{thorns_pct}/{poison_pct}` | `burstDmg / thornsOut / poisonDmg` ÷ `dmgDealt` | 占比分母统一为我方总输出；`dmgDealt = 0` 时显示 0%；四舍五入整数 |
| `{poison_pct}` 的分子 | `poisonDmg` | 毒伤总量**含毒爆** |
| `{thorns_taken}` | `thornsTaken` | 所受反伤（减免后、**护盾吸收前**）——与诊断规则 5 判定同源同值 |
| `{ab_max}` | `abStacksMax` | 敌方施加破甲层数峰值 |
| `{purge_n}` | `purgeCount` | 净化清除毒层次数（清空非零层才计） |

- 战报为**纯展示统计**：新增计数不得改变结算路径与随机数消耗序，改动后须复跑 18 例 golden 对照 sim。
- 胜利场**不做**战报（不服务 §10 任何标准），胜利只出 §1 收益行。

## 3. 归海叠浪教学文案（三处，交付【流程 1】）

> 教学空缺仅华山存在（少林「开战自动获得/受击自动」、唐门「开战施毒/命中 +1 层」的获得方式原文案已讲清，维持现状不动）。

### 3.1 路线选择卡（RouteSelect，华山卡；选择时点参悟必未购，允许写基线值）

| 条目 | 冻结文案 |
|---|---|
| 条 2 | `开战首击必定会心（并叠 1 重浪）` |
| 条 3 | `每次会心叠 1 重浪；叠满 5 重自动施展排山倒海` |

### 3.2 武学页「路线机制」区（华山，3 行）

```text
开战首击必定会心
每次会心叠 1 重浪
叠满 {叠浪需求} 重，施展排山倒海 {倍率}%
```

- `{叠浪需求}`/`{倍率}` 取**当前生效值**（一重参悟 5→4、三重 →3；二重 400%→550%）——**不得写死基线值**：已参悟玩家读到「叠满 5 重」而实际 4 重即文案撒谎。
- **通用规则**：武学页「路线机制」区内所有会被参悟修改的参数（三路线同理，如少林护盾比例、唐门层上限/毒爆系数）一律显示当前生效值；基线值只允许出现在路线选择卡（该时点参悟必未购，无失真）。

### 3.3 战斗日志与状态可见（§7.1 状态高亮合规载体）

| 位置 | 冻结格式 |
|---|---|
| 爆发 | 叙事句三选一（`battle-narration.md` §4「归海 · 叠满，排山倒海」） |
| 战斗页状态（气血 / 真气墨条下方） | 一行石印标记（`DESIGN.md` Signature Components「增减益标记」；原型 `docs/design/battle-status-prototype.html`），交手中显示。「你」侧：归海的**叠浪**印（右下角标重数，叠满待爆发时印面发亮，排山倒海后归零即隐去），武学挂上的运劲 / 凝眸 / 轻身。敌方侧：毒印（右下角标层数）、卸力 / 迷目 / 破绽、封穴。界面上不写字，数值只在悬停：叠浪 `叠浪　{n} / {当前需求} 重` + `叠满：排山倒海 {倍率}%`；毒 `毒　{n} / {上限} 层`；持续特效 `{名}　{属性} ±{值}` + `余 {n} 回合`；封穴 `封穴　下一次出手落空`。叠浪重数**不进战报**，战报只在会心后追加一句不带数字的余劲句（`battle-narration.md` §4「归海 · 会心后追加」）。 |
