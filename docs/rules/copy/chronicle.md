## 1. 每世的人

- **姓名**：姓氏沿用名册姓库（复姓约 6%）；男子用正派雅名，女子用女名，第二世起约四分之一的世是女子。
- **籍贯**：十卷地域的唐宋州县古名，每地 2–4 个；第一世固定「泰安」（教学卷在齐鲁），第二世起随机。
- **名号**：本世头一回打穿门户（门户 Boss）或以弱胜强（击败推荐境界高于自身的守关人）时起，一世只起一次；按本世胜场最多的那类兵器（主修武学类目，其次手中兵器，空手算拳）：
  - 打穿门户：意象 + 兵器（「流云剑」「追风刀」）；
  - 以弱胜强：单字 + 兵器 + 身份（「快剑浪子」「玉剑娘子」）。

## 2. 编年句式

第三人称、半文半白、一句一事；有名号后写「{名号}{姓名}」。

| 事 | 句式 |
|---|---|
| 入世 | `{籍贯}少年 / 女子{姓名}，年十八，始入江湖。` |
| 过正派外围 | `{名}过{势力}外客试炼，{图名}{岗位}{对手}让位闭关。` |
| 破正派门户 | `{名}破{势力}门户，{岗位}{对手}让位。` |
| 破邪派 | `{名}破{势力}{图名}，{岗位}{对手}败走。`（门户 Boss 写「伏诛」） |
| 闯官军 | `{名}闯{图名}，镇关军{岗位}{对手}不敌。`（门户写「{名}破{图名}，……去职。」） |
| 得名号 | 接在击败那句后：`江湖始称「{名号}{姓名}」。` |
| 拜入 | `{名}投{门派}门下。`（帮会写 `{名}入{帮}。`） |
| 高境界 | 境界 5 `跻身一流高手之列，名动一方` · 境界 6 `开宗立说，江湖尊为一代宗师` · 境界 7 `武功登峰造极，天下罕有敌手` |
| 寿终 | `{名}卒于{地}，年{N}。` |
| 战死 | `{名}殁于{地}，年{N}。` |
| 归隐 | `{名}归隐{地}，不知所终。` |

死所取本世到过的最深一卷的首个州县。

**江湖的事**（不存档，由名册推演；一世至多 8 条，被玩家击败的人优先，其次由近及远）：

| 事 | 句式 |
|---|---|
| 首领寿终 | `{势力}{首领称}{旧}卒，{新}继立。`（佛门「圆寂」，道门「羽化」） |
| 首领退隐 | `{势力}{首领称}{旧}退隐，{新}接掌门户。` |
| 官军首领 | `……卒于任上，朝廷改派{新}。` / `……告老，朝廷改派{新}。` |
| 被击败者，邪派 | `{势力}{岗位}{旧}败后为{寨 / 窟 / 教……}中所弃，{新}夺了{岗位}之位。` |
| 被击败者，正派 | `{势力}{岗位}{旧}败于后生，闭关不出，{新}接任。` |
| 被击败者，官军 | `{势力}{岗位}{旧}兵败去职，朝廷改派{新}。` |
| 被击败、先到了自然离任 | `{势力}{岗位}{旧}{伤重不治 / 败后远走 / 郁郁而终 / 败后归隐}，{新}接任。` |

被击败者的下场一律记在下一世开局那年（世内不换人）。

## 3. 进章因由与前世留痕

- 本世头一回进某张赶路图或某家外围时，战报开头一行 `进章因由　{因由}`；门户图不说。原文见 `chronicle.json` 的 `causes`，`{head}` 填当世首领。
- 前几世打穿过这家门户的，因由后追加：正派 `门中至今记得当年那位外客。`，邪派 `{寨 / 窟……}中至今忌惮当年那人。`

## 4. 转世醒来

冷青整屏：`江湖历 {N} 年 · 第{几}世` → 新名 → `{籍贯}人氏 · 年十八` → 至多四行 → 按钮 `入江湖`。

- 第一行写上一世的人：有名号 `「{名号}」{姓名}{卒于 / 殁于 / 归隐}{地}，其名已入{地域}说书人的旧话。`；无名号 `{姓名}{……}{地}，江湖上已少有人提起。`
- 其后至多三行：被上一世击败的人的下场（名字墨金），其次上一世里的首领更替，由近及远。

## 5. 守关人悬停

上一世在这关见到的人被玩家击败过、这一世已换人时，悬停提示加一行：`前任{本名}，败于{名号}{姓名}之手`。
