## 2. 三栏归隐预览（交付 a，落实规格书 §8.6-1）

**弹层标题**：`归隐盘点` **副标题**：`看清得失，再做决定`

### 2.1 「你将获得」栏

按下列顺序展示声望来源明细。**显示规则**：里程碑 5 行 + 精英行 + 全通行**常显**，未达成时灰显并计 +0——在保底场景下，灰显行本身就是「差什么才能拿全额」的解释；**保底折算行与短轮修正行为条件行**，不适用即整行隐藏——不给正常玩家制造从未触发的规则的理解负担。

| 行 | 达成时文案 | 未达成时文案（灰显） | 显示规则 |
|---|---|---|---|
| Boss 1 里程碑 | `击败山贼头目　+20` | `山贼头目未败　+0` | 常显 |
| Boss 2 里程碑 | `击败铁掌恶僧　+30` | `铁掌恶僧未败　+0` | 常显 |
| Boss 3 里程碑 | `击败黑风寨主　+50` | `黑风寨主未败　+0` | 常显 |
| Boss 4 里程碑 | `击败镇关都督　+40` | `镇关都督未败　+0` | 常显 |
| Boss 5 里程碑 | `击败无相居士　+60` | `无相居士未败　+0` | 常显 |
| 基础小计 | `基础声望　{base}` | 同左 | 常显 |
| 精英首杀 | `精英首杀 ×{n}　+{n×4}%` | `精英首杀 ×0　+0%` | 常显（n = 本轮精英首杀数，0–12） |
| 五图全通 | `五图全通　+10%` | `五图未全通　+0%` | 常显 |

| 短轮修正 | `轮时过短　×{系数}` | — | 仅本轮活跃时长 <15 分钟时显示（正常玩家永远不会见到，纯保险条款） |
| 合计 | `本次归隐声望　+{total}` | 同左 | 常显，视觉最重 |

`{total}` = 结算函数实际输出（四舍五入取整），必须与结算演出、`retire_confirmed.prestige_total` 逐位一致。

## 4. 结算演出（交付 c，落实规格书 §8.6-3）

**主模板**：

```text
你的第{N}段江湖：历时 {M} 分钟，击败了 {S} 个强敌，{最远足迹}。
```

**声望入账行**（滚动计数演出）：

```text
江湖会记得你——声望 +{total}
```

**变量定义**：

| 变量 | 取值口径 |
|---|---|
| `{N}` | 本轮轮次的中文序数：一/二/三/四……（run=1 →「第一段江湖」） |
| `{M}` | `run_duration_s` ÷ 60 四舍五入（tick 活跃秒口径，《声望经济表》§6.4） |
| `{S}` | 本轮 `stage_first_clear` 中 `kind ∈ {elite, boss}` 的计数（0–8：3 Boss + 5 精英） |
| `{total}` | 与预览、埋点同源的最终声望 |

**`{最远足迹}` 措辞映射**（按本轮到达的最远地图与 Boss 3 是否击破）：

| 本轮最远进度 | 措辞 |
|---|---|
| 止步地图 1（村外小径） | `足迹停在村外小径` |
| 到达地图 2（洛阳近郊） | `一路走到了洛阳近郊` |
| 到达地图 3，黑风寨主未破 | `走到了华山古道` |
| 击败黑风寨主 | `踏平黑风寨，走完了华山古道` |

## 5. 声望阁（交付 d）

**界面标题**：`声望阁` **副标题**：`归隐者的传承` **余额行**：`声望 {balance}`

**落地引导**（结算演出结束后自动进入声望阁，引导气泡指向当前可负担的节点，落实 §8.6-4「30 秒内兑现永久变强」）：

```text
你的声望可以换成传承，让下一轮更快更远——先挑一件带走。
```

### 5.1 八个节点卡（名称/价格/玩家可见效果描述，逐字冻结）

| 节点名称 | 价格 | 效果描述（卡面文案） |
|---|---:|---|
| 轻装上路 | 30 | 每一轮里，第一次更换路线不收银两 |
| 再入江湖 | 40 | 开战前，敌人的每个机制标签都附上一条克制提示 |
| 武道笔记 | 40 | 每轮开局自带 40 点阅历 |
| 快速入门 | 50 | 突破至「初窥门径」「小有所成」的内力消耗降低 30% |

| 旧梦重温 | 60 | 挂机修炼的内力产出提高 20% |
| 破关心得 | 70 | 对各图头目（Boss）造成的伤害提高 10% |
| 师门指引 | 80 | 每轮开局免费获得当前路线的一重参悟，更换路线后跟随新路线 |

> **江湖熟路**已按《声望经济表》§6.1 裁决改写为仅内力——卡面**不得**出现「战斗奖励」「银两」「阅历」字样。**再入江湖**按 §6.5 裁决改写——敌人标签与数值本就免费公开，卡面不得出现「预览敌人标签」措辞。**师门指引**卡面按「参悟」定名（v1.1）改写——「机制节点」为内部术语，卡面不得出现；「一重参悟」= 内容表 §3.2 节点 1，效果与埋点零改动。

黑风寨主仍未被击败。现在归隐，声望按六成结算；击败黑风寨主可获得全额声望。

**保底开放的一次性提示**（toast，按触发器二选一）：

|---|---|
