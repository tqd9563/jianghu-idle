### 2.1 「随魂而去」栏

大字：`+{total} 声望`。其下逐行：

```text
修行感悟 {n} 级 · 宿慧 +{suhui}×
内功 {n} 部 · 传承 {n} 件
名号与通关印记
```

栏尾一行小字：`转世后，错过的秘籍残页仍可在江湖中再度寻访。`

**大字悬停**（结算构成，按三层公式 `../economy.md` §1；逐行）：

| 行 | 文案 | 显示规则 |
|---|---|---|
| 基础 | `基础声望 {base}（本世挂机加权 {h} 小时，闭关按六成计）` | 常显 |
| 历来最深（达成） | `× {mult} 再败{Boss 名} · 历来最深` | 二选一 |
| 历来最深（未达成） | `× 1.0 今天还没再败{Boss 名}`；一个 Boss 都没打过时为 `× 1.0 尚未击败任何 Boss` | 同上 |
| 名号 | `名号与经脉 +{fame} 已随战随得，入账在先` | 本世成就声望 > 0 时显示 |
| 余额 | `现有声望 {balance}` | 常显 |

`{total}` = 基础 × 历来最深乘数，取整；与结算演出、`retire_confirmed.prestige_total` 逐位一致。名号与经脉声望已在当时入账，不计入 `{total}`，只作交代。

### 2.2 「随身而散」栏（删除线）

```text
境界回到江湖新丁
内功重数清零
各图通关进度
内力 {当前内力} · 银两 {当前银两}
{门派名}贡献 {当前贡献}　　（已拜入门派时显示）
```

> 资源为**全额清零**，不得出现「保留少量」等措辞。

### 2.3 寿元提示（按钮之上，醒目色）

剩余寿元还够再活一天以上时显示：`寿元尚有 {years} 年。此时转世，这一世的修为就此散去——活得越久，这一世爬得越高。`

- `{years}` = 本世寿元 − 当前年岁，取整数。「够再活一天」= 剩余寿元 ≥ 当前年岁速率 × 1 天（`../../systems/reincarnation/spec.md` §2.2）。
- 不够一天时不显示：寿元撑不到下次上线，此时转世正是时候（`../../systems/pacing/design.md` §2.3）。

**寿终正寝**（寿元耗尽、自动转世，`../../systems/reincarnation/spec.md` §4）：与主动转世同一屏，题眼换成 `{年岁} 岁 · 寿终正寝`（`{年岁}` 按寿元封顶显示）。没有 §2 演出；声望全额，不挂魂魄未稳。闭关（离线）期间寿终：回来时直接进本演出，不再弹出关演出。

战死的分岔见 `reincarnation.md` §3。

**变量定义**：

| 变量 | 取值口径 |
|---|---|
| `{N}` | 本轮轮次的中文序数：一/二/三/四……（run=1 →「第一段江湖」） |
| `{T}` | 本世时长（活跃秒 + 有效闭关秒）：不足 1 小时写 `{M} 分钟`，不足 1 天写 `{H} 小时`，否则写 `{D} 天`（均四舍五入） |
| `{S}` | 本世通关的精英与 Boss 数 |
| `{total}` | 与转世演出、埋点同源的最终声望 |

**`{最远足迹}` 措辞映射**（按本轮到达的最远地图与 Boss 3 是否击破）：

| 本轮最远进度 | 措辞 |
|---|---|
| 止步地图 1（村外小径） | `足迹停在村外小径` |
| 到达地图 2（洛阳近郊） | `一路走到了洛阳近郊` |
| 到达地图 3，黑风寨主未破 | `走到了华山古道` |
| 击败黑风寨主 | `踏平黑风寨，走完了华山古道` |

## 5. 声望阁（交付 d）

**页标题**：`声望阁` **副标题**：`持有 {balance} 声望`

**挂机倍率**（页头右侧大字）：`{M}×`，其下小字 `挂机产出`。悬停（逐行）：`基础 1`　`+ 宿慧 {suhui}×`　`+ 修行感悟 {ganwu}×`　`三项相加即挂机产出倍率`

**落地引导**（结算演出结束后自动进入声望阁，首次有声望且未买过任何东西时显示）：

```text
你的声望可以换成传承，让下一世更快更远——先挑一件带走。
```

**修行感悟卡**：

| 位置 | 文案 |
|---|---|
| 标题 | `修行感悟` |
| 角注 | `永久 · 转世不散`；悬停 `侠名在外，江湖自有人奉上资粮。价格每级 +10 声望，和每一世转世拿到的声望一起往上涨。` |
| 读数 | 大字 `{n} 级`，旁注 `每级挂机产出 +0.2× · 当前 +{ganwu}×` |
| 按钮一（描金） | `传承一级`，副文案 `{price} 声望`；买不起时置灰，副文案 `还差 {差额}` |
| 按钮二（轻按钮） | `尽数传承`，副文案 `{k} 级 · {cost} 声望`；够买两级以上才可用，否则置灰，副文案 `至少够两级时可用` |

**宿慧卡**：标题 `宿慧`，角注 `首达境界自得`（悬停 `不耗声望。散功重修，然剑意不灭——身体忘了的，神魂记得。`）；逐行 `首达 {境界名}　+{x}×`，未到的境界灰显 `+{x}× · 未至`。

**传承卡**：标题 `传承`，角注 `一次购得，永久生效`；每件一行：名称 + 类型标签 + 效果描述，右侧为购买按钮或状态（§5.2）。
