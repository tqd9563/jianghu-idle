## 2. 三栏归隐预览（交付 a，落实规格书 §8.6-1）

**弹层标题**：`归隐盘点` **副标题**：`看清得失，再做决定`

### 2.1 「你将获得」栏

按三层公式展示（`../economy.md` §1）。每行主文案 + 灰色小字说明。

| 行 | 主文案 | 说明小字 | 数值 | 显示规则 |
|---|---|---|---|---|
| 基础声望 | `基础声望` | `本世乘区加权 {h} 小时（闭关按六成计）` | `{base}` | 常显 |
| 前沿乘数（达成） | `打到自己的前沿` | `再败{Boss 名} · 历来最深` | `×1.2` | 常显，二选一 |
| 前沿乘数（未达成） | `打到自己的前沿` | `今天还没再败{Boss 名}`；一个 Boss 都没打过时为 `尚未击败任何 Boss` | `×1.0`（灰） | 同上 |
| 本世名号 | `名号与经脉` | `已随战随得，入账在先` | `+{fame}`（灰） | 本世成就声望 > 0 时显示 |
| 合计 | `本次归隐声望` | — | `+{total}` | 常显，视觉最重 |

`{total}` = 基础 × 前沿乘数，取整；与结算演出、`retire_confirmed.prestige_total` 逐位一致。名号与经脉声望已在当时入账，不计入 `{total}`，只作交代。

### 2.2 「你将失去」栏

```text
境界　　回到「江湖新丁」
内功　　重数与台阶清零，下一世重选
路线　　重新选择
通关进度　各图重推
内力　　{当前内力}　散去
银两　　{当前银两}　散去
```

> 资源三行为**全额清零**，不得出现「保留少量」等措辞。

### 2.3 「你将保留」栏

```text
声望　　现有 {balance} + 本次 {total}
修行感悟　{n} 级
宿慧　　+{suhui}×
传承　　已购 {n} 件，永久生效
江湖记录　名号与通关印记
```

**底部按钮**：确认 `决意归隐`（进入二次确认弹层）／取消 `返回江湖`。

## 3. 二次确认弹层（交付 b，落实规格书 §8.6-2）

- **标题**：`就此归隐？`
- **正文**：`这一段江湖就到此为止：境界、内功重数、通关进度与所有资源都会散去。只有声望、修行感悟、宿慧、传承和你留下的江湖记录，随你归来。此去无回头。`
- **寿元提示**（正文之下，醒目色；剩余寿元还够再活一天以上时显示）：`寿元尚有 {years} 年。此时归隐，这一世的修为就此散去——活得越久，这一世爬得越高。`
  - `{years}` = 本世寿元 − 当前年岁，取整数。「够再活一天」= 剩余寿元 ≥ 当前年岁速率 × 1 天（`../../systems/reincarnation/spec.md` §2.2）。
  - 不够一天时不显示：寿元撑不到下次上线，此时归隐正是时候（`../../systems/pacing/design.md` §2.3）。
- **确认按钮**：`挂剑，归隐`
- **取消按钮**：`再闯一阵`

## 4. 结算演出（交付 c，落实规格书 §8.6-3）

**主模板**：

```text
你的第{N}段江湖：历时 {T}，击败了 {S} 个强敌，{最远足迹}。
```

**寿终正寝**（寿元耗尽、自动归隐，`../../systems/reincarnation/spec.md` §4）：与主动归隐同一张结算卡，只在卡顶标题之上多一行 `{年岁} 岁 · 寿终正寝`（`{年岁}` 按寿元封顶显示）。没有预览、没有二次确认；声望全额，不挂魂魄未稳。闭关（离线）期间寿终：回来时直接进本演出，不再弹出关结算屏。

**声望入账行**（滚动计数演出）：

```text
江湖会记得你——声望 +{total}
```

**变量定义**：

| 变量 | 取值口径 |
|---|---|
| `{N}` | 本轮轮次的中文序数：一/二/三/四……（run=1 →「第一段江湖」） |
| `{T}` | 本世时长（活跃秒 + 有效闭关秒）：不足 1 小时写 `{M} 分钟`，不足 1 天写 `{H} 小时`，否则写 `{D} 天`（均四舍五入） |
| `{S}` | 本世通关的精英与 Boss 数 |
| `{total}` | 与预览、埋点同源的最终声望 |

**`{最远足迹}` 措辞映射**（按本轮到达的最远地图与 Boss 3 是否击破）：

| 本轮最远进度 | 措辞 |
|---|---|
| 止步地图 1（村外小径） | `足迹停在村外小径` |
| 到达地图 2（洛阳近郊） | `一路走到了洛阳近郊` |
| 到达地图 3，黑风寨主未破 | `走到了华山古道` |
| 击败黑风寨主 | `踏平黑风寨，走完了华山古道` |

## 5. 声望阁（交付 d）

**界面标题**：`声望阁` **副标题**：`归隐者的传承` **余额行**：`声望 {balance}`

**落地引导**（结算演出结束后自动进入声望阁，首次有声望且未买过任何东西时显示）：

```text
你的声望可以换成传承，让下一世更快更远——先挑一件带走。
```

**乘区账**（页首一行）：`挂机产出乘区　基础 1 + 宿慧 {suhui}× + 修行感悟 {ganwu}× = {M}×`

**修行感悟卡**：

| 位置 | 文案 |
|---|---|
| 标题 | `修行感悟` |
| 副题 | `无限级 · 每级挂机产出 +0.2×` |
| 角注 | `永久 · 归隐不散` |
| 读数 | `{n} 级`　`当前 +{ganwu}×`　`下一级 {price} 声望` |
| 按钮一 | `传承一级`，副文案 `{price} 声望`；买不起时置灰，副文案 `还差 {差额}` |
| 按钮二 | `尽数传承`，副文案 `{k} 级 · {cost} 声望`；够买两级以上才可用，否则置灰，副文案 `至少够两级时可用` |
| 说明 | `侠名在外，江湖自有人奉上资粮。价格每级 +10 声望，和每一世归隐拿到的声望一起往上涨。` |

**宿慧卡**：标题 `宿慧`，角注 `首达境界自得 · 不耗声望`；逐行 `首达 {境界名}　+{x}×`，未到的境界灰显 `+{x}× · 未至`；说明 `散功重修，然剑意不灭——身体忘了的，神魂记得。`

**传承区**小标题 `传承`；区尾注 `旧梦重温、快速入门、江湖熟路三件已废止，不再陈列。`

## 7. 再入江湖：机制标签克制提示（交付 Q6-c，逐条冻结，≤20 字）

仅持有「再入江湖」时，敌人卡片的每个机制标签下附对应一行；**组合标签（如黑风寨主 高血/狂暴、铁掌恶僧 高防/高攻）逐标签各附一条，不合成新文案**。未持有时仅显示标签本身。战败后的失败诊断提示（公式表 §5）不受本节点限制，始终免费。

| 标签 | 克制提示文案 |
|---|---|
| 高闪 | 身法奇快，命中不足者十剑九空 |
| 破甲 | 能削你防御，硬抗流越拖越亏 |
| 反伤 | 攻势会反噬自身，重击者伤己越重 |
| 毒（UI 显示「剧毒」） | 毒入肌理，护盾与防御皆挡不住 |
| 净化 | 会定期清去毒层，毒功难以积势 |
| 高血 | 气血浑厚，比拼的是持续输出 |

| 高攻 | 出手极重，需足够气血或护盾扛住 |

> 每条均与 §7.2 状态规则逐字核对过：毒「无视防御、绕过护盾」、反伤「按所受伤害比例反噬」、狂暴「逐回合递增」、净化「周期清层」——不承诺任何未实现的行为。
