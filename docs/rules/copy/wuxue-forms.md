## 0. 写法

- **意境跟着武学名走**（名录 W12）：每门武学先定一条意境主线，式名和句子都从这条线上取。比如寒蝉凄切掌取柳永《雨霖铃》，七式从「对长亭晚」写到「晓风残月」；穿林腿取苏轼《定风波》。
- **式名**：2–4 字，与现有 74 式及本批彼此都不重名。
- **句子**：一式一句，占位符与 `battle-narration.md` §0 相同。每句都含 `{我}`、`{招}`、`{敌}`、`{伤}`，`{招}` 与 `{伤}` 各一次。
- 现有 14 门武学的式名不变，只是武学改了名（见名录 §7.2）。

## 1. 新特效追加句

接在带特效那一式的句子后面，规则同 `battle-narration.md` §5.3。护体、回气、附毒沿用原句，必暴由暴击句体现。

| 特效 | 追加句 |
|---|---|
| 运劲 | 一股劲力贯入四肢，接下来几招更见沉猛。 |
| 连击 | 招势未尽，{我}顺手又补了一记。 |
| 凝眸 | 心神一凝，{敌}身上的破绽看得更清楚了。 |
| 轻身 | 身法随招变轻，接下来更难被打中。 |
| 回元 | 招意圆转，一部分真气回到了丹田。 |
| 透劲 | 劲力透体而入，{敌}的护身功夫挡不住。 |
| 封穴 | 这一下封住了穴道，{敌}一时动弹不得。 |
| 卸力 | {敌}手臂一麻，之后出手的力道弱了几分。 |
| 迷目 | {敌}眼前一花，之后出手便没那么准了。 |
| 破绽 | {敌}门户已乱，之后更容易被打伤。 |

「封穴」只在确实封住（敌人这回合被跳过）时追加；「连击」追加句后面接一条普攻句。
