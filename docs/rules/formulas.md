## 1. 基础战斗公式

### 1.1 命中判定

```text
命中率 = clamp( 攻方命中 / (攻方命中 + 守方闪避), 30%, 100% )
```

- 下限 30%：保证任何战斗都有伤害产出，高闪敌是「减益」不是「免疫」。
- 高闪精英（闪避 50）对玩家命中 113 → 命中率 ≈ 69%，华山的暴击期望被显著稀释——这就是「华山怕高闪」的数值实现。

### 1.2 暴击判定

```text
暴击判定在命中之后独立掷骰：
最终伤害倍率 = 暴击 ? 暴击伤害 : 100%
基础暴击率 5%，基础暴击伤害 150%
```

### 1.3 伤害与防御减免（形态锁定：除法/双曲）

```text
单次攻击伤害 = 攻击 × 暴击倍率 × 减伤系数(守方防御)
减伤系数(DEF) = K / (K + DEF)
K = 100 × 1.7^max(0, 关卡当量 − 3)      ← 本场战斗所在关卡的防御基准（v1.6）
最低伤害 = 1
```

**K 跟着关卡走**（v1.6）：K 固定为 100 时，长线后期敌我防御涨到几百，减伤饱和——攻击涨 70%、伤害几乎不涨，敌人血量却照涨，战斗越打越长，境界 5 的少林打前沿正好撞 50 回合上限。K 与属性同曲线放大后，每个境界打前沿的回合数与手感一致；打高档关卡时自己的防御显得薄、打低档关卡时显得厚，越级差距反而更鲜明。关卡当量见 `content.md` §2.0；前期（当量 ≤ 3）K 仍为 100，与旧口径一致。

**为什么选除法（双曲）而不是减法（攻击 − 防御）**：

1. 境界基础曲线是指数型（×1.7/境界），减法公式在指数曲线下极度敏感——防御略高即伤害归零、略低即防御无意义，会出现「高防敌对华山 0 伤害」的硬墙，违反门槛 Boss 守则与「Boss 2 各路线均可调整通过」的要求。
2. 双曲公式伤害永不为 0、收益平滑递减，DEF = 100 时恰好减伤 50%，调参直觉清晰。
3. 唐门「毒无视防御」的对比价值有稳定的数学意义：对 Boss 2（DEF 55）毒伤相对普攻放大 1.55 倍——克制关系是连续可调的量，不是开关。

### 1.4 回合结构与结算顺序

固定回合制，每回合玩家先行动、敌人后行动（规格书 §7.1）。结算顺序按规格书 §7.2：

```text
1. 行动方出手：命中判定 → 暴击判定 → 防御减免 → 护盾吸收 → 气血扣除
2. 受击方反伤（若有）：按「减免后、护盾吸收前」的伤害 × 反伤比例，
   跳过命中/暴击判定 → 攻击方护盾吸收 → 攻击方气血扣除；不再触发新的反伤
3. 回合结束：毒结算（绕过护盾）→ 狂暴/净化等回合型标签结算
4. 回合上限 50：达到上限战斗判负（失败提示走「输出不足」分支）
```

## 2. 六状态效果数值表

| 状态 | 数值形态（实现值） | 备注 |
|---|---|---|
| 护盾 | 战斗开始生成，护盾值 = 气血上限 × 护盾系数（少林基础 30%）；耗尽不再生 | 通用吸收层，先于气血扣除 |
| 反伤 | 反伤值 = 所受攻击伤害（减免后、吸收前）× 反伤比例；不可暴击、不触发新反伤；可被攻击方护盾吸收 | 少林基础 25%；反伤敌 30% |
| 毒（叠层） | 每层毒伤 = 施毒方攻击 × 毒伤系数（唐门基础 12%）；回合结束结算；**无视防御、绕过护盾**、不可暴击、不触发反伤；层数上限 8；层满触发毒爆 = 上限层数 × 攻击 × 毒爆系数（基础 50%）后清层 | 敌方毒（五毒散人）：每层 = 敌攻击 × 8%，每次命中 +1 层，上限 5 层 |
| 净化 | 敌方每 3 个己方回合行动后清空自身全部毒层 | MVP-0 敌方专属 |
| 破甲 | 命中时施加 1 层，每层削减目标防御 15%，上限 3 层，战斗内不消退 | MVP-0 敌方专属 |
| 狂暴 | 第 13 回合起，攻击每回合 +8%（复利前值累加：第 n 回合攻击 = 基础 × (1 + 8% × (n − 12))） | Boss 3 携带；是战斗时长软上限 |

> **毒与护盾/防御的规则说明**：毒伤无视防御且绕过护盾（毒入肌理，金钟不防）——这是「少林怕毒」在数值上成立的前提，也是本次产表对规格书 §7.2 的补充修订（见规格书 v0.5 变更日志）。

## 3. 玩家侧公式

### 3.1 境界基础属性（指数曲线）

```text
气血/攻击/防御：每境界 × 1.7（对齐初案「境界基础成长为超线性/指数型」）
命中：每境界 +12；闪避：每境界 +3（线性，避免命中体系失控）
```

具体值见内容表 §1。**曲线底数 1.7 的理由**：5 个境界内总放大 8.35 倍，既让「突破」成为体感上最大的单次跃升（每次 +70%，远超单级武学的 3–8%），又不至于让跨一个境界的关卡完全不可交互（双曲减伤下仍有 30%+ 伤害效率）。

> **底数适用范围**：固定底数 1.7 只覆盖 MVP-0 的境界 1–5（完整版第一大境界段）。固定底数下绝对跃升已逐级放大（境界 4→5 的属性增量 ≈ 境界 1→2 的 5 倍），相对跃升恒为 +70%；完整版「越往后质变越大」不通过连续递增底数实现，而按初案 §三「底数分段规则」——段内固定底数、段间 2–3 个跃迁节点承载质变。若未来调整底数，须同步调整 §1.3 中 K 的放大底数（v1.6 起 K 随关卡当量按同一底数放大）。

### 3.2 挂机内力产出（经济主引擎）

```text
内力产出/秒 = 9 × 1.25^(境界 − 1)                    // 境界基础：9.0 / 11.3 / 14.1 / 17.6 / 22.0
            × (1 + 宿慧 + 修行感悟)                    // 永久产出乘区，economy.md §2 / §3
            × 伤势压制                                 // injury/spec.md §3
            × 魂魄未稳                                 // reincarnation/spec.md §4.1
```

v1.5 起「声望效率加成」（旧梦重温 +20%）废止，由「修行感悟」多级化取代（`economy.md` §4）。离线产出按本式 × 60% 折算（`offline-rewards.md` §1.1）。

**产出随境界提升（×1.25）的设计理由**：修炼效率随境界提升既符合武侠直觉，更是第二轮加速的**复利引擎**——声望的 +20% 内力加成让玩家更早突破，更早突破又更早享受更高产出档位，扁平的加法节点由此产生 28% 的实测提速（见附录 A），命中 25%–40% 目标区间。没有这条规则，+20% 节点只能带来 ~13% 提速，无法达标。

### 3.3 境界突破消耗与充能

v1.5 起改为**周天分期缴纳制**：各境界总额见 `content.md` §1（长线值），分 N 段周天、段间公比 2 逐段缴纳，缴清且本境界首条经脉贯通即可突破，突破动作本身不再扣款。机制全文见 `../systems/zhoutian/design.md` §2 / §4；段配额见同文 §3.1。

旧「一次性扣除 2,800 / 5,000 / 10,000 / 21,000」与「最大充能段耗时 ≤ 5 分钟」锚点属压缩原型，随长线落地废止。

### 3.4 武学等级（门径武学）

v1.6 起按「战力预算」计（`../systems/pacing/design.md` §3.7）。本节是门派 / 主动武学重做前的**临时替身**：重做时可整体替换，只要守住战力预算，敌人与关卡不用重调。

```text
第 n 级的内力价 = 3,490 × 1.08^(n−1)                 // 绝对计价，与境界无关
第 1–10 级（招式）：沿用各路线原逐级加成（content.md §3.1）；练满即「十成」
第 11 级起（火候）：三路线相同，每级折合 1/20 个境界——
    气血 / 攻击 / 防御 × 1.7^(1/20)，命中 +0.6，闪避 +0.15
等级上限：不绑境界，仅受内力约束；每世归隐清零
```

**为什么十成后改火候**：原逐级加成放到几十上百级会失真——华山暴击约 26 级顶到 80% 上限后生存不再增长，唐门每级仅 +1% 攻击，三路线到第 100 天相差一个多境界。火候按境界曲线同形成长，三路线同步、不越档。武侠说法：招式有穷，火候无尽。

**为什么等比计价**：价格与效果都按等比走，火候折合的境界数约等于武学累计内力的对数——天然递减，一个平台期内最多长出约 0.8 个境界（`../systems/sim/longline_sim.py` 表三），高一档难度不会被提前打穿。第 100 天标准玩家约 80 级。

**为什么解除「上限 = 境界 × 2」**：长线里境界之间相隔一到七周，这条绑定让战斗力只在突破那天跳一下、其余时间冻结。

### 3.6 换路线结算

```text
换路线成本 = 200 银两（固定）[待测试]
已投入原路线的阅历（机制节点）100% 返还；原路线武学等级清零，
其已消耗内力不返还（内力是可再生资源，阅历不可再生——规格书 §6.4）
```

自洽性：首轮到 Boss 2 时银两累计收入约 530（内容表 §4），支付一次换线后仍有余量；阅历全额返还保证换线后立刻能重买新路线节点 1。

## 5. 失败提示诊断规则（规格书 §7.5 交付项）

战斗失败后，按以下优先级**从上到下取第一条命中**的规则输出提示（最多再附加一条次优先命中项）：

| 优先级 | 触发条件（战斗结算数据） | 提示文案方向 |
|---:|---|---|
| 1 | 玩家境界 < 关卡推荐境界（内容表列） | 「当前境界偏低，继续修炼可提高基础属性。」 |
| 1.5 | 当前境界首条经脉未贯通（主题版本扩展） | 「经脉未贯通，蓄够真气冲穴。」 |
| 2 | 敌方带「高闪」且玩家实际命中率 < 75% 且路线 = 华山 | 「你的命中不足，华山暴击流面对高闪敌人不稳定。」 |
| 3 | 敌方带「破甲」且战斗结束时玩家破甲层数 ≥ 2 且路线 = 少林 | 「敌人破甲较高，少林防御收益被削弱。」 |
| 4 | 敌方带「净化」且战斗中毒层被清除次数 ≥ 2 且路线 = 唐门 | 「敌人净化了毒层，唐门需要更高叠毒速度或换目标。」 |
| 5 | 敌方带「反伤」且玩家所受反伤 ≥ 自身气血上限 30% | 「敌人反弹了你的爆发，考虑降低单次伤害或先强化生存。」 |
| 6 | 战斗达 50 回合上限（超时判负）或敌方剩余血量 > 40% | 「你的输出不足，强化主武学或提升境界。」 |
| 7 | 兜底（以上均未命中） | 「差一点就赢了——再强化一次武学，或等内力突破境界。」 |

规则 1 优先于路线诊断：境界落后是最常见根因，先排除它，路线建议才有意义。优先级 1.5 为内功周天主题版本扩展。

## 6. 战斗奖励与回刷收益

### 6.1 战斗奖励（v1.6）

```text
关卡奖励：不掉内力；银两、阅历、秘籍残页不变
首通精英 / Boss：声望（economy.md §1.3）
```

**为什么不掉内力**：玩家在寿元将尽时用这一世的峰值推前沿，推完即归隐，内力随之清零；新的一世头几天打不动前沿。关卡内力无论按固定值还是按挂机秒数给，都落在一世的末尾，等于白拿。改给跨归隐保留的声望，推前沿才有实打实的回报。声望节点「江湖熟路」随之废止（`economy.md` §4）。

### 6.2 回刷（防原地刷爆）

```text
重复通关已通关卡：银两 = 首通值 × 50%，阅历 = 0
同一关卡连续回刷衰减：第 n 次连续回刷奖励再 × 0.8^(n−1)，间隔 10 分钟重置 [待测试]
```

阅历不可回刷是防套利核心：阅历的全部价值在机制节点与换线自由，若可刷则「阅历不可再生」的换线返还设计失去意义。
