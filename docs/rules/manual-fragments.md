## 核心设计

6 本秘籍 × 18 张残页，四渠道收集（Boss 首杀 / 试炼首胜 / 商店指名 / 离线零产出），跨归隐保留。

| 参数 | 值 |
|---|---|
| 秘籍数 | 6 本 |
| 每本残页 | 3 张 |
| 收集渠道 | Boss 首杀（必掉）、真传试炼首胜（必掉）、声望商店指名寻访（主动购买） |
| 离线产出 | 零（离线不发残页，保持回访动机） |
| 跨归隐 | 已收集残页和已集齐秘籍保留，本轮计数重置 |

|---|---|---|
