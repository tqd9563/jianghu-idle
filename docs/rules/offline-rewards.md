## 推导锚点

| 锚点 | 本表处理 |
|---|---|
| 不破坏 MVP-0 主循环 | 离线只发基础资源，不推进关卡/Boss/归隐/突破/首通 |
| 长线节奏：标准一天有效 16 小时 | 4 小时在线 + 20 小时离线 × 60% = 16 小时（`../systems/sim/pacing_sim.py` 外生假设 E_HOURS / OFFLINE_EFF） |
| 离线随乘区增长 | 离线内力按在线挂机速率折算，宿慧与修行感悟同样生效，否则长线后期离线等于白挂 |
| 离开太久不白白老去 | 上限 24 小时，年岁按同一封顶时长累计（`../systems/reincarnation/spec.md` §2.3） |
| 资源三列账闭合 | 离线只作为内力/银两/阅历的新增来源列 |
| 玩家侧术语纪律 | 界面文案用「闭关/出关结算」 |

## 1. 结算规则

### 1.1 主公式

```text
有效闭关分钟 = clamp(原始离线分钟, 0, 1440)                       // 上限 24 小时
离线内力     = 在线挂机内力速率（含全部乘区） × 有效闭关分钟 × 60 × 0.60
离线银两 / 阅历 = 当前最大可挂机关卡所属档位的每分钟产出（表 A） × 有效闭关分钟 × 0.60
```

- **内力**跟着在线速率走：宿慧、修行感悟、伤势压制、魂魄未稳都照常作用，与在线同一条乘法链（`formulas.md` §3.2）。
- **银两 / 阅历**暂沿用表 A 档位；它们在长线里的定位随战斗长线化另定（`../systems/pacing/design.md` §6）。
- **效率恒定 60%**，不再按离线时长分段打折（原表 C 废止）。
- 同一个「有效闭关分钟」也驱动离线养伤（`../systems/injury/spec.md` §5）与年岁增长（`../systems/reincarnation/spec.md` §2.3）。
- **闭关中寿终**：结算到寿终那一刻为止（内力、声望、养伤都只算到这一刻），按寿终正寝自动归隐；之后的离线时间不计，新的一世从上线时开始（`../systems/reincarnation/spec.md` §2.3 / §4）。
- **丹田封顶照旧**：离线内力进丹田后同样受「本境界突破所需」封顶，满了散掉；突破只能在线做（`../systems/pacing/design.md` 裁决 22）。
- 武侠说法：闭关以一日为限，出关方知世事。离开超过一天的部分拿不到——轻轻提醒玩家每天上线一次。

### 1.2 决策保留（来自 `../mvp1/spec.md` §5）

离线收益发放后，玩家不自动推进关卡、不自动突破、不自动归隐、不产残页。回访后必须手动做出至少一个真实决策（升武学/推关/冲穴等），离线收益才是合法增益而非跳过核心循环。

### 1.3 验收判据（来自 `../mvp1/spec.md` §8.1）

- A1：离线时长与收益对账（公式输出 vs 界面展示一致）
- A3：离线上限触发时收益不再增长
- A5：刷新页面后收益不丢失、不重复发放
- A6：系统时钟回拨不产生负收益

### 1.4 离线上限与效率

| 场景 | 上限 | 效率 |
|---|---|---|
| 在线 | 不限 | 100% |
| 离线（关闭页面） | **24 小时** | **60%** |
| 调试覆盖 | 可临时压低（`#offlinecap=N`） | — |

## 2. 产出档位表（表 A）

**v2.0 起只用于银两与阅历**；离线内力改按在线速率折算（§1.1）。离线收益按玩家当前最大可挂机关卡的最高档位取每分钟产出，完整档位表见 `code/src/engine/offlineRewards.ts`。档位表中的 `neiliPerMin`、`offlineEfficiency`、`offlineCapMin` 三列随 v2.0 停用。

## 3. 效率系数与上限表（表 C）· v2.0 废止

原按离线时长分段打折（效率 35%–50%、上限 20–480 分钟）。v2.0 改为恒定 60%、上限 24 小时（§1.4），本节保号不删。
