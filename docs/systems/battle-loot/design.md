## §0 这套系统在做什么

现在本作有两条挂机线，但只有一条有产出：

- **修炼挂机**产内力，内力推境界，是主进度。
- **战斗挂机**只产银两。第一次通关后，重打一关只给五成银两，连续重打还每次再打八折，挂十场就只剩不到一成。玩家卡关时除了干等境界，没有别的事可做。

本系统给战斗挂机一个自己的产出：**装备和武学**。它们只加战力，让玩家**不升境界也能往前推关**；内力和境界节奏完全不碰。

境界 1 的空档也一并解决：现在第一世在境界 1 要停大约 3 小时（`../pacing/design.md` §2），入门关几分钟就打完，后面只能挂着等突破。本系统把内功、武学、装备都提前到境界 1，让这 3 小时有关可打、有东西可拿。

## §2 战斗挂机

### 2.1 挂机入口

现在的「自动连战」开关有三个问题：输一场就停；首通后会自动去打下一关，在打不过的关输掉后停下，玩家得自己退回去点「重打」；它是个开关，不像一个挂机入口。

改成：

- 已通关的关卡上有一个明确的 **「在此挂机」** 按钮，按下后就一直原地重打这一关。
- **推关和挂机分开**：推关是「打下一关，赢了接着往前」；挂机是「守着一关反复打」。推关输了，自动退回最近一个已通关的关卡挂机，不再停下不动。
- 挂机中输了（比如身上带着伤）就退一关继续挂，不停机。
- 挂机的关卡记进存档，离线结算按它算（§2.3）。

### 2.2 一场挂机的收益

| 产出 | 规则 |
|---|---|
| 银两 | 重打这一关给首通银两的五成，**不再有连刷递减**（裁决 14） |
| 装备 | 按关卡掉落率掷骰（§3.4） |
| 武学 | 按关卡掉落率掷骰（§4） |
| 内力 | 不给（裁决 1） |

一场战斗本身要演一段时间（约 2.7 秒一回合），所以每小时能拿多少东西，已经被战斗时长卡住了，不需要再叠递减。

### 2.3 离线

- 离线时按挂机关卡折算场次：`离线场次 = 有效离线秒数 ÷ 这一关的平均战斗时长 × 胜率`，上限沿用离线结算的 24 小时（`../../rules/offline-rewards.md`）。
- 每场照常掷掉落。出关结算屏里列出银两、新装备（按品阶汇总）、武学所得。
- 胜率和平均时长在下线那一刻按当时的战力算一次，离线期间不变。
- 背包装不下时，低于当前所穿品阶的装备自动卖掉（§3.5）。

## §3 装备

### 3.1 部位与基础属性

| 部位 | 武侠里的样子 | 基础属性（类别固定，数值随机） |
|---|---|---|
| 兵器 | 柴刀、铁剑、袖箭、齐眉棍…… | 攻击 |
| 衣甲 | 粗布短打、皮甲、软甲、锁子甲…… | 气血、防御 |
| 佩饰 | 铜钱串、香囊、玉佩、护身符…… | 命中或闪避（二选一，随物件固定） |

- 品阶越高，基础属性的取值区间越高（§3.3）。
- 名字按品阶 × 部位配一张名表（`rules/copy/` 另出），同一品阶同一部位有几种物件。
- **兵器要不要和路数绑定**（华山用剑、唐门用暗器、少林用棍）：待议，见 §6。

### 3.2 词条

| 品阶 | 白 | 绿 | 蓝 | 紫 | 橙 |
|---|---|---|---|---|---|
| 词条数 | 0–1 | 1–2 | 2–3 | 3–4 | 4–5 |

词条池（候选，类别随机，同一件装备的词条不重复）：

| 词条 | 作用 |
|---|---|
| 攻击 +x% | 乘进攻击 |
| 气血 +x% | 乘进气血 |
| 防御 +x% | 乘进防御 |
| 命中 +x | 加命中 |
| 闪避 +x | 加闪避 |
| 暴击率 +x pp | 加暴击率 |
| 暴击伤害 +x pp | 加暴击伤害 |
| 真气上限 +x | 加真气上限，武学能多出几招 |
| 对精英 / Boss 伤害 +x% | 只对硬仗生效 |

- 每个词条的取值区间随品阶抬高（§3.3）。
- 是否要按部位限制词条池（比如兵器不出「气血 +x%」）：待议，见 §6。

### 3.3 数值怎么随关卡长

敌人强度随关卡当量指数增长（当量每 +1 约强一个境界，属性 ×1.7，`../../rules/content.md` §2.0）。固定数值的装备很快就会过时，所以：

- 每件装备带一个**装备等级**，等于它掉落关卡的当量。
- 基础属性 = 该部位基准 × 1.7^(装备等级 − 1) × 品阶系数 × 随机浮动。
- 百分比词条不随装备等级涨，只随品阶涨；数值词条（命中、闪避）随装备等级涨。

挂越往后的关，掉的装备越强。这样就形成「推关 → 掉更强的装备 → 再推关」的循环。

### 3.4 掉落率

- 每场胜利按关卡掷一次装备掉落。精英和 Boss 的掉落率更高，品阶也偏高。
- 品阶分布随关卡位置往高处偏移。一个可能的形态是：前段关卡几乎只出白、绿；越往后，蓝、紫越常见；橙极少见。
- 具体概率 `[待 sim]`，按「标准玩家一世里各品阶拿到几件」倒推（§5）。

### 3.5 背包与出售

- 背包有格数上限 `[待定]`。
- 卖装备换银两，价格按品阶 × 装备等级 `[待 sim]`。
- 一键出售「低于某品阶」的装备；离线时背包满了，自动卖掉低于当前所穿品阶的装备。

### 3.6 每世清零

- 转世时，装备和背包一律清空（裁决 8）。
- 下一世开局又从赤手空拳开始。不过有宿慧和内功加成，前段关卡会推得比上一世快，装备也会更快补齐。

## §4 武学掉落

### 4.1 两种形态

| 武学品质 | 掉什么 | 拿到后 |
|---|---|---|
| 寻常 | **某一式全本**，一次掉落就完整 | 见 §6 待议 1 |
| 上乘 / 绝学 | **某一式残页**，凑齐 N 页 `[待 sim]` 得这一式的口诀 | 口诀永久保留；这一式仍要按现行规则顿悟才会（`../sect-neigong/spec.md` §2.3） |

- **第一式**的全本 / 口诀就等于这部武学的秘籍：它是书肆购买、Boss 首杀之外的另一条来路。
- 需要「招式秘籍」才能顿悟的高阶式（上乘第 4–5 式、绝学第 5–7 式），口诀可以代替招式秘籍。
- 界面显示残页进度，比如「惊鸿剑 · 第二式 残页 2/5」。

### 4.2 只掉下一式

- 每部武学只掉你**下一步用得上的那一式**：没有第一式就只掉第一式；第一式到手，才开始掉第二式（裁决 12）。
- 某部武学全部式都到手以后，就不再掉它。
- 掉落池按地图、难度分层：前段图只掉寻常武学，上乘、绝学的残页从中后段图开始掉 `[待 sim]`。

### 4.3 重复掉落

全本或口诀已经有了，再掉到同一式的全本或残页时，转成这一式的熟练（加出招计数）`[待 sim]`。掉落永远不会白掉。

## §5 境界 1 的节奏：内功教学关

### 5.1 第一世

| 时段 | 发生什么 | 世界观说法 |
|---|---|---|
| 开局几分钟 | 赤手空拳打入门关 1–6；**不掉任何东西** | 初出茅庐，先收拾村口地痞 |
| 1-7 | 必败（裸属性打不过）；战败弹窗里接教学 | 第一次碰上真正的江湖人，被打得落花流水 |
| 教学 | 隐世前辈出场，选内功的整屏演出就在这时出现，三选一 | 前辈见你根骨尚可，传你一门心法 |
| 选完内功 | 真气、内功页签出现；境界 1 开 1 个武学槽；**装备和武学从这时起开始掉落** | — |
| 之后 | 内功、装备、武学叠在一起，在境界 1 把关卡推到极限 | — |

- 1-7 要做到**裸属性必败**。现在 1-7 的当量 2.52，裸属性能打的上限约 2.04，差距应该够，但伤害有 ±10% 浮动，要在 sim 里把胜率压到接近 0。
- 这个时点之前装备不掉落，是为了让第一次卡关的位置可控（裁决 13）。

### 5.2 第二世起

- 前辈已经传过功了：转世后一开局就选内功，不再经过 1-7 的教学。
- 入门关从第二世起也照常掉落 `[待议]`，或者保持不掉（只是重打很快）。

### 5.3 对现行规格的改动

| 现行 | 改为 | 位置 |
|---|---|---|
| 内功在突破进境界 2 时选 | 第一世在 1-7 战败后选；第二世起开局即选 | `../sect-neigong/spec.md` §4.1 |
| 境界 1 武学槽数 0 | 选定内功后为 1 `[待 sim]` | `../sect-neigong/spec.md` §2.4 |
| 书肆境界 2 开张 | 待议：随内功一起开，或仍在境界 2 开 | `../sect-neigong/spec.md` §4.2 |
| 重打连续第 n 次 ×0.8^(n−1) | 取消 | `../../rules/formulas.md` §6 |

## §6 待议

1. **寻常武学「某一式全本」拿到后是什么**：
   - A. 直接学会这一式，本世可用（相当于跳过顿悟）。寻常第 2–3 式现在不需要招式秘籍，如果全本只是「许可」，就没有意义。
   - B. 和高阶残页一样只是许可，仍要顿悟。
   - 倾向 A：寻常招式看一遍就会。但已领悟的招式每世清空，A 意味着下一世要重新掉一次，或者靠顿悟（前世悟过 ×3）重新学会。
2. **兵器是否和路数绑定**：绑定更有武侠味，但掉落会被摊薄（三条路线各一套兵器）。
3. **词条池是否按部位限制**。
4. **背包格数**与一键出售的门槛。
5. **装备战力预算**：标准玩家穿一身「当前档」装备，前沿要比现在多出多少境界当量（每 +0.05 当量约等于往前推一关；一个境界当量约 20 关）。这决定掉落率、品阶系数、词条区间的全部数值。
6. 境界 1 内功 + 武学 + 装备叠起来，能推到第几关；首通银两和精英名号声望会提前多少，节奏守卫（三路线首达境界 2–6 在里程碑 ±20% 内）是否仍通过。
