## §0 这套系统在做什么

现在本作有两条挂机线，但只有一条有产出：

- **修炼挂机**产内力，内力推境界，是主进度。
- **战斗挂机**只产银两。第一次通关后，重打一关只给五成银两，连续重打还每次再打八折，挂十场就只剩不到一成。玩家卡关时除了干等境界，没有别的事可做。

本系统给战斗挂机一个自己的产出：**装备和武学**。它们只加战力，让玩家**不升境界也能往前推关**；内力和境界节奏完全不碰。

境界 1 的空档也一并解决：现在第一世在境界 1 要停大约 3 小时（`../pacing/design.md` §2），入门关几分钟就打完，后面只能挂着等突破。本系统把内功、武学、装备都提前到境界 1，让这 3 小时有关可打、有东西可拿。

## §2 战斗挂机

### 2.1 挂机入口

现在的「自动连战」开关有三个问题：输一场就停；首通后会自动去打下一关，在打不过的关输掉后停下，玩家得自己退回去点「重打」；它是个开关，不像一个挂机入口。

改成：

- 已通关的关卡上有一个明确的 **「在此挂机」** 按钮，按下后就一直原地重打这一关。
- **推关和挂机分开**：推关是「打下一关，赢了接着往前」；挂机是「守着一关反复打」。推关输了，自动退回最近一个已通关的关卡挂机，不再停下不动。
- 挂机中输了（比如身上带着伤）就退一关继续挂，不停机。
- 挂机的关卡记进存档，离线结算按它算（§2.3）。

### 2.2 一场挂机的收益

| 产出 | 规则 |
|---|---|
| 银两 | 重打这一关给首通银两的五成，**不再有连刷递减**（裁决 14） |
| 装备 | 按关卡掉落率掷骰（§3.4） |
| 武学 | 按关卡掉落率掷骰（§4） |
| 内力 | 不给（裁决 1） |

一场战斗本身要演一段时间（约 2.7 秒一回合），所以每小时能拿多少东西，已经被战斗时长卡住了，不需要再叠递减。

### 2.3 离线

- 离线时按挂机关卡折算场次：`离线场次 = 有效离线秒数 ÷ 这一关的平均战斗时长 × 胜率`，上限沿用离线结算的 24 小时（`../../rules/offline-rewards.md`）。
- 每场照常掷掉落。出关结算屏里列出银两、新装备（按品阶汇总）、武学所得。
- 胜率和平均时长在下线那一刻按当时的战力算一次，离线期间不变。
- 背包装不下时，低于当前所穿品阶的装备自动卖掉（§3.5）。

## §3 装备

### 3.1 部位与基础属性

| 部位 | 武侠里的样子 | 基础属性（类别固定，数值随机） |
|---|---|---|
| 兵器 | 分刀、枪、剑、棍四类：柴刀、白蜡杆、铁剑、齐眉棍…… | 攻击 |
| 暗器 | 镖囊、针筒、石囊、袖箭…… | 攻击、命中 |
| 衣甲 | 粗布短打、皮甲、软甲、锁子甲…… | 气血、防御 |
| 佩饰 | 铜钱串、香囊、玉佩、护身符…… | 命中或闪避（二选一，随物件固定） |

- 品阶越高，基础属性的取值区间越高（§3.3）。
- 名字按品阶 × 部位配一张名表（`rules/copy/` 另出），同一品阶同一部位有几种物件。
- 兵器类别决定能装哪些器械武学（§3.7）；类别纯随机掉落（裁决 25）。

### 3.1a 装备名

装备名 = 词条前缀 + 物件名（裁决 26）：

- 没有词条：只有物件名，如「幽兰剑」。
- 一条词条：「锋锐的幽兰剑」。
- 两条及以上：前缀直接连写，最后加「的」，如「坚韧厚实的蝮蛇甲」。最多 4 个前缀，也就是全部词条都上名字（裁决 29）；前缀按词条数值从高到低排。

### 3.2 词条

| 品阶 | 白 | 绿 | 蓝 | 紫 | 橙 |
|---|---|---|---|---|---|
| 词条数 | 0–1 | 1–2 | 2–3 | 3–4 | 4（第一期） |

词条池按部位分（裁决 18）。词条从本部位的池里随机抽，同一件装备的词条不重复：

| 词条 | 作用 | 兵器 | 暗器 | 衣甲 | 佩饰 |
|---|---|:-:|:-:|:-:|:-:|
| 攻击 +x% | 乘进攻击 | ✓ | | | |
| 会心率 +x pp | 加会心率 | ✓ | ✓ | | ✓ |
| 会心伤害 +x pp | 加会心伤害 | ✓ | ✓ | | |
| 命中 +x | 加命中 | ✓ | ✓ | | ✓ |
| 对精英 / Boss 伤害 +x% | 只对硬仗生效 | ✓ | ✓ | | |
| 气血 +x% | 乘进气血 | | | ✓ | |
| 防御 +x% | 乘进防御 | | | ✓ | |
| 闪避 +x | 加闪避 | | | ✓ | ✓ |
| 真气上限 +x | 武学能多出几招 | | | ✓ | ✓ |
| 武学伤害 +x% | 只对招式生效，不加普攻 | | ✓ | | ✓ |

- 兵器、暗器、佩饰各 5 个候选，衣甲 4 个；第一期橙装 4 条，抽不空池子（裁决 21）。伤势抗性要等受伤系统接上后再加。
- 每个词条另有一个武侠名，用作装备名前缀（§3.1a）：

| 词条 | 前缀 |
|---|---|
| 攻击 +x% | 锋锐 |
| 会心率 +x pp | 狠辣 |
| 会心伤害 +x pp | 透骨 |
| 命中 +x | 眼明 |
| 对精英 / Boss 伤害 +x% | 遇强则强 |
| 气血 +x% | 厚实 |
| 防御 +x% | 坚韧 |
| 闪避 +x | 轻灵 |
| 真气上限 +x | 蕴气 |
| 武学伤害 +x% | 凝神 |

  会心率的前缀不直接叫「会心」，是因为它和属性名重名了，「会心的铁剑」读着别扭。
- 每个词条的取值区间随品阶抬高（§3.3）。

### 3.3 数值怎么随关卡长

敌人强度随关卡当量指数增长（当量每 +1 约强一个境界，属性 ×1.7，`../../rules/content.md` §2.0）。固定数值的装备很快就会过时，所以：

- 每件装备带一个**装备等级**，等于它掉落关卡的当量。
- 基础属性 = 该部位基准 × 1.7^(装备等级 − 1) × 品阶系数 × 随机浮动。
- 百分比词条不随装备等级涨，只随品阶涨；数值词条（命中、闪避）随装备等级涨。

挂越往后的关，掉的装备越强。这样就形成「推关 → 掉更强的装备 → 再推关」的循环。

### 3.4 掉落率

- 每场胜利按关卡掷一次装备掉落。精英和 Boss 的掉落率更高，品阶也偏高。
- 品阶分布随关卡位置往高处偏移。一个可能的形态是：前段关卡几乎只出白、绿；越往后，蓝、紫越常见；橙极少见。
- 具体概率 `[待 sim]`，按「标准玩家一世里各品阶拿到几件」倒推（§5）。

### 3.5 背包与出售

- 背包有格数上限 `[待定]`。
- 卖装备换银两，价格按品阶 × 装备等级 `[待 sim]`。
- 一键出售「低于某品阶」的装备；离线时背包满了，自动卖掉低于当前所穿品阶的装备。

### 3.6 每世清零

- 转世时，装备和背包一律清空（裁决 8）。
- 下一世开局又从赤手空拳开始。不过有宿慧和内功加成，前段关卡会推得比上一世快，装备也会更快补齐。

### 3.7 兵器与武学搭配

| 武学大类 | 类目 | 装配条件 |
|---|---|---|
| 器械 | 刀、枪、剑、棍 | 手里要拿同类兵器 |
| 肉身 | 拳、掌、指、腿 | 不挑兵器，随时可装 |
| 暗器 | 暗器 | 暗器槽里装着暗器才能装；和器械、肉身武学互不冲突（裁决 28） |

- 换兵器时，和新兵器不同类的器械武学自动卸下；卸下暗器时，暗器武学自动卸下。
- 武学槽数不变（`../sect-neigong/spec.md` §2.4），器械、肉身、暗器三类共用。
- 现有 14 门武学按新类目归类（裁决 24）：

| 类目 | 现有武学 | 说明 |
|---|---|---|
| 剑 | 流云剑、惊鸿剑、苍崖剑诀、落星剑 | — |
| 刀 | 断水刀 | — |
| 棍 | 行者棍、罗汉伏魔棍、降魔杵法 | 杵法并入棍 |
| 枪 | — | 待扩充 |
| 拳 | 伏虎拳 | — |
| 掌 | 开山掌 | — |
| 指 | — | 待扩充 |
| 腿 | — | 待扩充 |
| 暗器 | 袖里针、飞蝗石、落英飞针、牵机镖 | 单独成类 |

- 扩充数量另出一份武学名录（裁决 30）。名录扩版把全部武学改名为「xx剑法」「xx拳法」这类叫法，上表是改名前的旧名，对照见 `../wuxue-catalog/design.md` §7.2。

## §4 武学掉落

### 4.1 两种形态

| 武学品质 | 掉什么 | 拿到后 |
|---|---|---|
| 寻常 | **某一式全本**，一次掉落就完整 | 自动学会这一式（裁决 15）；这部武学要玩家装进武学槽才会出招 |
| 上乘 / 绝学 | **某一式残页**，凑齐 N 页得这一式的口诀 | 口诀永久保留；这一式仍要按现行规则顿悟才会（`../sect-neigong/spec.md` §2.3） |

- **第一式**的全本 / 口诀就等于这部武学的秘籍：它是书肆购买、Boss 首杀之外的另一条来路。
- 需要「招式秘籍」才能顿悟的高阶式（上乘第 4–5 式、绝学第 5–7 式），口诀可以代替招式秘籍。
- 界面显示残页进度，比如「惊鸿剑 · 第二式 残页 2/4」。

### 4.2 残页需求数

每式要凑的页数随武学品质走，上乘少于绝学（裁决 16）。靠后的式要不要更多页，`[待 sim]`：

| 品质 | 每式残页数 |
|---|---|
| 上乘 | `[待 sim]`（如 3–5） |
| 绝学 | `[待 sim]`（如 5–8），恒大于上乘 |

### 4.3 纯随机掉落，学的顺序不变

- 掉哪部武学、哪一式都是纯随机，不看玩家已经学到第几式（裁决 12）。
- 学的顺序仍是从第一式往后：
  - **寻常**：捡到的全本，如果前一式还没学会，就先收进书匣；前一式学会的那一刻，自动学会这一式。
  - **上乘 / 绝学**：残页随时可以攒；拼成的口诀只给资格，顿悟本来就要求前一式先到「熟练」（`../sect-neigong/spec.md` §2.3），顺序由顿悟规则保证。
- 掉落池按地图、难度分层：前段图只掉寻常武学，上乘、绝学的残页从中后段图开始掉 `[待 sim]`。

### 4.4 重复掉落

重复掉落不做转换，原样保留（裁决 17）：

- **寻常全本**：已领悟的招式每世清空，口诀不清。所以这一世还没学会这一式（比如前世会、这一世还没重新学），捡到全本就照常学会；这一世已经会了，全本原样收在书匣里，不起作用。
- **残页**：这一式的口诀已经拼齐，多出来的残页原样留在书匣里，不起作用。

## §5 境界 1 的节奏：内功教学关

### 5.1 第一世

## §6 留给 sim 与名录的事项

设定层面的问题已全部裁决，下列事项由后续步骤给出数值：

1. **装备战力预算**（sim）：标准玩家穿一身「当前档」装备，前沿要比现在多出多少境界当量（每 +0.05 当量约等于往前推一关；一个境界当量约 20 关）。这决定掉落率、品阶系数、词条区间的全部数值。暗器槽多出一份战力，要一起算进去。
2. **境界 1 能推到第几关**（sim）：内功 + 武学 + 装备叠起来的前沿、书肆开张关 X、首通银两和精英名号声望提前多少，节奏守卫（三路线首达境界 2–6 在里程碑 ±20% 内）是否仍通过。
3. **背包格数**与一键出售的门槛（sim）。
4. **装备名前缀顺序**：按词条数值从高到低。
5. **「暴击」改「会心」的文案范围**：属性面板、战报、失败诊断、冻结文案（`rules/copy/battle.md`、`battle-narration.md`）一起改，代码内部字段名不动。随实装做。
6. **武学名录扩版**（裁决 30）：各类目门数、品质、路数、获取途径、招式名与战报句子。
