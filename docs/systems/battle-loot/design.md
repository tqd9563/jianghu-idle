## §0 这套系统在做什么

现在本作有两条挂机线，但只有一条有产出：

- **修炼挂机**产内力，内力推境界，是主进度。
- **战斗挂机**只产银两。第一次通关后，重打一关只给两成半（裁决 39）银两，连续重打还每次再打八折，挂十场就只剩不到一成。玩家卡关时除了干等境界，没有别的事可做。

本系统给战斗挂机一个自己的产出：**装备和武学**。它们只加战力，让玩家**不升境界也能往前推关**；内力和境界节奏完全不碰。

境界 1 的空档也一并解决：现在第一世在境界 1 要停大约 3 小时（`../pacing/design.md` §2），入门关几分钟就打完，后面只能挂着等突破。本系统把内功、武学、装备都提前到境界 1，让这 3 小时有关可打、有东西可拿。

## §2 战斗挂机

### 2.1 挂机入口

现在的「自动连战」开关有三个问题：输一场就停；首通后会自动去打下一关，在打不过的关输掉后停下，玩家得自己退回去点「重打」；它是个开关，不像一个挂机入口。

改成：

- 已通关的关卡上有一个明确的 **「在此挂机」** 按钮，按下后就一直原地重打这一关。
- **推关和挂机分开**：推关是「打下一关，赢了接着往前」；挂机是「守着一关反复打」。推关输了，自动退回最近一个已通关的关卡挂机，不再停下不动。
- 挂机中输了（比如身上带着伤）就退一关继续挂，不停机。
- 挂机的关卡记进存档，离线结算按它算（§2.3）。

### 2.2 一场挂机的收益

| 产出 | 规则 |
|---|---|
| 银两 | 重打这一关给首通银两的两成半（裁决 39，原五成），**不再有连刷递减**（裁决 14） |
| 装备 | 按关卡掉落率掷骰（§3.4）；重打的精英 / Boss 按普通关掉落率、品阶加成保留（裁决 38） |
| 武学 | 按关卡掉落率掷骰（§4）；重打同上 |
| 内力 | 不给（裁决 1） |

一场战斗本身要演一段时间（约 2.7 秒一回合），所以每小时能拿多少东西，已经被战斗时长卡住了，不需要再叠递减。

### 2.3 离线

- 离线时按挂机关卡折算场次：`离线场次 = 有效离线秒数 ÷ 这一关的平均战斗时长 × 胜率`，上限沿用离线结算的 24 小时（`../../rules/offline-rewards.md`）。
- 每场照常掷掉落。出关结算屏里列出银两、新装备（按品阶汇总）、武学所得。
- 胜率和平均时长在下线那一刻按当时的战力算一次，离线期间不变。
- 背包装不下时，低于当前所穿品阶的装备自动卖掉（§3.5）。

## §3 装备

### 3.1 部位与基础属性

| 部位 | 武侠里的样子 | 基础属性（类别固定，数值随机） | 型（裁决 36） |
|---|---|---|---|
| 兵器 | 分刀、枪、剑、棍四类：柴刀、白蜡杆、铁剑、齐眉棍…… | 攻击 | 重型：攻击 ×1.08；轻型：攻击 ×0.92，另带少量命中 |
| 暗器 | 镖囊、针筒、石囊、袖箭…… | 攻击、命中 | 锐型：攻击 ×1.15、命中 ×0.85；准型：反之 |
| 衣甲 | 粗布短打、皮甲、软甲、锁子甲…… | 气血、防御 | 厚型：气血 ×1.15、防御 ×0.85；坚型：反之 |
| 佩饰 | 铜钱串、香囊、玉佩、护身符…… | 命中或闪避 | 命中型 / 闪避型（二选一） |

- **型**是同一部位里的种类：每部位两个型，决定基础属性往哪边偏，总量不变；掉落时型随机。系数经实装后复核维持（`spec.md` §7）。
- 品阶越高，基础属性的取值区间越高（§3.3）。
- 名字按型 × 品阶配一张名表（`../../rules/copy/gear-names.md`，兵器再按类别分列，共 70 个名），一格一名；同型同品阶靠词条前缀区分。
- **一名一图**：名表里每个物件各有一张写实材质风格的道具图（`code/public/art/gear/<key>.png`，透明底，低饱和古旧色调），背包格、穿戴列表、比较面板、市集与黑市都用它；同一物件不同品阶不换图，品阶靠描边色与名字色。武学书封与底图维持水墨，道具走写实，是有意的对比。
- 兵器类别决定能装哪些器械武学（§3.7）；类别纯随机掉落（裁决 25）。

### 3.1a 装备名

装备名 = 词条前缀 + 物件名（裁决 26）：

- 没有词条：只有物件名，如「幽兰剑」。
- 一条词条：「锋锐的幽兰剑」。
- 两条及以上：前缀直接连写，最后加「的」，如「坚韧强健的蝮蛇甲」。最多 4 个前缀，也就是全部词条都上名字（裁决 29）；前缀按词条数值从高到低排。

### 3.2 词条

| 品阶 | 白 | 绿 | 蓝 | 紫 | 橙 |
|---|---|---|---|---|---|
| 词条数 | 0–1 | 1–2 | 2–3 | 3–4 | 4（第一期） |

词条池按部位分（裁决 18）。词条从本部位的池里随机抽，同一件装备的词条不重复：

| 词条 | 作用 | 兵器 | 暗器 | 衣甲 | 佩饰 |
|---|---|:-:|:-:|:-:|:-:|
| 攻击 +x% | 乘进攻击 | ✓ | | | |
| 会心率 +x pp | 加会心率 | ✓ | ✓ | | ✓ |
| 会心伤害 +x pp | 加会心伤害 | ✓ | ✓ | | |
| 命中 +x | 加命中 | ✓ | ✓ | | ✓ |
| 对精英 / Boss 伤害 +x% | 只对硬仗生效 | ✓ | ✓ | | |
| 气血 +x% | 乘进气血 | | | ✓ | |
| 防御 +x% | 乘进防御 | | | ✓ | |
| 闪避 +x | 加闪避 | | | ✓ | ✓ |
| 真气上限 +x | 武学能多出几招 | | | ✓ | ✓ |
| 武学伤害 +x% | 只对招式生效，不加普攻 | | ✓ | | ✓ |

- 兵器、暗器、佩饰各 5 个候选，衣甲 4 个；第一期橙装 4 条，抽不空池子（裁决 21）。伤势抗性要等受伤系统接上后再加。
- 每个词条另有一个武侠名，用作装备名前缀（§3.1a）：

| 词条 | 前缀 |
|---|---|
| 攻击 +x% | 锋锐 |
| 会心率 +x pp | 凌厉 |
| 会心伤害 +x pp | 穿心 |
| 命中 +x | 精准 |
| 对精英 / Boss 伤害 +x% | 破军 |
| 气血 +x% | 强健 |
| 防御 +x% | 坚韧 |
| 闪避 +x | 轻灵 |
| 真气上限 +x | 蕴气 |
| 武学伤害 +x% | 通玄 |

  会心率的前缀不直接叫「会心」，是因为它和属性名重名了，「会心的铁剑」读着别扭。前缀一律两字，四个拼起来八字加「的」（2026-10-13 定稿：锋锐 / 凌厉 / 穿心 / 精准 / 破军 / 强健 / 坚韧 / 轻灵 / 蕴气 / 通玄）。
- 每个词条的取值区间随品阶抬高（§3.3）。数值一律整数（裁决 37）：百分比与 pp 到 1%，命中 / 闪避 / 真气到 1。

### 3.3 数值怎么随关卡长

敌人强度随关卡当量指数增长（当量每 +1 约强一个境界，属性 ×1.7，`../../rules/content.md` §2.0）。固定数值的装备很快就会过时，所以：

- 每件装备带一个**装备等级**，等于它掉落关卡的当量。
- 基础属性 = 该部位基准 × 1.7^(装备等级 − 1) × 品阶系数 × 随机浮动。
- 百分比词条不随装备等级涨，只随品阶涨；数值词条（命中、闪避）随装备等级涨。

挂越往后的关，掉的装备越强。这样就形成「推关 → 掉更强的装备 → 再推关」的循环。

### 3.4 掉落率

- 每场胜利按关卡掷一次装备掉落。精英和 Boss 的掉落率更高，品阶也偏高。
- 品阶分布随关卡位置往高处偏移。一个可能的形态是：前段关卡几乎只出白、绿；越往后，蓝、紫越常见；橙极少见。
- 具体概率 `[待 sim]`，按「标准玩家一世里各品阶拿到几件」倒推（§5）。

### 3.5 背包与出售

- 背包按部位形态占格，格数与放不下时的处理见 `spec.md` §1.4。
- 卖装备换银两，价格按品阶 × 掉落关卡首通银两（`spec.md` §1.4）。
- 一键出售「上乘以下」的装备；背包满了，不比身上强的新掉落直接卖掉。

### 3.6 每世清零

- 转世时，装备和背包一律清空（裁决 8）。
- 下一世开局又从赤手空拳开始。不过有宿慧和内功加成，前段关卡会推得比上一世快，装备也会更快补齐。

### 3.7 兵器与武学搭配

## §4 武学掉落

> v1.7 按裁决 42 重写（2026-10-19）。旧版「每式凑 5 / 7 页、口诀顶招式秘籍、顿悟领悟」已废止。

### 4.1 两种形态

| 武学品质 | 掉什么 | 拿到后 |
|---|---|---|
| 寻常 | **整门**，一次掉落就完整 | 立刻能出第一式；这门武学要玩家装进武学槽才会出招（裁决 15） |
| 上乘 / 绝学 | **某一式的那一页残页**：一门几式就几页，一页对应一式 | 有第一式那页即得这门武学，可装配、可出第一式；不必集齐 |

- 武学的来路：挂机掉落、市集武馆（寻常整门）、Boss 首杀（给第一式那一页）、黑市蒙面货（某一式那一页）、门派贡献商店（绝学一式一页）。
- 界面逐式显示：有页实心、缺页虚线，锁定行只写「缺少残页」或「待第 X 式圆满」（`../../design/wuxue-form-unlock-prototype.html`）。

### 4.2 解锁下一式：前一式圆满

- 第一式到手即可出。
- 第 k 式能出，要同时满足：
  1. **有这一式**：寻常有了整门就有；上乘 / 绝学要有第 k 页。
  2. **第 k − 1 式已能出，并练到「圆满」**（熟练第 4 档；出招数见 `../sect-neigong/spec.md` §2.2，本门武学 ×0.8）。
- 条件满足的那一刻自动接上，不判顿悟，也不看境界、真气。
- 例：有第一、三页，第一式圆满了也出不了第三式，要先得第二页、再把第二式练到圆满。

### 4.3 纯随机掉落，转世重练

- 掉哪部武学、哪一式都是纯随机，不看玩家已经练到第几式（裁决 12）。残页可以不按顺序攒，用起来仍从第一式往后接。
- 武学与残页跨世保留；**熟练每世清零**，所以已解锁的式下一世要从第一式重新练到圆满再接上。
- 掉落池按地图、难度分层：境界 2 只掉寻常，上乘残页境界 3 起进池（`spec.md` §2.2）。

### 4.4 重复掉落

重复掉落不转熟练，折成银两（裁决 17 改）：已有的寻常整门折 30 两，已有的那一页折 60 两 `[待 sim]`。

### 4.5 出招与熟练：招式库（裁决 45 / 46）

**一门武学怎么出招**

1. 先抽门：各门触发几率求和、封顶 75%，按几率加权抽一门（`spec.md` §3.3）。几率已按「装满 10 槽合计约 75%」标定，上限只在少数搭配下才碰到。
2. 再抽式：这门已能出的式里，筛掉当前真气出不起的，剩下的按**基础耗气**（未经熟练打折）加权抽一式。贵的式出得多，真气见底时自然滑向轻招。
3. 扣这一式的实际耗气（基础 × 熟练倍率），这门进入冷却。

**各式怎么拉开**

| 项 | 第一式 | 往后每式 | 末式 ÷ 第一式（寻常 / 上乘 / 绝学） |
|---|---|---|---|
| 倍率 | 品质基准 × 类型系数 | ×1.12 | 1.25 / 1.57 / 1.97 |
| 基础耗气 | 品质基准 × 耗气倾向 | ×1.15 | 1.32 / 1.75 / 2.31 |
| 特效 | 四档插值 × 类型系数 | 随档位递增 | 类型不变、数量不加 |

**品质与类型**（第一批 66 门实装值）

| 品质 | 类型 | 第一式倍率 | 触发几率 | 门数 |
|---|---|---|---|---|
| 寻常 | 重击 / 折中 / 双强 | 1.98 / 1.48–1.65 / 1.98 | 中位 11% / 15% / 7.5% | 5 / 25 / 6 |
| 上乘 | 重击 / 折中 / 双强 | 2.28 / 1.71–1.90 / 2.28 | 中位 6% / 7.5% / 7% | 6 / 9 / 3 |
| 绝学 | 重击 / 折中 / 双强 | 2.83 / 2.12–2.36 / 2.83 | 中位 4.8% / 5.5% / 3.7% | 2 / 6 / 1 |

- 类型系数：重击倍率 ×1.2、特效 ×0.5；双强倍率 ×1.2、特效 ×1.5；折中倍率 ×1（倍率倾向「低」的 ×0.9、特效 ×1.25）。必暴与附毒的主效果（必定会心、额外 1 层）不随系数变。
- 同序号的式两两比较，上乘倍率高于寻常约 85%、绝学高于上乘约 94%；耗气两项都在 95% 上下。剩下的是特例：寻常的重击 / 双强第一式可以比上乘的折中还重。
- 装满 10 槽（如 2 寻常 + 4 上乘 + 4 绝学）合计触发几率约 0.75；境界 2 装 6 门寻常约 0.8；境界 4–5 装 8–9 门约 0.5–0.6。

**熟练只做一件事**：减这一式的耗气，熟练 / 精通 / 圆满 ×0.92 / ×0.84 / ×0.75。圆满的第 k 式约等于第 k − 1 式生疏时的价（1.15 × 0.75 ≈ 0.86）。触发几率与冷却不随熟练变。

**熟练阈值**（每一式的累计出招数，`../sect-neigong/spec.md` §2.2）：寻常 40 / 100 / 250，上乘 50 / 125 / 300，绝学 60 / 150 / 350。按新参数实测，练到末式解锁的挂机时长（`../sim/cast_rhythm_measured.json`）：

| 品质 | 装配 | 第二式 | 末式 |
|---|---|---|---|
| 寻常 | 境界 1 单门 / 境界 2 装 6 门 | 约 2 小时 | 5.3 / 5.6 小时 |
| 上乘 | 境界 3 | 4.4 小时 | 35 小时 |
| 绝学 | 境界 4 / 5 | 8.5 / 7.6 小时 | 157 / 126 小时 |

- **绝学一世练不完**（用户 2026-10-21 认可）：境界 4–5 一世 3–5 天，绝学末式要五六天挂机；要接着练，靠刻骨铭心把主修武学的熟练带到下一世。
- **界面不展示类型**（用户 2026-10-21 定）：重击 / 折中 / 双强只是校准口径，玩家从倍率、特效数值与触发几率自己看出来。

**真气两种用法**：推图每关回满，真气是场内预算，后期够用、重招频出（实测「真气不足」不到 1%）；副本不回复，真气是跨场储备，越打越少、只剩轻招，真气上限、耗气高低与回气类特效在这里才有分量。两处共用同一套抽式规则。

**怎么校准**：`calib_cast.py` 先用解析模型反解触发几率，再用真实战斗逐门量余量（`code/src/telemetry/castDoors.sim.test.ts`），按「同品质均值 ÷ 本门余量」修正、迭代到同品质余量相差 ≤0.04 当量。改版前后各境界标准装配的前沿差在 ±0.1 当量内，境界 5–6 全部圆满时多 +0.15–0.2（`castBalance.sim.test.ts`，对照同日 main）。

### 5.1 第一世

3. **背包格数**与一键出售的门槛（sim）。
4. **装备名前缀顺序**：按词条数值从高到低。
5. **「暴击」改「会心」的文案范围**：属性面板、战报、失败诊断、冻结文案（`rules/copy/battle.md`、`battle-narration.md`）一起改，代码内部字段名不动。随实装做。
