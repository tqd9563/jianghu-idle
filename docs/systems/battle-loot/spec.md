## §1 装备

### 1.1 基础属性

装备等级 ℓ = 掉落关卡的当量（`design.md` §3.3）。基础属性沿敌我同一条曲线 1.7^(ℓ−1) 放大：

```text
兵器   攻击 = 0.036 × 100  × 1.7^(ℓ−1) × 品阶系数 × 浮动
暗器   攻击 = 0.021 × 100  × 1.7^(ℓ−1) × 品阶系数 × 浮动；命中 = 0.65 × 品阶系数 × 浮动 × (1 + ℓ/5)
衣甲   气血 = 0.0175 × 1000 × 1.7^(ℓ−1) × 品阶系数 × 浮动；防御 = 0.0175 × 50 × 1.7^(ℓ−1) × 品阶系数 × 浮动
佩饰   命中或闪避（随物件二选一） = 1.05 × 品阶系数 × 浮动 × (1 + ℓ/5)
浮动 ∈ [0.90, 1.10]
整数口径（裁决 37）：以上结果四舍五入、最低 1；词条百分比 / pp 取整到 1%，命中 / 闪避 / 真气取整最低 1。sim 以整数口径跑：余量与浮点口径相差 ≤ 0.02，境界 1 蚀骨 / 镇岳各多推 1–2 关
型系数（裁决 36；§7 复核：两型余量差 ≤ 0.04 当量，维持）：兵器 重型 攻击 ×1.08 / 轻型 ×0.92 另带命中 0.31 × 品阶系数 × (1 + ℓ/5)；暗器 锐型 攻击 ×1.15、命中 ×0.85 / 准型 反之；衣甲 厚型 气血 ×1.15、防御 ×0.85 / 坚型 反之
```

100 / 1000 / 50 是境界 1 的攻击 / 气血 / 防御基准（`../../rules/content.md` §1 v2.9 展示尺度；sim 里是 10 / 100 / 5），所以一把白兵器约等于「同当量玩家裸攻击的 3.6%」，橙兵器约 8.5%。

### 1.4 背包与出售

- 背包按形态占格（DESIGN.md「行囊」）：10 列 × 8 行共 80 格，兵器 1×3、暗器 1×2、衣甲 2×2、佩饰 1×1，约合 30–40 件：标准玩家在线 4 小时掉约 40 件（§2.2），一上线清一次正好。
- 放不下时（`design.md` §3.5）：新掉的不比身上强就直接卖掉；比身上强的，卖掉背包里品阶最低的腾位，腾不出（背包里全比它好）才卖掉它自己。在线、离线同一规则。
- 出售价 = 掉落关卡首通银两 × {白 0.5, 绿 1, 蓝 2, 紫 5, 橙 15}，最低 1 两 `[待实测]`：一世的装备卖出约等于一世首通银两的一到两成，不冲击市集定价。

## §2 掉落

### 2.1 概率

| | 普通关 | 精英 | Boss |
|---|---:|---:|---:|
| 每场胜利掉一件装备 | 6% | 20% | 100% |
| 每场胜利掉一次武学（整式 / 残页） | 3% | 10% | 50% |

上表只在**首通**时按精英 / Boss 取；重打（含挂机、离线）一律按普通关的 6% / 3% 掷，品阶的精英 / Boss 加成保留（`design.md` 裁决 38）。

装备品阶按关卡在本前沿里的位置 pos（0 = 段首，1 = 段末）取权重，再归一：

```text
白 55 − 40·pos   绿 35   蓝 8 + 14·pos   紫 0.06 + 0.18·pos   橙 0.01 + 0.03·pos
精英：三成概率品阶 +1；Boss：必 +1
```

即段首约 白 56% / 绿 36% / 蓝 8%；段末 白 14% / 绿 35% / 蓝 22% / 紫 0.24% / 橙 0.04%（未计精英升阶）。

### 3.2 校准：同品质同强度

> **已被取代**（2026-10-21，裁决 46）：阀门由倍率改为触发几率，强度按「全部圆满、推图」语境计并经真实战斗逐门修正，见 `design.md` §4.5。下文留作历史。

- **强度** = 每回合期望输出（相对只普攻）÷ (1 − 受击减免)。出招比例 f = min(1 / (冷却 + 1 / 触发), 20 / (3 × 有效耗气 + 20))——真气按「3 门同装」分摊，单门时真气永远够用、耗气会变成死参数。防御类特效（护体、轻身、卸力、迷目、封穴）折成受击减免，进攻类折成输出。参考环境取境界 4 平台末。
- **品质锚** 固定为寻常 1.166、上乘 1.140、绝学 1.094（v1.2 时「中 / 中 / 中 / 中」配四种旧特效、特效只挂首末式的平均强度）。v1.3 特效改为每式都带（§3.4），锚不随之抬高，多出来的特效价值由倍率吸收，武学整体强度不变。
- **倍率是阀门**：每门武学按倾向取定触发、耗气、冷却后，反解第 1 式倍率使强度 = 锚；倍率不低于 1.0（招式不弱于普攻）。到底仍超锚的 10 门改降触发几率到恰好落锚（寒蝉凄切掌 −22 pp、飞星逐月拳与落英缤纷针 −14、罗汉伏魔棍 / 游身掌法 / 幽篁蛇影指 −10，其余 4 门 −2）——都是护体 / 附毒这类按次生效、倍率压不住的特效。
- **MC 复核**（境界 4、3 门同款上乘、三路数平均）：七种风格余量 +0.18–0.27、十四种特效 +0.18–0.27，相差 ≤ 0.08，解析模型与实战一致。持续类特效的覆盖率按 1 − (1 − f)^3 算（同名只刷新不叠加），附毒按 8 层上限打八折。
- 独门三门（落星沉海剑 / 金刚降魔杵 / 牵机引魂镖）不校准，沿用现行倍率。
- 现有 14 门的倍率随同组重标：回气类抬高（渡江棍法 1.30 → 1.96、惊鸿照影剑 1.50 → 1.90），必暴、附毒类压低（苍崖九叠剑 1.45 → 1.02、大江断流刀 1.50 → 1.05、落英缤纷针 1.45 → 1.03）——回气在真气够用时几乎没价值；必暴、附毒每式都带后价值翻了几倍。

### 3.3 触发求和

```text
总触发率 = min(75%, Σ 当下能出招的武学的触发几率)      // 在冷却、真气不够的不计
掷骰 < 总触发率 → 按各门触发几率加权抽一门 → 等概率抽一式
```

出招率（圆熟）：5 门全「高」0.75、全「中」0.75、全「低」0.72；3 门第一批上乘 0.57（原固定 55% 规则约 0.55）。

## §6 实装口径

- 装备在开战前叠进构筑（`apply_gear`，代码 `gear.ts` `applyGearToBuild`），`fight()` 内部不认识装备——与伤势同一条安全通道，顺序为「内功构筑 → 装备 → 伤势」。百分比词条乘进基础值，命中 / 闪避 / 真气上限相加，会心率封顶 80%；「破军」按关卡种类（精英 / Boss）生效，「通玄」只乘招式倍率。
- 掉落在胜利结算时掷骰（§2.1），传功（选内功）之前不掉；入门关只出白绿（裁决 19）。装备等级取关卡当量，出售价基数取该关首通银两。离线按挂机胜场逐场掷骰（`../../rules/offline-rewards.md` §1.1）。
- 触发求和、持续增益 / 减益、连击、透劲、封穴、回元进 `combat.ts`；持续状态用「名字 → [剩余回合, 数值]」，回合末递减。golden 测试：不装武学、不穿装备时逐项不变（判据 1）。
- 171 门参数以 `wuxue-params.json` 为准，代码读表不手抄。
- 战斗时长假设 2.7 秒 / 回合 + 2.5 秒，若实装改了战报节拍，§2.2 的「件 / 世」按比例变，概率不变。

- **大概率亏、小概率赚**：权重 40 / 35 / 20 / 4.5 / 0.5。一件蒙面货的价钱等于挂一天（前期）的进账，而挂一天能捡 90–120 件、其中蓝品十来件、紫品约一件；开出凡品 / 精良 / 上乘（95%）都不如那一天的掉落，只有珍品以上（5%）算赚。黑市多出的是「指定部位」与一把赌。
