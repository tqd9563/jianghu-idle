## 1. 伤型表

每一类伤是一行配置，新增伤型只加一行，机制骨架不变（`design.md` §3.1）。

| 字段 | 含义 |
|---|---|
| `id` | 伤型标识 |
| `name` | 玩家可见名 |
| `combat` | 战斗影响：压哪些 Build 字段 |
| `idleWeight` | 修炼影响权重：乘在严重度压制值上，得出挂机产出压制 |

首发三行：

| id | name | combat（压 Build 字段） | idleWeight |
|---|---|---|---:|
| `wai` | 外伤 | `dfs`（防御）、`hp`（血上限，按压制值 ×0.66） | 0.25 |
| `nei` | 内伤 | `atk`（攻击） | 0.75 |
| `du` | 毒伤 | `hit`（命中）、`dodge`（闪避） | 0.45 |

`idleWeight` 的分级依据：修炼靠经脉运行气血——内伤伤在根子上最重，毒伤须分心镇压居中，外伤只是难以入定最轻（`design.md` §3）。

## 2. 严重度表

每种伤型一条严重度轴，取值 0–3；越过 3 即触发致死（§5）。

| severity | 名称 | 战力压制 | 自愈时长（降一档，游戏内分钟） |
|---:|---|---:|---:|
| 0 | 无 | — | — |
| 1 | 轻 | 10% | 3 |
| 2 | 中 | 25% | 8 |
| 3 | 重 | 45% | 20 |

**战力压制值为 45% 封顶的依据**：sim 扫描 10%–50% 区间显示，压制一旦超过 20%，带伤作战必败或惨胜、反添新伤，「带伤打还是养伤」的权衡消失，理性解永远倒向养伤。10/25/45 是唯一保有权衡空间的档位（`../sim/injury_sim.py` 扫描输出）。

## 3. 挂机产出压制

```text
产出乘数 = max(FLOOR, Π(1 − 压制值[severity] × idleWeight[伤型]))
FLOOR = 0.40
```

多种伤并存按乘法叠加；地板 0.40 防止同时带三种重伤把修炼归零。

各伤型单独带伤时的产出乘数（由上式导出，供实现自检）。**以下为精确值，实现须逐值对齐**，界面显示可自行取整：

| 伤型 | 轻 | 中 | 重 |
|---|---:|---:|---:|
| 内伤 | 0.925 | 0.8125 | 0.6625 |
| 毒伤 | 0.955 | 0.8875 | 0.7975 |
| 外伤 | 0.975 | 0.9375 | 0.8875 |

三种重伤并存：0.6625 × 0.7975 × 0.8875 ≈ **0.469**（地板 0.40 未触发，仅作边界参考）。

## 4. 获取判定

受伤**只在硬仗产生**，普通关卡战斗不产伤（`design.md` §1）。

| 触发 | 条件 | 效果 |
|---|---|---|
| 硬仗失败 | 败给 Boss 或精英 | 对应伤型 severity +1 |
| 关键战惨胜 | 战胜 Boss 或精英，且战后剩余血量 < 25% | 对应伤型 severity +1 |

**伤型归属**（首发最小形态，对应 `design.md` §1 预留扩展的起点）：

| 敌人特征 | 伤型 |
|---|---|
| 带「毒」标签 | 毒伤 |
| Boss | 外伤 |
| 精英（无毒标签） | 内伤 |

## 5. 恢复速率

**主路径：时间自动疗愈**（`design.md` §2.1）。

```text
实际自愈时长 = 自愈时长[severity] × 境界系数
境界系数 = max(0.5, 1 − 0.05 × (境界 − 1))
```

- 境界系数为次要修正，主导恢复速度的仍是严重度档位；下限 0.5 防止高境界自愈过快使伤势失效。
- 自愈在**在线与离线同样进行**，离线按结算时长计入、沿用现有离线封顶（`design.md` §2.1）。
- 自愈期间**挂机产出仍受压制**（§3），即养伤本身带着修炼损失。

**辅路径：资源加速疗伤**为可选项，具体形态待定（`design.md` §7 开放问题），不在本版规格内。

## 6. 折寿与致死接口

对外暴露给转世系统（对上 `../reincarnation/design.md` §9 接口行）。

| severity | 寿元影响 |
|---:|---|
| 0–2（无/轻/中） | **不折寿**，纯战斗与修炼 debuff |
| 3（重） | 升入重度时一次性折寿 **15 年** |
| 越过 3 | 触发**强制转世**（声望按六折结算，见 `../reincarnation/design.md` §3.1） |

**接口约定**：

```text
lifespanLoss(伤势) → 年数     // 重度以下为 0；升入重度返回 15
isLethal(伤势, 新受创) → bool  // 已在重度且同伤型再受创 → true
```

## 7. 验收判据

实现后须复现 `../sim/injury_sim.py` 的 V6–V9 全部 PASS：

| 判据 | 内容 | sim 实测 |
|---|---|---|
| V6 | 无死亡螺旋：稳健画像不战死且能推进 | 28/28 关，存活 |
| V7 | 受伤稀疏度：稳健画像单轮受伤 1–15 次 | 11 次 |
| V8 | 硬撑代价显著高于稳健 | 稳健折寿 0 年 / 硬撑折寿 15 年且战死 |
| V9 | 养伤不拖垮进度：稳健画像单轮 ≤90 分钟 | 46.2 分钟 |

## 8. 调参优先级

改动时按此顺序考虑，越靠前影响面越大：

1. **严重度压制值**（§2）——直接决定权衡是否存在，超过 20% 权衡即消失，动它须重跑 V6–V9。
2. **自愈时长**（§2）——主导单轮时长（sim 中养伤占稳健画像 64% 时间），拉长会显著拖慢轮次。
3. **获取判定阈值**（§4）——惨胜血线决定受伤频率，直接影响 V7。
4. **折寿量与致死线**（§6）——影响 V8 与转世系统的战死频率。
5. **idleWeight / 地板**（§1/§3）——影响最小，正常区间内不改变玩家行为。

## 9. 已知局限

**正常玩家对伤势基本无感**。sim 显示稳健画像的单轮时长在任何战力压制幅度下均为 46.2 分钟，纹丝不动——因为他永远养满才开打，压制再狠也碰不到他；而养伤在放置游戏里等同于白等，不构成痛感。

要堵住「养好就没事」这条逃生通道，需要引入伤势无法靠等待规避的代价（如重伤跌境界）。该方向已评估但本版搁置，作为开放项挂账。
