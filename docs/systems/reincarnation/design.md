## §0 这套系统在做什么，和现有系统什么关系

现在游戏里的「归隐—声望」是一套抽象的重开加成：每轮重来、带着上一轮买的节点变强。本系统给它换一层真实的世界观骨架——**声望不再是抽象的「重开」，而是玩家角色在江湖历纪元中一次次「转世」**：这一世活了多少年、江湖历走到哪一年、你是正是邪，都真实发生、真实留痕。

一句话概括新设定：**玩家开局资质平平，偶得一卷上古不灭功法。功法分正邪两面，每次转世须择其一。你带着上一世的修为底蕴重生，在接续的江湖历年代里再闯一遍江湖。**

**和 `economy.md` 的分工**：`economy.md` 仍然是声望结算的**实现权威**（公式、8 节点、收支都以它和代码为准）。本文只定**框架**——时间怎么走、寿元怎么算、正邪怎么影响结算。等这些真正编码时，再回头给 `economy.md` 升版补上接入点（见 §4.4、§3.1）。**在那之前，`economy.md` 不改动**，避免实现权威描述还没实现的东西。

## §1 时间与纪元

### §1.1 两个时钟：角色年岁 和 江湖历

系统里有两个时钟，它们同步走、但含义不同：

- **角色年岁**：这一世的角色多少岁。涨到寿元上限就被迫转世（见 §2）。
- **江湖历**：整个江湖的纪年，像「江湖历 137 年」。它决定世界背景——哪个门派正当兴盛、谁在朝堂当权、这个年代流行什么武学。

两者都**只在你游玩时前进**，走的是「游戏内时间」，不是现实日历。你离线再久，世界也不会甩下你几百年——回来时最多只老掉离线结算覆盖的那一小段。

### §1.2 年岁怎么算（公式骨架）

```text
当前年岁 = 初始年龄
         + (在线时长 + 封顶后的离线结算时长) × 年岁速率     ← 游戏内时间累积（在线离线同速率）
         + Σ 事件年龄修正                                ← 重伤折寿等（见 §2.2）

当前江湖历 = 上一世终点年份 + (当前年岁 − 初始年龄)
```

要点：
- **在线、离线同一个年岁速率，离线只受「封顶」限制**：年岁是「游戏内时间」的累积，不是资源产出，所以不套用离线的资源折扣（`offlineEfficiency`，那是内力/银两/阅历的产出打折，与年岁无关）。离线唯一的差别是：能累积的游戏内分钟被现有离线结算的**封顶**截断——离线只能存到 cap 那么多分钟，但每一分钟老得和在线一样快。一句话：活一分钟就老一分钟，只是离线能存的分钟有上限。这样活跃玩家和挂机玩家，每一世投入的「游玩量」大致公平，不会因为作息不同被惩罚。
- **突破不耗年岁**：境界突破是水到渠成的瞬间，本身不花时间；花时间的是突破之前那段积累，而积累就发生在上面的游戏内时间里，已经算进去了。
- 具体系数（年岁速率、初始年龄）待 sim 标定，见 §6。

### §1.3 转世时，江湖历怎么接续

江湖历在世内是连续走的（你 71 岁那一世，江湖历就从 100 真实走到了 171）。转世时，**下一世直接从你上一世谢幕的那个年份接着算**——第一世活在江湖历 100–171，第二世就从 171 往后。纪元因此一世一世往前推，自然分段，正好对应「第一轮 100–200 年、第二轮接着往后」的设定。

## §2 寿元与死亡

### §2.1 寿元是「一生的容量上限」，不是倒计时

寿元不是一个滴答倒数的沙漏，而是**这一世能活到的岁数上限**。角色出生自带一个寿元（首版定 120 岁；主角身负不灭功法，寿元本就超凡）。年岁一旦触到这个上限，就被迫转世。

平时你不会时刻盯着寿元，因为多数时候你会**主动**在合适的时机归隐转世（见 §3）。寿元真正起作用，是当你贪图深推、迟迟不肯收手时——它是一根「拖太久就要吃亏」的鞭子。

### §2.2 两种死法：老死 和 战死

寿元的压力来自两处：

- **老死（底线）**：年岁自然累积，慢慢逼近寿元上限。可预期，是所有人最终都要面对的归宿。
- **战死（尖峰）**：战斗中的**重伤**会直接折损寿元。内伤、外伤、毒伤累积到重度时，寿元可能从 120 骤降到 80，甚至当场不治、立刻被迫转世（代价见 §3.1）。这一刀是突发的、算不准的，给死亡注入了戏剧性。

战死这条，把**受伤系统**（`../injury/`，已定稿并规格化）缝进了转世机制：**受伤不再只是临时掉属性，重到极致会要命**。深推的赌注，因此从「多花点时间」升级成「可能把命搭上」。

## §3 转世与结算

### §3.1 主动归隐无代价，被迫转世来世体弱

转世有两条路，声望都**全额**结算；差别在来世的开局：

- **主动归隐（主路径）**：你自己挑时机转世，来世如常。这就是现在游戏里的归隐循环，原样保留——玩家依然完全掌握「什么时候收手」的主动权。
- **被迫转世（兜底）**：寿元耗尽或重伤不治，强制转世，来世**魂魄未稳**——转世后到首次突破为止，修炼产出打折（数值见 `spec.md` §4）。

**为什么罚来世而不罚本世的声望**（2026-09-24 裁决）：声望经济表 v2.0 把基础声望定为「时间 × 乘区」，声望就是时间。整单打折是把已经花掉的时间抹去一截——用 sim 数字算，贪到老死打六折仍比标准点归隐多拿三成，抽不到人；打狠了又伤到早早战死的新手。所以惩罚改收**未来的时间**：本世攒的一分不少，来世开局虚弱、首个境界修得慢。它和寿元天然咬合——开局弱等于有效寿命短。

老死和战死用同一条规则。战死的人在生前已被折寿罚过一道（§2.2），不再区别对待。

> 同一根杠杆下，代码里「保底归隐六折」一并退役：保底归隐是玩家主动的，归全额。

### §3.2 为什么不做「死亡回档」——避免读档死循环

一个自然的疑问：主角死了要不要像传统 RPG 那样回档重来？**我们明确不这么做。** 因为真实回档会掉进「读档—送死—回档—再读档」的死循环，既没意义又劝退。

我们的解法是：**死亡不是 game over，而是一次带伤的转世**。不灭功法保你魂魄不灭，仓促离世只是让魂魄受了创、来世开局体弱（§3.1）。没有存档可读，也就没有死循环——死亡有真实代价，但游戏永远向前，从不倒退。

### §3.3 跨世带走什么：底蕴中立，正邪每世重来

转世时继承的东西分两层，这一分层是「正邪可切换却不别扭」的关键：

- **声望底蕴（永久继承，中立）**：上一世修为沉淀下来的纯粹实力（声望节点）。它只是「底子厚」，**不带任何正邪色彩**。
- **正义值 / 杀戮值（单世，清零）**：衡量你这一世立场行为的值，每次转世**归零重攒**。

因为带走的底蕴是中立的、正邪值又每世清零，所以「这一世当大侠、下一世当魔头」不会自相矛盾——你不会顶着一身正派印记去行凶。每一世都是干净的新起点。

## §4 正邪

### §4.1 正邪决定「立场和结算」，不锁死「能玩到的内容」

正邪**不做内容门控**——不会因为你选了正派，就永远看不到反派的那部分游戏。世界内容大家都能遇到；**正邪决定的是你的立场**：

- 结算吃哪种值（正派吃正义值、反派吃杀戮值，见 §4.4）；
- NPC 对你的态度；
- 同一个事件里，你能选的选项和后续走向。

举例：同样撞上「魔教血洗华山」，正派玩家可以驰援、赚正义值；反派玩家可以趁火打劫、赚杀戮值。**内容一套、立场分叉**——既有代入感，又不用做两套只能玩一半的互斥内容。

### §4.2 每次转世可重选正邪

正邪**每一世都能重新选**，不是选一次定终身。

叙事上这样圆：不灭功法是件上古外物，不是你的人格。每次转世，功法**在新的魂途里重铸正邪**，你需要重新抉择。所以不是「同一个人朝正夕邪」，而是「这卷功法在漫长岁月里，流转于一具具不同的皮囊、一段段不同的人生」。「世世抉择」的宿命感，比「一次定终身」更贴转世的主题。

### §4.3 切换正邪：一个探索选择，不是数值最优

**切换正邪永远不是「数值上更划算」的选择，它是「想体验另一面」的探索选择。** 三个机制配合，让切换既不会太频繁、也不会从来不发生：

- **复利软封顶**：连续保持同一派转世，会积累这一派的「道心根基」加成（越走越强，但有软上限）。这让**专精成为高效的默认路径**，压住「每世乱切薅好处」的冲动。
- **双修完满成就**：设一个长线目标——正邪双修、集齐两派道心。让追求圆满的玩家，最终也有理由去体验另一面，半数机制内容不会对任何人永久闲置。
- **纪元机遇**：某些江湖大事件给切换一个**有分量的时机**（比如「魔教覆灭、正道招安，此世弃暗投明可得大礼」）。切换因此有了具体的叙事场景，而不是玩家凭空翻牌。

三者合起来：频繁横跳被复利和重置代价压低，从不切换被体验回报和双修目标打破，落点是「以专精为主、切换是重大转折」。

### §4.4 正义值 / 杀戮值怎么接进声望结算

正义值和杀戮值，**并入现有的「表现加成」，共用那个 +30% 的上限**：

- 现在的表现加成来自「精英首杀 + 全通」（`economy.md §1.2`，封顶 +30%）。
- 重构后，再加一项来源：正派算正义值、反派算杀戮值，**和原来的项一起，共享同一个 +30% 封顶**。

这样正邪立场真实影响了声望产出，但**不碰那个用 sim 换来的封顶和防套利结构**——`economy.md` 的收益公式、收支、防套利几节几乎零改动，只在表现加成里多加一行来源。

> **⚠ 本节接入口径已过期**：上文按 `economy.md` **v1.3** 的「表现加成 +30% 封顶」写成，而 economy.md 已升 **v2.0**（三层结构：基础层 / 行为乘数 / 成就层），该封顶不复存在。**「正邪影响声望产出」的设计意图不变，但接入哪一层须重新裁决**——详见 `spec.md` §7。

## §5 世内事件系统

### §5.1 事件不绑「里程碑」，而是从「纪元事件池」里抽

一个要避开的坑：如果事件死绑在进度里程碑上（比如「一推到图 3 就触发某事件」），那每一世走到同一进度都撞同一套事件，哪怕换了皮，节奏也一模一样，玩久了像土拨鼠日。

所以事件这样设计：

1. **每个纪元有一个事件池**，池子里的事件按当前世界状态加权——你的正邪立场、已经发生过的纪元变迁、当下的时代 buff，都会影响哪些事件更可能出现。
2. **每一世从池里抽一个「事件预算」**（比如 2–4 个，数量本身也浮动）。**抽中哪些、抽几个、落在哪，每一世都不一样**——这一世图 3 附近可能有奇遇，下一世同一段路可能风平浪静。

「事件预算」是为了给节奏定个地板和天花板：不会某一世空无一事，也不会事件轰炸。但预算内的一切都是浮动的。

### §5.2 战斗事件卡难度，叙事事件卡年份

抽中的事件按性质分两种放法：

- **战斗相关事件**（会改敌人强度那种）：落进一个**和它难度匹配的进度带**里（比如「图 3 到图 4 之间」），而不是钉死在某一关。难度可控，但具体落点在带内浮动。
- **叙事 / 奇遇 / 氛围事件**（不影响战斗难度）：锚在**江湖历年份**或随机窗口上。因为江湖历每一世都往后走，这类事件天然每世不同。

再加一条兜底：**同一个事件近期已经见过，就降低它的出现权重**，避免连着两世撞上同一个。

一个诚实的边界：事件的丰富程度，取决于我们往池子里写了多少事件、世界状态有多少种变化。早期池子浅，变化有限；但架构上已经没有「固定节奏」了，往后是持续往池子里堆内容的事。这些内容（纪元变迁、江湖兴衰、朝廷更替、时代 buff）不是可有可无的装饰，而是这套事件系统的**新鲜度燃料**。

## §7 内容 authoring 待办

这些是本系统跑起来后要持续填充的内容，不在本轮设计范围，但架构已为它们留好接口：

- **纪元事件池**：各纪元的世内事件（战斗 / 叙事两类）。
- **纪元变迁规则**：跨世的因果——比如上一世你灭了某门派，下一世它就从地图消失。
- **正义值 / 杀戮值的事件来源表**：哪些行为加正义值、哪些加杀戮值。
- **朝廷 / 庙堂**：随纪元更替的当权势力。
- **时代 buff**：不同年代的流派加成（如「剑法大兴」年代用剑加成）。
- **江湖兴衰史**：门派兴衰、塞外势力起落等自动演化——也是版本更新在游戏世界内的写照。

## §8 开放问题

- **主动闭关**：一种「主动加速积累、但快速消耗寿元」的高风险玩法（区别于离线挂机的「闭关」）。目前游戏没有这个系统，留待日后，不进本轮。
- **战死加码**：现在强制转世不论老死战死都是同一档「魂魄未稳」。等日后真做了「武学感悟传承」系统，再考虑要不要给战死额外加码（比如损失部分传承）。钩子已留，暂不实现。
- **魂魄未稳的终止条件**：现定「到首次突破为止」。若 sim 或实测发现首个境界太短、罚不出感觉，可改为固定年数；两者择一，不叠加。
- **双修完满的具体形态**：双修成就的解锁条件与奖励，待细化。
