## 1. 导读：用一场战斗讲清楚

### 1.1 一句话总览

门派、内功、主动武学不是三个并列系统，而是**一条新战斗资源轴的三个角色**：

- **内功 = 引擎**：决定这条资源轴（真气）有多大、回得多快、附带什么特效，装配唯一 1 门，是 build 的主心骨；
- **主动武学 = 消耗端**：装配若干门武学，每回合花真气抽一门打出，星级定天赋、熟练度定养成；
- **门派 = 供给端**：不是前期唯一渠道，而是中后期的主要渠道，同时是跨轮长线目标。

门径（华山剑意 / 少林金钟 / 唐门毒功）**不变**，仍是打法根基，不占武学槽位。

### 1.2 具体走一遍：一场战斗怎么打

假设玩家修习「剑法门径 · 惊雷」，内功选了「基础吐纳」（真气上限 100，每回合回气 15），装配了 3 门主动武学：

| 武学 | 真气消耗 | 基础权重 | 熟练度加成 |
|---|---|---|---|
| 破浪斩 | 25 | 40 | 初窥 |
| 惊鸿式 | 45 | 25 | 纯熟（权重 +10） |
| 龙渊斩 | 70 | 15 | 初窥 |

每回合玩家行动的判定：

1. 判定是否出招（总触发率，例如 60%）；
2. 若出招，在**真气够用的已装配武学**里按权重抽一门（惊鸿式因熟练度更高，被抽中概率相对更大）；
3. 抽中即扣真气、打出该武学，**本回合不再普攻**；
4. 若判定不出招，或真气不够任何一门，则**普攻**，普攻回真气 +15。

**关键补丁**：华山门径的"剑意"计数（暴击 +1 层、满 5 层自动爆发剑招）在武学命中触发暴击时**同样累积**——武学是门径机制的燃料，不是它的竞争对手。如果只靠普攻攒剑意，装武学反而会拖慢核心机制，这是必须堵死的坑（详见 §5.3）。

**保底**：龙渊斩权重最低，如果连续 6 回合真气够却没被抽中，其权重会逐回合递增，抽中后重置——防止"整场一次没放"的最坏情况。

**内功和武学的相容性**：如果龙渊斩带「疾」标签，装配的内功若也带「疾」标签，龙渊斩的抽取权重再 +5pp——这是"共鸣"，不是硬性搭配（§6.2）。

### 1.3 跨阶段看：池子和槽位怎么长大

装配槽位**必须**跟着武学池规模走，池子不够大时开槽位=装满即止，策略消失：

| 阶段 | 武学池规模 | 装配上限 | 主要新增供给渠道 |
|---|---|---|---|
| P1 框架验证 | 6–8 门 | 3 | Boss 首杀、声望商店、挑战试炼 |
| P2 内功开放 | 6–8 门（不变） | 3 | 同上 + 内功试炼 |
| P3 门派上线 | 15–20 门 | 5–6 | + 门派贡献商店、门派任务、独占机制武学 |
| 完整版 | 30+ 门 | 10 | 秘境探索、比武大会 `[占位]` |

### 1.4 名词对照表

| 名词 | 人话解释 |
|---|---|
| 真气 | 战斗内新增的资源轴，每场战斗独立，与"内力/丹田"（修炼货币，突破用）是两回事，严禁混用 |
| 内功 | 真气引擎：定真气上限、每回合回气、一条特殊效果；装配唯一 1 门（P4 起 +1 辅修） |
| 主动武学 | 装配制、加权随机自动触发、替换普攻并消耗真气的招式；星级定天赋、熟练度定养成 |
| 被动武学 | 装配制、不吃真气、只加固定属性（命中/闪避/暴率/暴伤/攻/防/血）的贴片 |
| 门径 | 不变，仍是战斗核心机制载体，不占武学槽，武学触发对门径计数同样生效 |
| 门派 | 每轮拜入的江湖组织归属，不限门径、不被门径限制；独占机制武学 + 贡献商店 + 任务线 |
| 共鸣 | 内功与主动武学的 tag 匹配加成，挂在触发权重上，不挂伤害倍率 |
| 拜山预告 | 门派正式解锁前的叙事提前量：NPC 出现、门派名可见，功能未开放 |

以上具体数字均为示例占位，真正产表定稿见规格化批次；**结构关系**（真气轴/内功/主动武学/被动武学/门派怎么互相咬合）是本文确认的口径。下面各节是这套结构的精确定义与规格化用检查清单。

## 3. 核心循环

### 3.1 单场战斗（真气轴）

```text
回合开始 → 判定是否出招（总触发率）
  → 触发：按权重（基础权重 × 熟练度加成 × 共鸣加成 × 保底加成）抽取一门已装配且真气够用的主动武学
    → 扣真气 → 打出武学 → 命中/暴击按门径计数规则同步累积
  → 不触发或真气不足：普攻 → 回真气 → 门径计数按普攻规则累积
回合结束 → 门径核心机制按既有规则结算（毒/反伤/护盾等，§7.2 mvp0 规则不变）
```

### 3.2 跨战斗（门派供给）

```text
拜山预告（Boss2 后，NPC 可见）
  → 门派正式解锁（P3：Boss3 或境界 4）→ 拜入（受地域 + 隐性声望门槛）
    → 入门内功（保底真气轴可用）
    → 门派任务 → 本轮门派贡献 → 贡献商店兑换武学/内功
    → 门派试炼首胜 → 独占机制武学
归隐 → 门派身份与本轮贡献重置；门派永久声望保留（复用初案既有货币，见 §8）
```

## 4. 概念定义

### 4.1 真气（战斗内资源轴）

- **与"内力"严格区分**：现有「内力」是战斗外修炼货币（丹田、突破用，`gameStore` 单钱包），**不新增其上限概念**；真气是战斗内独立资源，逐战斗重置，二者不共享数值、不共享 UI 位。这条区分本身就是回答"内功加内力上限没有意义"这个问题的落点——真正要加的不是内力上限，是真气上限。
- 真气**每场战斗清零**，开局值 = 内功「真气上限」的固定比例（满值或半值 `[占位]`），不跨战斗保留、不跨归隐保留。
- 落点对齐既有坑位：`game-design-proposal.md` §五「内功：资源倍率、恢复、护盾」与 §七基础属性表「内力恢复」一项，即为真气轴的既有伏笔，本文是其具体化。

### 4.2 内功（引擎）

| 项 | 规则 |
|---|---|
| 装配数 | 1 门主修（P4 起 +1 辅修，辅修只吃基础效果的 30% `[待测试]`，防乘区膨胀） |
| 基础效果 | 真气上限、每回合回气速率——两项都不直接加攻击/气血/防御，通过放大整套武学间接起效 |
| 特殊效果 | 攻击附带状态（寒冰减攻 / 流血回合真伤 / 破防减防 / 吸元回血 `[占位]`），**首发特效池须避让三门径核心机制**（附毒类特效与唐门核心重叠，若做则效果改写为"喂给唐门的毒层收益强化"，不做独立触发） |
| 成长 | 等级提升三件套数值，不改变触发方式（对齐 `mvp0/spec.md` §7.1「武学等级提升改变触发参数，不改变触发方式」的既有先例） |
| 归隐 | 见 §8 |

**"内力越深厚功夫越强"的机制化落点**：内功不直接加数值，而是通过真气上限（存得起高消耗招式）和回气速率（出招更频繁）间接放大主动武学的实际输出——同一套武学，内功浅的人偶尔打出、内功深的人连绵不绝。

### 4.3 被动武学（属性贴片）

与内功的分工，是本文对"内功和被动武学怎么区分"的直接回答：

| | 内功 | 被动武学 |
|---|---|---|
| 管什么 | 战斗资源轴引擎 + 全局特效 | 固定属性贴片 |
| 装配数 | 1（唯一，build 主心骨） | 多个，随境界扩槽 |
| 决策感 | 选哪一门（互斥，定义打法） | 装哪几张（组合，查漏补缺） |
| 属性范围 | 真气上限/回气/状态特效（新增） | 命中、闪避、暴击率、暴击伤害、攻击、防御、气血（`mvp0/spec.md` §7.2 既有 7 项白名单内），**不新增速度/身法轴**（§12 开放问题） |

### 4.4 主动武学（消耗端）

| 项 | 规则 |
|---|---|
| 触发模型 | 加权随机抽取（§5），非固定顺序，非玩家手动 |
| 星级 | 占位字段，首发不启用（继承 `wuxue-collection-direction-note.md` 星级推迟裁决），P4 开放；星级定机制复杂度而非线性强度——1★=单体倍率斩，5★=带条件增伤的多段招 |
| 熟练度 | 若干档（占位：初窥 / 纯熟 / 精通 / 圆满），提升触发权重与效果倍率，不改变触发方式 |
| 装配上限 | 随境界扩容，见 §1.3 表；上限必须 ≤ 池子规模的 1/2–1/3，防止"装满即止" |
| 获取渠道 | Boss/精英首杀、声望商店、挑战试炼、门派贡献商店（P3 起主渠道）、独占机制武学（门派专属）；秘境探索/比武大会为完整版敞口 `[占位]` |

### 4.5 门派（供给端）

- **拜入条件**：不受门径限制（铁律 1），受地域限制（对齐主线进度），可能叠加隐性声望门槛 `[占位]`；具体门派名单、数量、恩怨史**本文不设定**（`worldview.md` §9 留白条款覆盖，留待门派系统规格化批次一并揭示，命名沿用初案 §六 IP 风险标注）。
- **拜山预告**：门派正式功能解锁前，以叙事形式提前量出现——NPC 可见、门派名可见、显示解锁前置条件；不开放任何功能。解决"门派后移后前期玩家怎么知道有门派"的预期管理问题，成本仅一处地图/NPC 呈现。
- **入门内功**：拜入即得，保证真气轴人人可用，不与其他内功互斥（可后续替换）。
- **独占机制武学**：沿用 `game-design-proposal.md` §六既有术语（不用"招牌武学"另造新词）——每个门派至少一门改变战斗方式的独占武学，是"机制是轮换的理由"的既有约定，机制本身对任何门径开放，不与门径绑定（铁律 1/2）。
- **门派任务与两级货币**：**复用初案归隐总表既有的两行货币**，不新增资源类目——「本轮门派贡献」（任务/试炼产出，兑换本轮武学/内功名额，归隐重置）与「门派永久声望」（`game-design-proposal.md` §四总表既有行，跨轮保留，兑换永久性内容）；银两可作贡献兑换的补充输入（对齐 §二资源源汇表银两 sink 既有条目「门派捐献换贡献」）。

## 5. 战斗触发模型

### 5.1 回合行动判定（锁定加权随机，非排序优先级）

固定排序会退化为"唯一最优解可解题"，抄一次作业就死；加权随机把装配从"排序题"变成"组牌库"，玩家的控制力在**组库**，随机性在**出牌**，与"战斗外决策、战斗内自动"的既有支柱（`mvp0/spec.md` §7.1）分工一致。

```text
权重(武学) = 基础权重 × 熟练度加成 × 共鸣加成（§6.2）× 保底加成（§5.2）
```

### 5.2 保底（pity）

某门已装配、真气足够但连续 N 回合未被抽中，其权重逐回合递增，一旦被抽中即重置。目的：保留单场方差（欧皇/非酋场都在），但封住"整场一次没放"的最坏情况——放置游戏里玩家不能操作，无法归因的失败是差评首因，保底把方差的下界钉住。

### 5.3 替换普攻 + 回气，与门径机制的协同补丁（防劣化）

- 主动武学触发时**替换本回合普攻**，不额外行动（额外行动会打穿回合上限、需要重调全部敌人数值，不做）。
- 普攻回真气（数值占位），构成"攒气 → 放招 → 攒气"的战斗节拍，让自动回放有可读的节奏。
- **强制补丁**：三门径核心机制的计数触发（华山暴击攒剑意 / 唐门命中攒毒层）**对主动武学的暴击/命中同样生效**。不打这个补丁，唐门（普攻系数仅 0.60）会因替换普攻纯赚，而华山（靠普攻暴击攒剑意）会因普攻次数减少而核心机制熄火——即系统性劣化剑法门径。此补丁是本文对"主动武学装配数量提升"最需要提前处理的交互，必须随 P1 一起实现，不得后置。

### 5.4 可读性要求（装配上限提升到 10 的配套）

装配槽扩到 5–10 门后，战斗回放的技能触发若不做统计呈现会变成刷屏噪音。P1 起战斗结算须提供**武学触发统计**（每门触发次数 / 伤害占比），供失败诊断（`combat.ts` `diagnose()`）引用；否则装 10 门等于看不懂 10 门。

## 6. 相容性与共鸣

三层耦合关系分开处理，全部禁止硬门槛，只允许有封顶的软加成：

### 6.1 门径 × 武学（沿用既有封顶，本文不新增）

`worldview.md` §6 已锁定：与门径相配的武学有搭配加成，**幅度封顶为「不超过一档武学品质差、不超过一次克制适配的收益」**——配得上是优势，配不上不是残废。本文不改这条规则，只补一点：主动武学的星级/机制复杂度（§4.4）与该封顶是同一把尺子，规格化时一并产表。

### 6.2 内功 × 主动武学（本文新增：tag 共鸣）

- 武学与内功按主题打 tag（占位候选：寒 / 血 / 刚 / 疾…）；装配同 tag 内功时，该武学**触发权重 +5pp `[待测试]`**——加权重而非加伤害倍率，天然不占用乘区预算（§7.1）。
- 收益封顶控制在 10–15% 效果差以内：有共鸣的 build 更顺手，无共鸣的 build 完全可玩，超过这个幅度就退化成变相硬绑定。

### 6.3 门派 × 门径（零数值大项耦合，允许小甜头）

`worldview.md` §5 铁律 2 原文：「本门弟子修本门武学的加成只是小甜头，小到不改变拜哪个门的决策」——本文继承此界定，不做成零耦合（会与既有铁律的"小甜头"表述冲突），而是**明确"小甜头"的封顶必须小于 §6.1/§6.2 任一项**，确保门派选择的决策权重仍然由资源/职位/独占武学等门径无关因素主导。命名侧铁律不变：门派命名不得与门径 id（华山/少林/唐门）产生"唯一最优门派"的暗示（`worldview.md` §7.1 词库不重叠规则同理延伸到本文新增门派名单，规格化时核对）。

## 7. 数值归属与预算

### 7.1 乘区合规

```text
最终量 = 基础值 × (1 + 永久加成总和) × (1 + 本轮临时加成总和)
```

- 内功**不直接进乘区**：真气上限/回气速率不是攻防血命中闪避暴击暴伤 7 项白名单内的量，通过放大主动武学的"出招频率/可承受消耗"间接起效，不占用乘区预算，不需要判断归属哪一区。
- 被动武学固定属性**必须写明**归入永久乘区还是本轮临时乘区（对齐武学 perLevel 现行模式：随境界/装配变化的部分进本轮临时区，跨轮保留的部分——如门派永久声望兑换的被动——进永久区），禁止为"装配感"新开第三乘区。
- 触发权重（保底、共鸣）**不是乘区**，不进属性最终量公式，不占预算表，但需在规格化时单独校验："随机预算 + 触发权重叠加"是否会稀释失败诊断的可归因性（沿用 `wuxue-collection-direction-note.md` §5 第 3 条既有检查项）。

### 7.2 属性/状态白名单重开

真气轴与内功特殊效果需要显式重开 `mvp0/spec.md` §7.2 的 7 项属性 + 6 种状态清单（当前"禁止新增"是 MVP-0/1/2 范围锁，完整版立项时按新清单重产表，不沿用旧数字）：

- 新增资源轴：真气（战斗内，逐场重置，非新属性，走独立结算通道）；
- 新增状态效果候选（占位，需规格化批次逐条过检查）：寒冰（减攻）、流血（回合末真伤）、破防（减防）、吸元（回血）——需与既有 6 种状态（护盾/反伤/毒/净化/破甲/狂暴）做重叠检查，避免行为重复。

### 7.3 门派贡献三列账

按 `game-design-proposal.md` §二纪律，新增经济条目须补全来源/主消耗/后期 sink：

| 资源 | 来源 | 主消耗 | 后期 sink |
|---|---|---|---|
| 本轮门派贡献 | 门派任务、门派试炼首胜 | 兑换武学/内功名额 | 高熟练度突破材料、重复兑换消耗品 `[占位]` |
| 门派永久声望 | 复用初案 §四既有行（归隐结算） | 复用既有声望天赋消耗 | 不新增，沿用既有 sink |

## 11. 规格化前置检查（完整版立项时逐项过）

1. **通用四项**（沿用 `wuxue-collection-direction-note.md` §5 与量级边界文档口径）：加成域归属、乘区是否超 2、资源三列账（真气/门派贡献均需过）、门槛 Boss 守则与 ≤5 分钟节拍红线。
2. **属性/状态白名单重开清单**（§7.2）：真气资源轴与新增状态效果逐条过检查，与既有 6 种状态做重叠核对，不沿用 MVP-0 的 7+6 数字。
3. **D3 补丁验证**（§5.3）：华山/唐门门径核心机制在装配主动武学后的期望触发频率不得低于无装配基线，需 sim 验算（对齐 `mvp0/sim/mvp0_sim.py` golden 对照方法论）。
4. **保底 + 共鸣叠加的随机预算**：验证叠加后失败诊断仍可归因（`wuxue-collection-direction-note.md` §5 第 3 条既有检查项的复用）。
5. **门派贡献经济平衡**：贡献产出速率 vs 兑换成本，防止「无出口」或「速通清空」两极。
6. **内容成本红线核验**（`game-design-proposal.md` §五）：P4 星级 × 门派数 × 武学池的内容矩阵总量评估，防重蹈"全矩阵成本极高"覆辙。
7. **归隐保留/重置逐行核对**（§8）：确认未新增货币类目，全部条目能对应到初案总表既有行或明确标注为该行的展开。
8. **命名与文案红线核对**：门派命名避开门径 id 撞名（`worldview.md` §7.1 词库不重叠规则延伸）；具体门派名单/数量按 §9 留白条款留待专项批次。
