## 1. 导读：三个概念、五种资源

### 1.1 一句话

**内功是根基，武学是招式，门派是靠山。**原来的「武学门径」并入内功，成为内功的「路数」。

| 概念 | 回答什么 | 玩家做什么 | 吃什么 |
|---|---|---|---|
| **内功** | 我是什么路数、根基多厚 | 选一部内功主修，灌注内力升「重」，到台阶处顿悟质变 | 内力 |
| **武学** | 我用什么招 | 收集秘籍，装几门武学上阵，越用越熟 | 秘籍（解锁）、实战（熟练） |
| **门派** | 我靠着谁 | 每一世拜入一派，做门派任务攒贡献，换本派绝学 | 门派贡献 |

### 1.2 资源各有一个去处

| 资源 | 去处 |
|---|---|
| 内力 | 周天与突破（约八成）、内功重数（约两成，接替原门径武学的份额） |
| 实战 | 武学招式的熟练度（只看出招次数） |
| 秘籍 | 武学后续招式、高品质内功后几个台阶的解锁资格 |
| 银两 | 书肆买秘籍、散功重修的手续费 |
| 门派贡献 | 本派贡献商店换秘籍 |
| 阅历 | **本版冻结**（§7.3），留给以后「提升悟性」的途径 |

### 1.3 走一场战斗

玩家主修「惊雷」路数的一部上乘内功，第 30 重，战斗真气上限 120；装了三门武学：

| 武学 | 耗气 | 冷却 | 已领悟招式 |
|---|---|---|---|
| 某剑法（寻常，3 式） | 20 | 2 回合 | 3 / 3 |
| 某掌法（上乘，5 式） | 45 | 3 回合 | 2 / 5 |
| 某暗器（上乘，5 式） | 35 | 3 回合 | 3 / 5 |

每回合轮到玩家时：先看哪些武学**冷却已好且真气够**；有候选就按触发率判定出不出招，出招则按权重抽一门，从它**已领悟的招式里随机出一式**，扣真气、进冷却，这一式熟练 +1；没候选或没触发就普攻，普攻回气。惊雷的核心机制（暴击攒剑意、满层自动爆发）对普攻和武学的暴击**一视同仁**。

这门掌法的第 3 式还没领悟：要境界够、真气上限够、手里有第 3 式的招式秘籍，而且第 2 式熟练到阈值——都满足后，每次出招都会判一次「顿悟」，悟性越高越快。

## 2. 定位与取代关系

- 本文是门派 / 内功 / 武学主题的**唯一权威设定**，取代 v1.0（真气轴 + 被动武学 + 门径独立并存），v1.0 各裁决去向见 §11.2。
- **门径并入内功**：三门径（惊雷 / 镇岳 / 蚀骨）改为内功的三个**路数**；门径武学（招式 10 级 + 火候，`../../rules/formulas.md` §3.4）由内功重数接替；参悟节点改为内功台阶的质变。世界观铁律 3 随之改写为「内功路数是战斗核心机制的载体」（`worldview.md` §5）。
- **与周天分立**：周天是行功（冲穴、贯通经脉、缴突破），内功是所修的功。两者本版不联动。周天侧原称「所需真气」的内力消耗改称「所需内力」，「真气」一词专指战斗内的气条（裁决 3）。
- **与不灭功法分立**：转世系统里的「上古不灭功法」是转世的叙事装置（`../reincarnation/design.md` §0），不是可装配的内功，不进本文任何表。
- **被动武学取消**：属性成长由内功承担，不再设装配式属性贴片。

## 3. 内功

### 3.1 路数

路数决定**战斗核心机制**，是原门径的直接继承：

| 路数 | 核心机制（沿用 `../../rules/content.md` §3） | 源出门派 |
|---|---|---|
| 惊雷（爆发） | 暴击攒剑意，满层自动爆发 | 华山 |
| 镇岳（护体） | 开场护盾 + 受击反伤 | 少林 |
| 蚀骨（阴毒） | 命中叠毒，满层毒爆 | 唐门 |

- 境界 2 在三部**入门内功**（寻常品质，各一路数）中三选一，时机与原门径选择相同。入门内功由隐世前辈传授（`worldview.md` §8）。
- 同一路数下有不同品质的内功，品质越高，机制越强或多一层变化，**机制本身不换**。
- 路数以后可以扩充，本版只有三路。

### 3.2 品质

四档，内功与武学共用：**寻常 / 上乘 / 绝学 / 神功**（名称 `[占位]`，进文案冻结批次定稿）。

品质影响：每重的属性效率与真气增量、台阶的机制强度、顿悟的难度（§5）。**品质带来的战力差封顶为「一档品质差」**，与 `worldview.md` §6 的搭配加成封顶是同一把尺。

### 3.3 重数（内力灌注）

- 内力换「第 N 重」，价格与效果都按等比走，沿用火候的对数曲线：第 N 重的内力价 = 基价 × 公比^(N−1)，每重加气血 / 攻击 / 防御与真气上限 `[待 sim]`。
- 上限不绑境界，只受内力约束。
- 这一条接住战力预算（§8.1）：**敌人与关卡不用重调**。

### 3.4 台阶（顿悟质变）

每若干重是一个台阶：**入门 → 登堂 → 入室 → 大成**（名称 `[占位]`）。跨台阶是**机制质变**，原门径的三重参悟挪到这里，例如惊雷登堂时剑意需求 5 → 4。

跨台阶的条件：

1. 重数到达本台阶的上限（硬性）；
2. 境界到达门槛（硬性）；
3. 绝学 / 神功的后几个台阶：持有对应的**秘籍卷册**（硬性）；
4. 以上都满足后，挂机修炼时按悟性判定**顿悟**（§5），顿悟即跨阶。

卡在台阶上时，重数不再上涨，溢出的内力照常留在丹田，不浪费。

### 3.5 真气（战斗内气条）

- 真气是战斗内的气条，每场开打时给一部分（比例 `[待 sim]`），打完清零，不跨战斗保留。
- **真气上限 = f(境界, 内功品质, 内功重数)**（裁决 3）。
- 普攻回真气；武学出招扣真气。
- 真气与内力严格分开：不共享数值，不共享 UI 位。

### 3.6 散功重修（换内功）

| 情形 | 新内功的起点 |
|---|---|
| 同路数（如寻常惊雷 → 上乘惊雷） | 旧重数的一定比例 `[待 sim]` |
| 跨路数 | 从第 1 重开始 |

- 两种情形都不带走已过的台阶，也都要付一笔银两手续费。
- 动词用「转修」：同路数叫「转修」，跨路数叫「散功重修」（文案冻结批次定稿）。

## 4. 武学

### 4.1 招式

- 一门武学由若干**招式**组成，招式数随品质走：寻常约 3 式，上乘约 5 式，绝学约 7 式，神功约 9 式 `[待 spec]`。个别神功可以覆写（如十八式），不作常规。
- 每一式有自己的威力与特效，随熟练度加强。

### 4.2 熟练度

- **只看出招次数**：这一式每打出一次，熟练 +1，攒到阈值就升一档：**生疏 → 熟练 → 精通 → 入化**（名称 `[占位]`）。
- 每升一档，这一式的威力或特效加强一分。
- 品质越高，阈值越高 `[待 sim]`。

### 4.3 招式领悟

后续招式的领悟条件，**全部满足后按悟性顿悟**：

1. 境界到达该式门槛；
2. 真气上限 ≥ 该式门槛；
3. 持有该式的**招式秘籍**（高品质武学一次只给前几式，后几式另行获得）；
4. 前一式熟练到阈值；
5. 满足后，这门武学每出一次招判一次顿悟（§5）。

### 4.4 装配

- **装配槽跟境界走**：境界 2 约 2 槽，逐境界递增 `[待 sim]`。
- 槽位数不超过武学池规模的一半，避免「有啥装啥」（继承 v1.0 D1 的纪律）。
- 装配与卸下没有成本。

### 4.5 触发（冷却 → 真气 → 随机）

```text
玩家每回合行动：
  候选 = 已装配 ∧ 冷却已好 ∧ 当前真气 ≥ 该武学耗气
  候选非空 ∧ 通过触发率判定：
      按权重从候选中抽一门武学
      → 从它已领悟的招式中随机出一式
      → 扣真气，该武学进冷却，这一式熟练 +1，本回合不普攻
  否则：普攻，回真气
```

- 权重 = 基础权重 × 共鸣加成（§4.6）。冷却保证每门武学都会出手，**不设保底**。
- 冷却、耗气挂在**武学**上，不挂在招式上。
- **门径机制不劣化（硬约束，继承 v1.0 §5.3）**：路数核心机制的计数，对武学的命中与暴击同样生效（惊雷暴击攒剑意、蚀骨命中叠毒）。否则装武学会减少普攻次数，惊雷的机制反而熄火。须由 sim 验证：装满武学后，三路数核心机制的触发频率不低于只普攻的基线。
- 出招替换普攻，不额外行动，回合上限与敌人数值不变。

### 4.6 与路数的共鸣

武学带路数标签；与所修内功同路数时，得一个小加成（耗气降低或触发权重提高，二选一 `[待 spec]`）。**封顶**：不超过一档品质差（`worldview.md` §6）。配得上是优势，配不上不是残废。

### 4.7 可读性

装上多门武学后，战斗结算须给**武学触发统计**（每门武学出招次数、伤害占比），失败诊断引用它；否则装五门就等于看不懂五门（继承 v1.0 §5.4）。

## 5. 悟性与顿悟

- **悟性**：领悟的快慢。内功跨台阶、武学领悟新招式，硬性条件都满足后，按悟性判定是否顿悟。与转世的「宿慧」分清：宿慧加快攒内力，悟性加快领悟。
- **本版来源**：转世时随机生成，一世内不变。随机范围收窄并设下限（例如基准的 ±20% `[待 sim]`），避免一世全程卡在领悟上。提升悟性的途径以后再加（候选：阅历参悟，见 §7.3）。
- **顿悟判定**：
  - 内功：挂机修炼每满一段时间判一次；
  - 武学：该武学每出一次招判一次。
  - 顿悟概率 = f(悟性, 品质)，品质越高越低；**失败没有代价**。
- **期望等待时长**是 sim 的标定目标：标准悟性下，寻常品质几乎即时，神功要一两天量级 `[待 sim]`。

## 6. 门派

### 6.1 名单

本版三派：**华山、少林、唐门**，分别是惊雷、镇岳、蚀骨三路数的源流（`worldview.md` §8 的揭示在此落地）。门派恩怨史仍然留白。

### 6.2 拜入

- **境界 3（约第 7 天）开放拜入**；境界 2 起出现**拜山预告**：门派名与拜入条件可见，功能不开。
- **拜入不受路数限制**（铁律 1）：修惊雷的人拜入少林很正常（铁律 4，带艺投师）。
- 每一世重新拜入，一世只拜一派；叛出与改投规则 `[待 spec]`。
- 本门弟子修本门武学的加成只是小甜头，封顶小于共鸣（铁律 2）。

### 6.3 门派任务

- 挂机派遣式：接一个任务，经过一段挂机时长后结算贡献，离线同样计时。
- 任务的具体形态、时长与产出 `[待 spec]`。

### 6.4 贡献商店

- 用门派贡献兑换本派的**绝学秘籍**（内功卷册、武学招式秘籍），以及部分上乘秘籍。
- 每派至少一部绝学内功（本派路数）和两三门绝学武学，其中至少一门是**独门机制武学**（改变战斗方式，对任何路数开放）。
- 贡献每世清零，兑换得的秘籍按 §9 跨世保留。

## 7. 秘籍与资源

### 7.1 秘籍

秘籍是「会什么」的凭证，分三种：**武学秘籍**（得到一门武学及其前几式）、**招式秘籍**（后续某一式的领悟资格）、**内功卷册**（高品质内功后几个台阶的资格）。

### 7.2 渠道按品质分层

| 品质 | 主要渠道 |
|---|---|
| 寻常 | 书肆（银两）；入门内功直接给 |
| 上乘 | 精英 / Boss 首杀掉落；书肆偶有 |
| 绝学 | 门派贡献商店（各派独门） |
| 神功 | 本版不投放（或只在最高难度 Boss 上，`[待 spec]`） |

秘籍阁（真传残页，`../../rules/manual-fragments.md`）的解冻并入本渠道设计，spec 时统一裁。

### 7.3 阅历冻结

阅历的唯一用途（门径参悟节点）随门径并入内功而消失。本版**冻结**：存档字段保留，关卡与离线停止产出，界面隐藏。以后做「阅历参悟提升悟性」时再启用。换路线「阅历全额返还」的规则随之作废。

### 7.4 银两

银两的去处：书肆买秘籍、转修手续费。长线里银两随关卡当量指数上涨（BACKLOG「银两与阅历的长线定位」），书肆定价须按长线量级重做 `[待 sim]`。

## 8. 战力预算

### 8.1 内功接替门径武学

内功重数完整继承 `../pacing/design.md` §3.7 的三条：一世约两成内力、一个平台期内战力涨幅不超过一个境界、增长约与累计内力的对数成正比。**敌人仍按「境界 + 内功重数」标定**，关卡不用重调。

### 8.2 武学是曲线之上的余量

- 武学不吃内力，是余量，用来挑战更高难度（`../pacing/design.md` 裁决 5）。
- **余量须设上限**：标准配置下，武学带来的战力增量不超过高一档难度的当量差，否则高一档难度会被提前打穿 `[待 sim]`。
- 品质、熟练度、共鸣三者叠加，也要落在这个上限内。

### 8.3 乘区

- 内功重数的属性加成并入现有的本世临时乘区（与原门径武学同位），不开新乘区。
- 真气、冷却、触发权重不是属性，不进乘区。

## 9. 转世保留与重置

| 项 | 转世处理 |
|---|---|
| 收藏过的秘籍（武学 / 招式 / 卷册） | **保留** |
| 内功重数、已过台阶 | 重置 |
| 已领悟的招式 | 重置（凭保留的秘籍重新领悟） |
| 武学熟练度 | **按比例带入下一世** `[待 sim]` |
| 装配、所修内功 | 重置，下一世在境界 2 重新选 |
| 门派身份、门派贡献、任务进度 | 重置 |
| 悟性 | 重新随机 |
