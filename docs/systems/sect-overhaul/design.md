## §0 解决什么问题

现行门派还是旧九派（华山、少林、唐门……），只是临时挂在卷二到卷四，和舆图上的势力对不上；每派只有一两门绝学，差事只有「短差 / 长差」，货架只卖武学与内功。武道源流扩成七路后，新四路的内功也要靠门派给出来路。

## §1 已定口径（用户 2026-10-26、10-27）

- 舆图开局 28 家里，世家（会稽顾氏、建安岑氏、江陵裴氏、雁门秦氏）、官军（镇关军）、蒿里寨、夜阑风雨楼不可拜，其余 **21 家可拜**；帮会的拜入叫「入伙」。
- 碧磷洞是蚀骨的源流门派，隐世，凭因缘才拜得（`../wudao-yuanliu/design.md` §3）；千岩寺是镇岳源流，入世照常可拜。
- 建安岑氏的牵机引魂镖、千丝万缕针改归花影坊；雁门秦氏的霸王卸甲枪改归苍梧派。
- **绝学看体量**，小门小户可以没有；**每家都配内功**，按体量分入门、进阶、镇派递进；有绝学内功的门派一定有绝学武学，反之不必。
- **门派地位**一级级升，升级解锁门内武学、内功、装备的兑换资格。
- 每家武学至多三类，主修一到两类。

## §2 取舍原则

1. **七路在卷四之前都拜得到**：开局传功只给狂澜、镇岳、蚀骨三路，新四路要靠门派，所以卷二到卷四的七家要把七路配齐。
2. **同源流、同品质的内功数值相同**：各家内功只在名字与气质上区分，七路对拍的平衡结论不被门派打散（`../wudao-yuanliu/spec.md` §3）。
2a. **核心源流**：每家有一路核心源流，镇派内功（大派）或最高一档内功必是这一路。个别大派可兼修，门内内功至多涉及三路（用户 2026-10-27 定），兼修的只出入门或进阶档（§3.1）。
3. **一路三家**：21 家平分七路，每路三家，前中后期各有一家可拜。
4. **体量随格局档位**：二宗、三教、七绝是大派；五秀、六隐与八奇里有绝学的是中派；其余是小门小户。

**源流取舍的理由**（一句一家）：苍崖、虎啸、风雷都是刚猛爆发的路子，归狂澜；千岩寺、擎天门是守中带攻，北邙门掘墓镇阴、功夫厚重，归镇岳；千蛇窟、瘴月教、碧磷洞是毒门，归蚀骨；蜃海教的幻术、乾元观的道家柔功、幽篁宫竹影无定，归太虚；花影坊惑人、水月庵封脉指、阴山派指绝，归玄寂；凌风山庄轻功、天工坊机关暗器手快、苍梧派的连环枪，归惊鸿；千帆帮、横江会是水上讨生活的狠角色，鸣沙教烈日熔金，归焚血。

## §4 地位与兑换

- **四级地位**，称谓按门派性质起（§3 表最后一列）；帮会、教门、佛道各有一套。
- **兑换资格**：

| 地位 | 解锁兑换 |
|---|---|
| 一级（入门即得） | 寻常武学、入门内功 |
| 二级 | 上乘武学残页、本门装备（低档） |
| 三级 | 进阶内功、绝学武学残页 |
| 四级 | 镇派内功、本门装备（高档） |

- **怎么升级**（用户 2026-10-27 定）：按本世**累计**得到的贡献升，兑换花掉的贡献不降级；各级门槛待 sim，按一世能攒多少倒推。
- **转世后**：地位默认清零，下一世重新从一级做起；买了前尘「认祖归宗」的，开局拜回上一世门派并保留二级地位（用户 2026-10-27 定：保留一级，即比入门高一级）。
- **门派装备**：每家一两件，按本门擅长的兵器与气质起名；品质高于同段地图掉落（具体高多少待 sim，装备定位见 `../battle-loot/design.md` 裁决 49）。

## §5 差事

现行「短差 2 小时 / 长差 8 小时」两档的时长与贡献不变，只把差事名按门派写（如千帆帮「押漕船过闸」、千岩寺「后山担水」、天工坊「校验机括」），每家两件。

## §7 开放问题

- **兼修门派**：§3.1 的四家是否合适。
- **蜃海教的绝学**：大派有镇派内功，按规则须有绝学武学，从名录第二批补一门（掌或暗器）。幽篁宫、碧磷洞两个中派没有绝学，已认可。
- **起名**：每家一两件门派装备、每家两件差事，另批起名送审（内功已定，§3.2）。
- **正邪**：留到第三期，本批拜入邪派不受限制。
