## §0 解决什么问题

现行门派还是旧九派（华山、少林、唐门……），只是临时挂在卷二到卷四，和舆图上的势力对不上；每派只有一两门绝学，差事只有「短差 / 长差」，货架只卖武学与内功。武道源流扩成七路后，新四路的内功也要靠门派给出来路。

## §1 已定口径（用户 2026-10-26、10-27）

- 舆图开局 28 家里，世家（会稽顾氏、建安岑氏、江陵裴氏、雁门秦氏）、官军（镇关军）、蒿里寨、夜阑风雨楼不可拜，其余 **21 家可拜**；帮会的拜入叫「入伙」。
- 碧磷洞是蚀骨的源流门派，隐世，凭因缘才拜得（`../wudao-yuanliu/design.md` §3）；千岩寺是镇岳源流，入世照常可拜。
- 建安岑氏的牵机引魂镖、千丝万缕针改归花影坊；雁门秦氏的霸王卸甲枪改归苍梧派。
- **绝学看体量**，小门小户可以没有；**每家都配内功**，按体量分入门、进阶、镇派递进；有绝学内功的门派一定有绝学武学，反之不必。
- **门派地位**一级级升，升级解锁门内武学、内功、装备的兑换资格。
- 每家武学至多三类，主修一到两类。

## §2 取舍原则

1. **七路在卷四之前都拜得到**：开局传功只给狂澜、镇岳、蚀骨三路，新四路要靠门派，所以卷二到卷四的七家要把七路配齐。
2. **同源流、同品质的内功数值相同**：各家内功只在名字与气质上区分，七路对拍的平衡结论不被门派打散（`../wudao-yuanliu/spec.md` §3）。
2a. **核心源流**：每家有一路核心源流，镇派内功（大派）或最高一档内功必是这一路。个别大派可兼修，门内内功至多涉及三路（用户 2026-10-27 定），兼修的只出入门或进阶档（§3.1）。
3. **一路三家**：21 家平分七路，每路三家，前中后期各有一家可拜。
4. **体量随格局档位**：二宗、三教、七绝是大派；五秀、六隐与八奇里有绝学的是中派；其余是小门小户。

## §4 地位与兑换

- **六级地位**（用户 2026-10-28 定）：前四级是弟子、门众一层，五、六级到护法、堂主、长老一层；称谓按门派性质分套（§3 表最后一列）。窟、洞、门三家第一级直接是弟子，往上顶到太上长老。

## §5 差事

用户 2026-10-28 定：差事按地位分六档，升一级多解锁一档，低档仍可派；档位越高，贡献效率越高，且拉开差距（每级约 ×1.6，六级是一级的十倍）。

- 每家每档一件差事，共 126 件，名字一律四字（用户 2026-10-28 定，见下表）。
- 时长不绑在差事上：派差时选 2 小时或 8 小时，8 小时的每小时贡献打七五折（沿用现行短差、长差的比例）。同一时间只跑一件。

## §7 门派页（原型定稿，用户 2026-10-28）

原型：`../../design/sect-overhaul-prototype.html`，场景型页面，照修炼页、战斗页的做法：一整幅水墨夜景即界面，文字题在画上，主按钮用卷轴。

- **驻地图**：每家一张本门驻地的俯瞰水墨图（苍崖派样张 `code/public/art/sect/cangya-map.jpg`），像战斗页的分图。三座建筑是入口，建筑旁一块竖排名牌、牌下一团柔光，点建筑或名牌进内景：
  - **百务殿**：领差事；
  - **典籍院**：兑换武学与内功；
  - **天工库**：兑换本门装备，二级地位解锁，解锁前不显示、解锁时带金点。
  - 左上只写一行「地位称谓 · 贡献 n」，画里不画任何地位层级。
- **百务殿**：殿内墙上六块挂牌即六档差事，已解锁的点亮、竖写差事名，可点选；未解锁的空白不亮。右侧是差事卷宗：差事名、〔地位 · 差事〕、一句交代、两档时长（**一个时辰 / 四个时辰**，一时辰按 2 小时算，对应 §5 的 2 / 8 小时）各带「赏 n 贡献」、卷轴按钮「领牌派出」。派出后案上那炷香计时，剩余按时辰、刻写；按钮换成暗底线框的「召回」。同一时间只跑一件，其余挂牌压暗。
- **典籍院 / 天工库**：左侧底图只作氛围，不交互。右侧上面是货架（只列已解锁条目，选中行铺暗金底），中间一条菱纹暗金分割线，下面是选中物的卷宗：名字（按品质着色）、〔品阶 · 类别〕、一句来历、属性（引擎真值）、卷轴按钮「兑换」。价格只在货架上写一次；贡献不足时价格变红、按钮置灰，差额只在悬停里。兑换后浮起「−n」，该条变「已得」。
- **不写说明小字**，但风味句要有：差事交代、物品来历各一句。
- **苍崖派差事交代**（其余 20 家另批）：

| 差事 | 交代 |
|---|---|
| 洒扫剑冢 | 剑冢埋着历代先辈的佩剑，落叶积苔，须日日拂拭，不可惊扰。 |
| 夜守剑阁 | 剑阁藏着本门名剑，入夜须持灯巡守，防宵小觊觎。 |

- **美术量**：驻地图每家一张（21 张），以苍崖派为构图模板图生图，三个入口位置固定、热区坐标共用；内景按门派类型分套（正派、佛门、道观、邪教、帮会约五套 × 三座）。入口名可按门派性质换叫法（如佛门的知客寮、藏经楼），待各家出图时定。
