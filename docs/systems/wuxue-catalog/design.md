## §0 为什么要扩

掉落与装备系统把武学分成三大类、九个类目（`../battle-loot/design.md` §3.7）：

- **器械**（刀、枪、剑、棍）：手里要拿同类兵器才能装。
- **肉身**（拳、掌、指、腿）：不挑兵器，随时可装。
- **暗器**：暗器槽里装着暗器才能装，和另外两类互不冲突。

现有 14 门武学放进九个类目后，枪、指、腿是空的，其余类目也只有一两门。挂机掉落要掉得出花样，收集要有得收，所以每个类目扩到寻常 10、上乘 6、绝学 3（W1）。

## §1 一门武学由什么决定

### 1.1 五项参数，各门各取

现在一门武学的数值按品质查一张表（`../sect-neigong/spec.md` §2.1），同品质的武学完全相同。改为**每门武学一行**，五项各自取值：

| 参数 | 说明 |
|---|---|
| 伤害倍率 | 第 1 式倍率；往后每式递增仍按品质走 |
| 耗气 | 每次出招扣的真气 |
| 触发几率 | 这门武学对总触发率的贡献（§2） |
| 冷却 | 出完一招后隔几回合才能再用 |
| 特效 | 从特效池里选一种（§3） |

总表（§7）里前四项先给**高 / 中 / 低**倾向（冷却给**短 / 中 / 长**），具体数值由 sim 定。

为什么现在不写具体数值：每门武学的五项要凑成「强度落在本品质区间里」，比如倍率高了，触发或冷却就得让一让。这要 sim 把每门武学放进战斗里跑出来才知道，手填的数字一跑就会被改掉。所以名录只定「这门武学往哪边偏」，数值由 sim 生成后写进 `spec.md`（`../../README.md` §1：数值出自 sim）。

### 1.2 品质只定强度区间

品质不再直接给数值，只规定总强度：同一品质的武学，五项怎么搭都行，但 sim 算出的强度要落在该品质的区间里（如基准 ±5% `[待 sim]`），超出就回调。招式数仍按品质：寻常 3 式、上乘 5 式、绝学 7 式。

### 1.3 怎样算「不一样」

同路数、同品质的武学，五项组合起来不能完全相同（W4）。总表的生成脚本对每个「路数 × 品质」分组逐一校验过，没有两门组合相同。

## §2 触发规则

改写 `../sect-neigong/spec.md` §2.5 的「固定 55%，再等概率抽一门」：

```text
玩家每回合行动：
  候选 = 已装配 ∧ 冷却为 0 ∧ 当前真气 ≥ 耗气
  总触发率 = min(候选各门触发几率之和, 上限)
  掷骰 < 总触发率：
      按各门触发几率加权抽一门 → 从它已领悟的招式中等概率抽一式
      → 扣耗气，该武学进入冷却，这一式熟练 +1，本回合不普攻
  否则：普攻，回真气 20
```

- 只有当下能出招的武学计入总和（在冷却、真气不够的不算），这是我补的细节。
- 总触发率要设上限 `[待 sim]`，否则 5 个槽都装高触发武学，几乎每回合都出招。
- 原 55% 是 2–3 门武学同时可用时的平均水平，sim 以此为锚标定各档触发几率。

| 己方 · 持续 | 凝眸 | 之后 N 回合会心率提高 | 新增 |
| 己方 · 持续 | 轻身 | 之后 N 回合闪避提高 | 新增 |
| 敌方 · 即时 | 附毒 | 额外叠毒 | 现有 |
| 敌方 · 即时 | 透劲 | 本式无视一部分防御 | 新增 |
| 敌方 · 即时 | 封穴 | 有几率令敌人跳过下一次行动 | 新增 |

| 敌方 · 持续 | 迷目 | 之后 N 回合敌人命中降低 | 新增 |
| 敌方 · 持续 | 破绽 | 之后 N 回合敌人防御降低 | 新增 |

- 特效强弱随品质分档（寻常一档、上乘二档、绝学三档），具体数值和持续回合 `[待 sim]`。
- 「持续」类是新的战斗状态，战斗引擎要加「增益 / 减益 + 剩余回合」的结算；这一条推翻了门派武学 v2.0「不新增状态」的约束（`../sect-neigong/spec.md` §2.6）。
- 「必暴」以外，特效挂在哪几式沿用现规则：第 1 式与末式。

### 3.2 门派独门（3 种，不进通用池）

蓄势（落星沉海剑诀）、反震（金刚降魔杵经）、引爆（牵机引魂镖诀），沿用 `../sect-neigong/spec.md` §2.6，每一式都带。

## §4 路数分配

### 4.1 路数是什么、影响什么

路数就是武学和哪部内功同源：惊雷（华山）、镇岳（少林）、蚀骨（唐门），或者不属于任何一路。它只影响两件事：

- **共鸣**：武学与所修内功同路数时，招式倍率 ×1.10（`../sect-neigong/spec.md` §2.7）。这是现行机制，把「修哪部内功」和「配哪些武学」连起来。
- **绝学在哪个门派卖**：绝学归主路数，由对应门派的贡献商店出售（§5）。

不同路数的武学谁都能装，路数不限制装配。

### 4.2 怎么分

每个类目有一个**主路数**，多数武学归它，其余分给另两路和「无路数」：

| 类目 | 主路数 | 理由 |
|---|---|---|
| 剑、刀、枪 | 惊雷（华山） | 快、狠的器械 |
| 棍、拳、腿 | 镇岳（少林） | 少林以棍法、拳脚见长 |
| 掌、指、暗器 | 蚀骨（唐门） | 毒掌、点穴、暗器都是唐门手段 |

| 品质 | 主路数 | 另两路各 | 无路数 |
|---|---|---|---|
| 寻常（10 门） | 4 | 2 | 2 |
| 上乘（6 门） | 3 | 1 | 1 |
| 绝学（3 门） | 3 | — | — |

- 每条路线合计：寻常 24、上乘 15、绝学 9；无路数寻常 18、上乘 9。
- 绝学全归主路数，由该路数的门派出售（§5）。
- 「无路数」武学不吃任何共鸣，谁修都一样。

## §7 总表

### 7.1 起名规则

| 品质 | 刀、剑 | 枪、棍、拳、掌、指、腿、暗器 |
|---|---|---|
| 寻常 | 两字 + 剑法 / 刀法（4 字）：青萍剑法、破风刀法 | 两字 + 类目字（3 字）：齐眉棍、八极拳、寸劲指、梅花针 |
| 上乘 | 四字意象 + 类目字（5 字）：千山负雪剑、大江断流刀 | 同左：梨花带雨枪、开碑裂石掌、踏雪无痕腿、满天星斗镖 |
| 绝学 | 四字 + 类目字 + 诀 / 谱 / 经（6 字）：长虹贯日剑诀、大漠孤烟刀谱 | 同左：霸王卸甲枪诀、不动明王拳经、万毒归宗掌诀 |

- **两字前缀**（W7）：刀、剑后面加「法」，免得「流云剑」读起来像一把剑；其余类目不加。暗器名本身就是暗器（针、镖、钉、石、箭、梭），按暗器种类取类目字。
- **长前缀**（W8）：不加「法」，「四字意象 + 类目字」直接成名。这是武侠游戏里最常见的长名写法（参考飞书表《武学名称》约 450 条主动 / 攻击武学，五字名占六成以上，如回风舞柳剑、鹤归云隐剑、碧海惊涛掌）。四字意象取景物、动作或典故：飞瀑断崖、燕穿垂柳、平沙落雁、开碑裂石、断桥残雪。
- **绝学**在四字之后加「诀 / 谱 / 经」，比上乘多一个字，显出分量。
- **借鉴不照搬**：参考了飞书表《武学名称》、本地武侠游戏笔记（烟雨江湖、汉家江湖、下一站江湖Ⅱ、弈剑行、放置江湖等）与网上收集的游戏、小说、传统武术名称。171 个名字与飞书表逐个比对过，只有「流云剑法」完全同名（即现有的流云剑按 W7 改名）。金庸、古龙等作品的标志性专名一律不用（降龙、独孤、六脉、暴雨梨花、孔雀翎、化骨绵掌、千蛛万毒手等）。

### 7.2 总表

倍率、耗气、触发三项给高 / 中 / 低倾向，冷却给短 / 中 / 长。「现有」指已实装的 14 门，它们的特效与来路照旧，只改名。
