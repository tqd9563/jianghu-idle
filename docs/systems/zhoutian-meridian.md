## 2. 核心循环（单境界）

```text
挂机产出 → 丹田充能（上限 = 本境界突破消耗）
  → 每越过一段新高水位 =「第 N 周天圆满」
    → 发放 1 枚冲穴机会（每境界总数 = 周天数 N，硬封顶）
      → 择穴冲击（池 > 必通数 M；失败无损，保底累积）
        → 窍穴亮起：小额属性加成（加法条目）；集齐一条经脉 → 贯通集合加成
丹田充满 且 已通窍穴 ≥ M → 「突破」点亮 → 一次性扣全额 → 境界跃升
段末境界：九转圆满 + 玄关试炼 → 跃迁（一次性倍率 + 机制解锁 + 大周天换皮重锚）
```

## 3. 概念定义

### 3.1 丹田上限

丹田仍是内力唯一钱包（规格书 §6.1 单钱包模型不变），新增容量上限 = **当前境界突破消耗**（复用既有曲线，不新增参数）。武学升级照常随时支取；充满后的产出走溢出转化（§4.3），不硬浪费。

### 3.2 周天、周天数 N 与单自由度纪律

一个周天 = 内力沿已开经脉完整循环一圈，推动 `丹田上限 ÷ N` 的内力入库。呈现层「丹田上限 × 经脉 × 窍穴共同决定周天时长」成立；**参数层三者全部派生，唯一自由度是 N 的等差步长**（继承周天笔记锁定点 4：N 线性等差 +1 或 +2，段内封顶 9「九转」，禁等比/超线性）：

```text
单周天耗时 = (突破消耗 ÷ N) ÷ 内力产出/秒 ≤ 5 分钟（在线尺度红线，推广式继承）
```

### 3.3 小周天 / 大周天（段间换皮重锚）

借内丹术原典定义（小周天 = 任督二脉循环；大周天 = 全身经脉循环），与初案 §三「段内固定底数、段间跃迁」对位：

| 大境界段 | 循环形态 | 说明 |
|---|---|---|
| 第一段（境界 1–5 `[占位]`） | **小周天**：任督二脉循环 | N 等差递增至九转 |
| 段边界（跃迁节点） | **玄关**冲击（§6） | 九转圆满后突破升格为「冲击生死玄关」 |
| 第二段（境界 6–8 `[占位]`） | **大周天**：扩展至十二正经 | 「门开则路变长」字面兑现；周天计数回落重锚，单周天量级跳档 |
| 第三段（境界 9–10 `[占位]`） | 再升格一次，命名候选：天人周天 / 混元周天 `[占位]` | 同上重锚 |

小周天/大周天不是并行概念，是同一循环在不同大境界段的形态。

### 3.4 经脉（结构层，零独立数值）

| 职能 | 说明 | 数值属性 |
|---|---|---|
| 窍穴分组容器 | 每境界窍穴池分布在 2–3 条经脉上；「境界解锁新经脉」= 新池开放的叙事与图形载体（高境界经脉在图上为暗，坐实「低境界接触不到高境界窍穴」） | 零数值 |
| 贯通奖励 | 一条经脉窍穴全通 =「经脉贯通」，小额集合加成（首版纯属性，裁决 D4） | 加法条目，与窍穴同域同预算 |
| 周天路径可视化 | 周天动画沿已开经脉运行，已通窍穴为常亮珠点（兑现经脉笔记 §4 视觉种子与锁定点 2 印记呈现） | 零数值 |

**纪律**：经脉不设独立「打通」动作与成本——点亮经脉的唯一途径是打通其上窍穴，禁止为经脉另造资源消耗（防第三成长轴）。

### 3.5 窍穴（两类，严格分工）

| | 普通窍穴 | 玄关 |
|---|---|---|
| 数量 | 每境界 4–8 个 `[占位]` | 全游戏 2–3 个，仅大境界段边界 |
| 获得 | 冲穴机会 + 概率 + 保底（§4） | 九转圆满 + 专属试炼（心魔试炼占位落点），**无随机** |
| 产出 | 小额属性（加法）+ 贯通集合加成 | 零数值：跃迁倍率 + 机制解锁 + 周天升格（§6） |
| 池限制 | 境界分池：低境界不可接触高境界窍穴 | — |
| 声望接口 | 单穴永久增强（§8） | 首通进称号/图鉴（初案归隐保留表既有类目） |

## 4. 冲穴机制

### 4.1 机会发放（锚定新高水位）

冲穴机会**只由突破新高的周天圆满发放**（复用 `chargeHighWater` 语义，继承锁定点 2）：支取内力致水位回落后重新充能的周天不重复发放，每境界机会总数被 N（≤9）硬封顶，刷取漏洞结构性封死。发放比例定 1:1（每个新高周天 1 枚），不另设间隔参数（防多余自由度）。

### 4.2 冲击与温和失败

- 冲击消耗 1 枚机会，基础成功率 p `[待测试]`；失败**不损失机会以外的任何资源**（对齐初案 §三突破温和失败规则）。
- **保底累积**：每次失败使该窍穴「松动」，下次成功率 +X pp，或第 k 次必成（形态二选一 `[待测试]`）——坏运气分支不得击穿 §5 排程不等式。
- 丹药等后续系统提升 p 或补充机会；声望节点围绕返还/保底设计，不做纯成功率堆叠（初案 §三既有原则）。

### 4.3 溢出转化（有界，裁决 D2）

丹田充满后产出转为「气势」，为下一次冲穴提供成功率加成。**转化收益必须有界**：

- 单次冲穴的气势加成封顶 +Y pp `[待测试]`，且/或转化速率随已积气势指数衰减；
- 气势不跨境界累积，突破时清零；
- 目的：把「内力已满、窍穴未齐」的等待窗口变成冲穴助力，同时禁止「挂机囤气势 → 必成」的退化策略。

### 4.4 呈现

沿用机制与皮肤分层（规格书 §6.1 v0.8）：冲穴动作玩家侧措辞候选「行气冲穴」；失败措辞避重词，候选「窍穴松动几分」`[占位]`，实装走冻结流程。

## 5. 突破双条件与排程约束

```text
突破条件 = 丹田充满（内力 ≥ 突破消耗） 且 已通窍穴数 ≥ M
```

- M < 池大小（保留选择空间）；M、池、p、保底联合满足排程不等式：

```text
P(成功数 ≥ M | N 次机会, p, 保底) ≈ 1
```

- 形态示例 `[待测试]`：N=6 境界配 M=3、池 6 选 3、p=70% 起步 + 失败保底 → 期望 4–5 成，正常玩家丹田充满时窍穴自然已齐；富余机会用于池内额外窍穴（丹药价值 = 超额选择权，非必需品）。
- **设计目标**：双条件在体感上是一个过程的两个刻度，不得形成两条独立等待队列；「内力满而窍穴不齐」只允许出现在极端坏运气 + 保底兜底的窄区间，且被 §4.3 溢出转化覆盖。

## 6. 玄关与跃迁（方案三融合）

- 玄关 = 跃迁节点（初案 §三既有占位）的武侠皮，承载：一次性跃迁倍率、机制解锁（新武学档位/新系统层）、周天升格（§3.3）。零属性数值。
- 玄关**无随机**：稀缺节点不掷骰；获取 = 段末九转圆满 + 专属试炼（心魔试炼的天然落点 `[占位]`）。
- 路线向机制增强（经脉笔记方案三例「唐门通手三阴解锁毒爆二段」）**降档挂在经脉贯通层**，不占玄关——玄关全程 2–3 个，须路线无关（对齐门槛 Boss 守则的对称精神）。首版贯通为纯属性（裁决 D4），机制词条是后续批次敞口（§10-7）。

## 7. 数值归属与预算

### 7.1 乘区合规（继承锁定点 1）

窍穴/贯通加成一律**加法合并进本轮临时乘区**，作用于属性白名单内既有最终量（战斗域预算）；禁独立乘法项：

```text
最终量 = 基础值 × (1 + 永久加成总和) × (1 + 本轮临时加成总和)
                                        ↑ 窍穴/贯通条目在此加法合并
```

### 7.2 保留到归隐（裁决 D1；锁定点 3 改写的权威处）

窍穴加成**突破时不清零，保留至归隐**。与被取代的自动周天加成不同类的理由：有决策、每境界池硬封顶、加法合并、总量被预算比锁死。配套义务：

1. **敌人曲线锚定把「标准冲穴进度」计入预期玩家曲线**（与武学等级同等待遇），初案 §四第 7 条的锚定前提由此维持；
2. 每境界预算比仍须成立：境界内合计（M 穴 + 贯通）与突破跃升之比 ≤ 1/6 `[待测试]`——突破仍是体感最大单次跃升；
3. 周天笔记锁定点 3 自本文起仅约束自动型周天加成（已被取代，实际无租客）。

### 7.3 预算占位（沿用周天笔记 §3 框架，全部 `[待测试]`）

| 项 | 建议值 |
|---|---|
| 单穴加成 | +1.5%–2.5% |
| 经脉贯通集合加成 | 单条 ≈ 1–2 穴等值 |
| 境界内合计（M 穴 + 贯通） | ≤ 10%–12% |
| 与突破跃升之比 | ≤ 1/6 |
| 声望·窍穴铭刻（永久域） | 进初案 §四预算表新行，战斗域软上限内 `[占位]` |
