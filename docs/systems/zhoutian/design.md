## 1. 一句话总览

把丹田想象成一个**会长大的蓄水池**。每个周天有自己的配额：挂机产出像水一样注入，蓄满即「周天圆满」——这一池内力**沉入丹田根基（真实消耗）**，换得一次冲穴机会，丹田容量随之扩到下一段更大的配额。如此周而复始；N 段全部缴清、窍穴也通够数，方可突破。突破消耗在过程中**分期支付**，不再一次性扣除。

**经脉**是把窍穴分组的容器（不是独立数值系统），**玄关**是大境界之间的门（本版不做），**气势**是周天圆满时随机会一并赠予的临时加成。

### 名词对照

| 名词 | 解释 |
|---|---|
| 丹田 | 内力唯一钱包，容量 = 当前周天的配额（逐段扩大） |
| 周天 | 蓄满当前配额并沉入根基的一次循环；圆满即潮落 |
| 周天配额 | 第 i 段需缴纳的内力；境界内公比 2（每段翻倍） |
| 周天数 N | 本境界的分期段数（境界 1–5 = 4/3/4/6/8） |
| 冲穴机会 | 每次周天圆满发 1 次，可囤积不过期 |
| 窍穴 | 冲开后给加成，永久保留到归隐 |
| 经脉 | 窍穴分组容器，全通一条有额外奖励 |
| 气势 | 周天圆满时赠予的临时状态（v3 裁决 D5：替代旧「溢出转气势」） |
| 宿慧 | 首达境界的一次性永久产出加成（跨归隐保留，见 §8 与声望经济表） |

## 2. 核心循环

```text
挂机产出 → 注入当前周天（容量 = 本段配额）
  → 蓄满 =「第 i 周天圆满」：本段内力沉入根基（真实消耗，潮落）
    → 发放冲穴机会 +1（可囤积）并赠气势（D5）
    → 丹田容量扩至下一段配额（公比 2）
      → 择穴冲击（池 > 必通数 M；失败无损，保底累积）
        → 窍穴亮起，加成生效；集齐一条经脉 → 贯通加成
  → N 段全部缴清 且 已通窍穴 ≥ M → 突破（费用已分期付讫）
```

升级武学支取内力时，从**当前段**扣款、液面如实回落（气机回落）；已沉入根基的部分不受影响。

### 3.1 境界总额与周天配额（长线版，由 pacing_sim 反解）

里程碑锚（唯一的源）：第 1/7/21/50/100 天首次摸到境界 2/3/4/5/6；

乘区 M(第 d 天) = d（宿慧 60% + 声望阁 40%，见声望经济表）。

| 境界 | N | 本境界总额 | 断崖 | 基准时长 | 首段配额 | 末段配额 |
|---|---|---|---|---|---|---|
| 1 | 4 | 518,000 | — | 16h | 34,533 | 276,267 |
| 2 | 3 | 3,890,000 | 7.5× | 96h | 555,714 | 2,222,857 |
| 3 | 4 | 11,300,000 | 2.9× | 223h | 753,333 | 6,026,667 |

| 参数 | 值 | 说明 |
|---|---|---|
| 基础成功率 p | 85% | 失败不损失机会以外的任何资源 |

| 必成兜底 | 第 3 次必成 | 同穴累计失败 2 次后必成 |

## 4. 突破双条件

```text
突破条件 = N 段周天全部缴清 且 已通窍穴数 ≥ M
```

突破消耗已在各周天圆满时分期付讫，突破动作本身不再扣除内力。
"周天缴清而窍穴不齐"只出现在极端坏运气 + 保底兜底的窄区间（§3.4 P≥0.90）；
此时继续产出的内力顶在末段满额、机会不再新增——此敞口由声望节点「冲穴保底类」承接（§7）。

## 6. 加成域归属

```text
最终量 = 基础值 × (1 + 永久加成总和) × (1 + 本轮临时加成总和 + 窍穴/贯通加成总和)
```

窍穴/贯通加法合并进临时乘区，禁独立乘法项。

## 8. 长线节奏（v3.0 新增）

- **依赖方向**：里程碑表（第 1/7/21/50/100 天首达境界 2/3/4/5/6）是唯一的源，
  境界总额、周天配额、宿慧表、声望经济目标全部由 `../sim/pacing_sim.py` 反解；
  调节奏改 sim 输入重跑，产物回填本表与声望经济表。
- **宿慧**：首达境界 X 的一次性永久产出加成，预付下一里程碑的 60%
  （首达 2/3/4/5 分别 +3.6× / +8.4× / +17.4× / +30.0×，跨归隐保留）；
  余下 40% 斜坡由声望阁「修行感悟」节点交付（声望经济表 v2）。
- **玩家画像**：锚定标准玩家（4h 在线 + 20h 离线 × 60% = 16h/天）；
  全天在线快 1.5×（境界 6 ≈ 第 67 天），轻度玩家几乎不掉队（≈ 第 105 天）。
- **联动挂账**：离线收益表需改为「恒定 60% 效率、无硬上限」；敌人曲线/地图解锁按境界重锚
  （`spec.md` §2 已标过期）；武学升级消耗改按当前段配额百分比计价（公式表待定）。
