## 1. 一句话总览

把丹田想象成一个**会长大的蓄水池**。每个周天有自己的配额：挂机产出像水一样注入，蓄满即「周天圆满」——这一池内力**沉入丹田根基（真实消耗）**，真气沿经脉多行至一处窍穴，丹田容量随之扩到下一段更大的配额。如此周而复始；N 段全部缴清、本境界首条经脉也贯通了，方可突破。突破消耗在过程中**分期支付**，不再一次性扣除。

**冲穴只用内力一种资源**：窍穴松动后，丹田蓄够它所需的真气便可冲，冲即扣款，成则通穴，败则真气白白耗散。没有「机会」，也没有「气势」（v4.0 起废止）。

**经脉**是把窍穴分组的容器（不是独立数值系统），**玄关**是大境界之间的门（本版不做）。

### 名词对照

| 名词 | 解释 |
|---|---|
| 丹田 | 内力唯一钱包，容量 = 当前周天的配额（逐段扩大） |
| 周天 | 蓄满当前配额并沉入根基的一次循环；圆满即潮落 |
| 周天配额 | 第 i 段需缴纳的内力；境界内公比 2（每段翻倍） |
| 周天数 N | 本境界的分期段数（境界 1–5 = 4/3/4/6/8） |
| 窍穴 | 冲开后给加成，永久保留到归隐 |
| 松动 | 真气行至该穴的状态：可冲的前提之一（另一前提是真气蓄够） |
| 所需真气 | 冲一次该穴要从当前段扣的内力，按当前段配额的百分比定，松动即装得下（§3.3） |
| 经脉 | 窍穴分组容器；同一条脉的穴按次序冲，全通一条有额外奖励 |
| 宿慧 | 首达境界的一次性永久产出加成（跨归隐保留，见 §8 与声望经济表） |

## 2. 核心循环

```text
挂机产出 → 注入当前周天（容量 = 本段配额）
  → 蓄满 =「第 i 周天圆满」：本段内力沉入根基（真实消耗，潮落）
    → 真气行至下一穴：后 M 段每圆满一段松动一穴（前几段筑基，真气未至；末段圆满时余下窍穴一并松动）
    → 丹田容量扩至下一段配额（公比 2）
  → 冲穴（随时，须同时满足两个条件）：
      ① 该穴已松动，且它前面同一条脉的穴已通
      ② 当前段内力 ≥ 该穴所需真气
      → 扣掉所需真气 → 成：窍穴亮起，加成生效；集齐一条经脉 → 贯通加成
                       → 败：真气耗散，同穴下次 +10pp，再蓄再冲
  → N 段全部缴清 且 本境界首条经脉贯通 → 突破（费用已分期付讫）
```

冲穴和升级武学一样，都从**当前段**扣款、液面如实回落；已沉入根基的部分不受影响。冲穴因此会拖慢本段圆满——这是玩家要权衡的：先冲穴，还是先让周天圆满。

周天圆满一次给三样东西：缴清一期突破费用、丹田扩容、真气行至下一穴。三样在修炼面板上都看得见。

- **同一条脉须按次序冲**：前一穴未通，后一穴即使松动也不可冲；不同脉之间不互相阻塞

### 3.3 冲穴参数

成功率与所需真气由**公式生成默认值**，看这个穴在它那条经脉里排第几（位次 k）；越靠后的穴越难通、要的真气越多——贯通一条脉就是一路越冲越难。公式可无限延伸到更长的脉；个别穴要特别难，在 §3.2 窍穴表逐穴覆写。

| 项 | 公式 | 第 1 / 2 / 3 穴 |
|---|---|---|
| 成功率 | 90% − 10pp × (k−1)，最低 50% | 90% / 80% / 70% |
| 所需真气（占当前段配额） | (11% + 5% × (k−1)) × 1.2^(境界−2) | 境界 2：11% / 16%；境界 5：19% / 28% / 36% |

- 锚在**当前段配额**，松动即装得下、即可冲，没有等扩容的空窗。
- **境界乘数 1.2^(境界−2)**：同一位次的穴，境界越高要的比例越大——保证「越往上越难」在境界 2→3、4→5 这类突破穴数不变的台阶上也成立（`sim.py` W4）。
- 上述数值经 `sim.py` 判据 W1–W4 全 PASS（2026-09-22 拍板）。

| 参数 | 值 | 说明 |
|---|---|---|
| 冲穴消耗 | 所需真气，成败同扣 | 失败 = 这笔真气白白耗散，这就是惩罚 |
| 冲穴门槛 | 当前段内力 ≥ 所需真气 | 升武学支取后液面回落，可能要再蓄 |
| 失败加成 | +10pp/次 | 同穴每次失败，下次 +10pp；v3 的「第 3 次必成」废止（内力可无限重试，不需保底） |
| 单穴加成 | 境界 2–4 +2%，境界 5 +1.5% | 加法合并进临时乘区 |
| 贯通集合 | 单穴 × 1.5 | 全线通则额外奖励 |

### 3.4 冲穴附加时间判据（`sim.py` 验算 PASS）

冲穴花的内力全从当前段扣，所以「通够 M 穴要多付的内力 ÷ 境界总额」就是突破被拖慢的比例（与 §3.1 基准时长同口径）。四条判据：

| 判据 | 要求 | 实测（20000 次） |
|---|---|---|
| W1 无死锁 | 内力持续产出可无限重试；所需真气 ≤ 当前段配额 | 全境界 PASS |
| W2 附加时间中位 | 15%–50% 账期 | 境界 2/3/4/5 = 15% / 27% / 35% / 37% |
| W3 坏运不惨 | P95 总时长 ≤ 中位 × 1.5 | 1.08 / 1.21 / 1.20 / 1.27 |
| W4 越往上越难 | 附加占比随境界非递减 | PASS |

## 4. 突破双条件

```text
突破条件 = N 段周天全部缴清 且 本境界首条经脉贯通
```

「贯通」= 该脉所有窍穴按次序冲通（§3.2）。门槛**按境界计，不跨境界累计**：每境界重建窍穴池，只看本境界的首条脉。注意与加成口径区分——窍穴/贯通**加成**保留至归隐、按全局累计（§5 D1），只有突破的门槛按境界。

武侠对应：底蕴不是「通了几个穴」，而是「一条经脉是否走通」——脉走到末穴越冲越难，根基不够，内力再多也过不去。

突破消耗已在各周天圆满时分期付讫，突破动作本身不再扣除内力。
「周天缴清而窍穴不齐」不再是死路：末段满额后冲穴扣款、液面回落、再蓄再冲，直到通够为止（§3.4 W1）。

## 8. 长线节奏（v3.0 新增）

- **依赖方向**：里程碑表（第 1/7/21/50/100 天首达境界 2/3/4/5/6）是唯一的源，
  境界总额、周天配额、宿慧表、声望经济目标全部由 `../sim/pacing_sim.py` 反解；

- **宿慧**：首达境界 X 的一次性永久产出加成，预付下一里程碑的 60%
  （首达 2/3/4/5 分别 +3.6× / +8.4× / +17.4× / +30.0×，跨归隐保留）；
  余下 40% 斜坡由声望阁「修行感悟」节点交付（声望经济表 v2）。
- **玩家画像**：锚定标准玩家（4h 在线 + 20h 离线 × 60% = 16h/天）；
  全天在线快 1.5×（境界 6 ≈ 第 67 天），轻度玩家几乎不掉队（≈ 第 105 天）。
- **联动挂账**：离线收益表需改为「恒定 60% 效率、无硬上限」；敌人曲线/地图解锁按境界重锚
  （`spec.md` §2 已标过期）；武学升级消耗改按当前段配额百分比计价（公式表待定）。
