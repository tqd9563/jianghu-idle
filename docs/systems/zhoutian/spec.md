## 1. 呈现一致性

| 层 | 语义 | UI 实现 |
|---|---|---|
| 进度回落 | 数值可信——内力支取后进度条如实回落 | ChargeTrack 段内宽度 |
| 印记常亮 | 高水位——已圆满的周天不因回落而消失 | ChargeTrack 段珠点常亮 |
| 气势条 | 丹田充满后溢出可见——与充能进度语义分离 | QishiBar 独立条 |

- 三层 UI 语义可区分，不混淆（验收项）。
- 冲穴措辞走冻结流程，见 `../../rules/copy/zhoutian.md`。

## 2. 敌人曲线锚定

标准冲穴进度须计入预期玩家曲线。**本版结论**：境界 2–5 合计加成 6–12%，相当于永久乘区 +6–12%，与武学等级（每级 +6–8%）同量级。**MVP-0 敌人数值不动**——既有 golden 用例按「属性只来自境界+武学+节点」校准，加入窍穴后玩家曲线整体上移 6–12%；本版接受此上移（玩家体验更顺、卡点稍后移），不重锚敌人数值。后续若实测卡点失效，再走数值重锚子任务。
