## 4. 修炼面板呈现方案（内视星图式）

> **状态**：原型已收敛未定稿。原型 `../../design/zhoutian-composite-v3.html`，接入 `CultivatePane.tsx` 前须先定稿。

### 4.1 两态结构

面板分**外视**与**内视**两态，默认外视，点丹田切入内视，「收功」返回。

| 态 | 职责 | 信息粒度 |
|---|---|---|
| 外视 | 气象——「我这个人现在什么水准」 | 境界级：经脉辉光、周身罡气、丹田气光强弱 |
| 内视 | 详情——「这一池攒到哪、哪个窍穴能冲」 | 周天段级 + 窍穴级；冲穴交互只在此态可用 |

- 外视**不读液位**：丹田处只呈现一团强弱随进度变化的气光，不做液位裁切（小尺寸下裁切边会暴露成矩形）。
- 外视错过的时机由 toast 兜底：周天圆满时提示「点丹田内视冲穴」。

### 4.2 三层职责与数据绑定

内视自后向前分三层，各层只吃自己那一档数据，互不复述：

| 层 | 呈现 | 绑定 |
|---|---|---|
| 背景 | 墨渊星空底图 + 向心暗角 | 静态 |
| 器皿 | 液体视频（波形遮罩裁出液面）、空腔气雾、中央段进度读数 | 段内进度 → 液面高度；挂机倍速 → `playbackRate`（封顶 4）；圆满 → 闪光 + 沉底 |
| 器物 | 周天月相串、窍穴星曜 + 星官连线、图例 | 已缴段数 → 月相三态；松动且真气够 → 星曜可点态；已通窍穴 → 金星与经脉贯通柔光 |

外视另有两项绑定：境界 + 总进度 → 人影亮度与经脉辉光强度；境界 ≥ 炉火纯青 → 周身罡气显影。

**三态色义**（与 §1 语义分层同属呈现契约，不可与其它状态混用）：

| 元素 | 未及 | 当前/可操作 | 已成 |
|---|---|---|---|
| 周天月相 | 晦月（全暗盘） | 上弦（右半明） | 满月（全亮） |
| 窍穴星曜 | 墨星（灰度压暗） | 朱砂星（脉动） | 金星 |

### 4.4 素材制作纪律

以下四条为本轮踩坑固化，新增素材须遵守：

1. **无缝循环**：循环视频用首尾同帧模式生成（同一张图同时作首帧与尾帧），验收标准为首尾帧灰度均差 < 1%；并须复核中间帧与首帧有差异，防止模型退化成静止画面。
2. **调色烘进素材**：用 ffmpeg 预调色（暗素材用 `eq=gamma=`，勿用 `contrast=`——对暗画面会把暗部整体压死）。**禁止给 `<video>` 或其祖先挂 CSS `filter`**：会打断合成快路径，实测产生硬边矩形假影。
3. **透明精灵**：在纯黑底生成，按「减黑场 → 亮度转 alpha」抠图。黑场值取四角样本实测（JPEG 的黑约为 3–11，不减会整张蒙一层灰纱）。
4. **体积**：单个视频素材压到 200KB 量级（720 见方 / crf 26 足够）；被取代的素材随原型引用一并清理，不留 404。
